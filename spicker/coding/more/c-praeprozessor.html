#define & Makros

#define MAX_PLAYERS 8                 /* Konstante (wird vor dem Kompilieren ersetzt) */
#define SQUARE(x) ((x) * (x))           /* Makro – Klammern sind wichtig! */

int players[MAX_PLAYERS];
int area = SQUARE(3 + 1);               /* ((3 + 1) * (3 + 1)) = 16 */

#ifdef DEBUG
    printf("[debug] Start\n");         /* nur mit gcc -DDEBUG */

Für Konstanten ist in modernem C oft static const int MAX = 8; oder ein enum besser – das hat einen Typ.

Dateien

FILE *file = fopen("scores.txt", "w");      /* "r" lesen, "w" schreiben, "a" anhängen */
if (file == NULL) {
    perror("[Datei] fopen");                 /* gibt Grund aus, z. B. "No such file" */
    return 1;
}
fprintf(file, "Max %d\n", 120);
fclose(file);

file = fopen("scores.txt", "r");
char line[128];
while (fgets(line, sizeof line, file) != NULL) {
    printf("Gelesen: %s", line);
}
fclose(file);

Tipps & typische Fehler

  • Jedes fopen braucht ein fclose.
  • Makros sind reiner Text-Ersatz – ohne Klammern gibt SQUARE(3 + 1) sonst 3 + 1 * 3 + 1 = 7.
  • static vor einer Funktion macht sie nur in ihrer Datei sichtbar.
