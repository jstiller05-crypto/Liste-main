<canvas>

Eine Zeichenfläche, auf der du mit JavaScript Grafiken, Diagramme oder Spiele zeichnest.

Was ist das?

<canvas> ist zuerst leer. Mit JavaScript holst du dir einen Kontext (den „Pinsel“) und zeichnest damit Pixel für Pixel: Rechtecke, Linien, Kreise, Text, Bilder. Viele Browser-Spiele laufen so.

Syntax

<canvas id="myCanvas" width="300" height="150"></canvas>

<script>
  const canvas = document.getElementById("myCanvas");
  const ctx = canvas.getContext("2d");   // 2D-Pinsel holen
</script>

Beispiel

const canvas = document.getElementById("myCanvas");
const ctx = canvas.getContext("2d");

// gefülltes Rechteck: x, y, Breite, Höhe
ctx.fillStyle = "#4f8cff";
ctx.fillRect(20, 20, 100, 60);

// Kreis: Mittelpunkt x, y, Radius, Startwinkel, Endwinkel
ctx.beginPath();
ctx.arc(200, 75, 40, 0, Math.PI * 2);
ctx.fillStyle = "#f2f2f2";
ctx.fill();

// Linie
ctx.beginPath();
ctx.moveTo(20, 130);     // Stift ansetzen
ctx.lineTo(280, 130);    // Linie ziehen
ctx.strokeStyle = "#a8a8a8";
ctx.stroke();

// Text
ctx.font = "16px Arial";
ctx.fillText("Hallo Canvas", 20, 110);

Wichtige Befehle

BefehlWirkung
fillRect(x, y, b, h)Gefülltes Rechteck
strokeRect(x, y, b, h)Nur Rahmen
clearRect(x, y, b, h)Bereich löschen
beginPath() … fill() / stroke()Eigene Form zeichnen
arc(x, y, r, start, ende)Kreis/Bogen (Winkel im Bogenmaß)
fillText(text, x, y)Text schreiben
drawImage(bild, x, y)Bild einfügen

Animation

let x = 0;

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height); // alles löschen
  ctx.fillRect(x, 50, 30, 30);                      // Quadrat zeichnen
  x = (x + 2) % canvas.width;                       // nach rechts, am Ende von vorn
  requestAnimationFrame(draw);                      // nächstes Bild
}
draw();

Tipps & typische Fehler

  • Größe mit den Attributen width/height setzen, nicht nur mit CSS – sonst wird die Zeichnung verzerrt.
  • Der Ursprung (0,0) ist oben links; y wächst nach unten.
  • Was einmal gezeichnet ist, sind nur noch Pixel – zum Bewegen alles löschen und neu zeichnen.
