SwiftUI

Apples Framework für Benutzeroberflächen: Man beschreibt, was angezeigt wird – SwiftUI kümmert sich um das Wie.

Was ist das?

SwiftUI ist deklarativ: Die Oberfläche ist eine Funktion des Zustands. Ändert sich eine @State-Variable, zeichnet SwiftUI automatisch neu – ähnlich wie React im Web.

Nur auf macOS: Xcode, SwiftUI-Vorschau und der iPhone-Simulator gibt es ausschließlich auf einem Mac. Die Sprache Swift selbst läuft auch auf Windows und Linux.

Erste Ansicht

import SwiftUI

struct ContentView: View {
    @State private var count = 0            // Zustand: Änderung → neu zeichnen

    var body: some View {
        VStack(spacing: 16) {               // senkrecht stapeln
            Text("Zähler: \(count)")
                .font(.title)
            Button("Plus eins") {
                count += 1
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}

#Preview {
    ContentView()                           // Live-Vorschau in Xcode
}

Modifier

Text("Hallo")
    .font(.headline)          // wie CSS-Eigenschaften, aber als Methodenkette
    .foregroundStyle(.blue)
    .padding()
    .background(.gray.opacity(0.2))
    .clipShape(RoundedRectangle(cornerRadius: 8))

Die Reihenfolge der Modifier zählt: .padding().background() ist etwas anderes als .background().padding().

Liste mit Eingabe

struct TodoView: View {
    @State private var items: [String] = []
    @State private var newItem = ""

    var body: some View {
        NavigationStack {
            List {
                HStack {
                    TextField("Neue Aufgabe", text: $newItem)   // $ = Bindung an den State
                    Button("Hinzufügen") {
                        guard !newItem.isEmpty else { return }
                        items.append(newItem)
                        newItem = ""
                    }
                }
                ForEach(items, id: \.self) { item in
                    Text(item)
                }
            }
            .navigationTitle("Aufgaben")
        }
    }
}

Zustand weitergeben

Property WrapperBedeutung
@StateEigener, lokaler Zustand einer Ansicht
@BindingZugriff auf den State einer übergeordneten Ansicht (mit $ übergeben)
@Observable (Klasse)Gemeinsames Datenmodell für mehrere Ansichten
@EnvironmentWerte aus der Umgebung, z. B. Dark Mode

Tipps & typische Fehler

  • Jede SwiftUI-Ansicht ist ein struct, das das Protocol View erfüllt und eine body-Eigenschaft hat.
  • $name erzeugt eine Bindung (zum Lesen und Schreiben), name nur den Wert.
