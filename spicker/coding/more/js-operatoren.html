Praktische Kurzformen

// Ternärer Operator: kurzes if/else
const label = age >= 18 ? "volljährig" : "minderjährig";

// || – Ersatzwert, wenn links falsy ist
const name = input.value || "Gast";

// ?? – Ersatzwert nur bei null/undefined (0 und "" bleiben erhalten)
const count = savedCount ?? 0;

// ?. – optional chaining: kein Fehler, wenn etwas fehlt
const city = user?.address?.city;   // undefined statt Absturz

Tipps & typische Fehler

  • Immer === statt == verwenden.
  • = weist zu, === vergleicht. if (x = 5) ist ein klassischer Fehler.
  • Punkt vor Strich gilt auch hier – im Zweifel Klammern setzen.
