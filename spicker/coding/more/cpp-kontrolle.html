C++ · Kontrollstrukturen

switch, do-while, break & continue

Weitere Kontrollstrukturen neben if, for und while.

switch – viele feste Werte

int choice = 2;

switch (choice) {
    case 1:
        std::cout << "Addition\n";
        break;                        // ohne break läuft es in den nächsten case!
    case 2:
        std::cout << "Subtraktion\n";
        break;
    case 3:
    case 4:                           // mehrere Fälle, gleicher Code
        std::cout << "Multiplikation oder Division\n";
        break;
    default:                          // wenn kein case passt
        std::cout << "Ungültige Auswahl\n";
}

switch funktioniert nur mit ganzen Zahlen, char und enum – nicht mit std::string.

do-while – mindestens einmal

int number;

do {
    std::cout << "Zahl zwischen 1 und 10: ";
    std::cin >> number;
} while (number < 1 || number > 10);   // wiederholen, solange ungültig

std::cout << "Danke, " << number << "\n";

Anders als while prüft do-while die Bedingung erst nach dem ersten Durchlauf – ideal für Eingabe-Prüfungen und Menüs.

break & continue

for (int i = 1; i <= 10; ++i) {
    if (i % 2 == 0) continue;    // gerade Zahlen überspringen
    if (i > 7) break;            // Schleife ganz beenden
    std::cout << i << " ";       // 1 3 5 7
}

Bereichsbasierte for-Schleife

std::vector<int> scores = {80, 95, 70};

for (int score : scores) {              // Kopie jedes Elements
    std::cout << score << "\n";
}

for (int& score : scores) {             // Referenz: Elemente ändern
    score += 5;
}

for (const auto& score : scores) {      // nur lesen, ohne Kopie – empfohlen
    std::cout << score << "\n";
}

Menü-Schleife (typisches Muster)

bool running = true;

while (running) {
    std::cout << "1) Spielen  2) Statistik  0) Beenden\n";
    int choice;
    std::cin >> choice;

    switch (choice) {
        case 1: startGame();      break;
        case 2: showStatistics(); break;
        case 0: running = false;  break;
        default: std::cout << "Unbekannt\n";
    }
}

Tipps & typische Fehler

  • Fehlendes break im switch ist einer der häufigsten Fehler – der Compiler warnt mit -Wimplicit-fallthrough.
  • Variablen innerhalb eines case in { } setzen, sonst meckert der Compiler („jump to case label“).
  • break beendet nur die innerste Schleife.
