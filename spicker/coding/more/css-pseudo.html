Pseudoklassen & Pseudoelemente

Elemente in einem bestimmten Zustand (:hover) oder unsichtbare Teile eines Elements (::before) gestalten.

Unterschied

PseudoklassePseudoelement
Schreibweiseein Doppelpunkt :hoverzwei Doppelpunkte ::before
BedeutungElement in einem ZustandEin Teil des Elements

Zustände (Pseudoklassen)

PseudoklasseTrifft, wenn …
:hoverdie Maus darüber ist
:focusdas Element fokussiert ist (z. B. ins Feld geklickt)
:focus-visibleFokus per Tastatur – für sichtbare Fokus-Rahmen
:activegerade geklickt wird
:visitedder Link schon besucht wurde
:checkedCheckbox/Radio angehakt ist
:disableddas Feld deaktiviert ist
:focus-withinirgendein Kind Fokus hat (z. B. für Dropdowns)

Position (Pseudoklassen)

PseudoklasseTrifft …
:first-child / :last-childdas erste / letzte Kind
:nth-child(2)das 2. Kind
:nth-child(even) / (odd)jedes gerade / ungerade Kind
:nth-child(3n)jedes dritte Kind
:not(.active)alle, die NICHT die Klasse haben
 
li:not(:last-child) {
  border-bottom: 1px solid #444;   /* Trennlinie außer beim letzten */
}

tr:nth-child(even) {
  background: #2b2b2b;             /* Zebra-Streifen */
}

Pseudoelemente

PseudoelementGestaltet …
::before / ::afterEinen eingefügten Inhalt vor / nach dem Element (braucht content)
::placeholderDen Platzhaltertext eines Eingabefelds
::markerDen Punkt/die Nummer einer Liste
::selectionMarkierten Text
::first-letterDen ersten Buchstaben
 
.required::after {
  content: " *";          /* ohne content erscheint nichts! */
  color: #ff5f5f;
}

input::placeholder {
  color: #888;
}

Beispiel: Button mit allen Zuständen

.button              { background: #3a3a3a; }
.button:hover        { background: #474747; }
.button:active       { transform: scale(0.97); }
.button:focus-visible{ outline: 2px solid #4f8cff; }
.button:disabled     { opacity: 0.5; cursor: not-allowed; }

Tipps & typische Fehler

  • Den Fokus-Rahmen nie ersatzlos entfernen (outline: none) – Tastatur-Nutzer sehen sonst nicht, wo sie sind.
  • ::before/::after funktionieren nicht bei leeren Elementen wie <img> oder <input>.
  • Zustände kannst du in den Entwicklertools (F12 → Elemente → „:hov“) erzwingen und testen.
