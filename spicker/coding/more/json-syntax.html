JSON · Syntax

JSON-Syntax

Nur sechs Datentypen, dafür sehr strenge Regeln – schon ein fehlendes Komma macht die ganze Datei ungültig.

Die sechs Datentypen

TypBeispiel
string"Max"
number17, 3.14, -5
booleantrue, false
nullnull
object{ "city": "Berlin" }
array["chess", "coding"]

Was es NICHT gibt: ein eigenes Datum, undefined, Funktionen, NaN und Infinity – all das kennt JSON nicht als Typ.

Ein Datum speichert man trotzdem – einfach als string im ISO-Format: "2026-10-09T16:45:00Z". Das lässt sich in jeder Sprache leicht wieder in ein echtes Datum umwandeln.

Objekte

Ein JSON-Objekt ist eine Liste von Schlüssel-Wert-Paaren in { }. Der Schlüssel steht immer in doppelten Anführungszeichen, auch wenn er wie ein normaler Name aussieht:

{
  "name": "Anna",
  "age": 16
}

Arrays

Ein JSON-Array ist eine geordnete Liste von Werten in [ ]. Die Werte dürfen gemischte Typen haben, auch wenn in der Praxis meist alle Einträge gleich aufgebaut sind. Der häufigste Fall ist ein Array aus Objekten:

[
  { "name": "Max", "points": 10 },
  { "name": "Anna", "points": 15 }
]

Verschachtelung

Objekte und Arrays dürfen beliebig tief ineinander verschachtelt sein – ein Objekt in einem Array in einem Objekt ist völlig normal:

{
  "users": [
    { "name": "Max", "items": ["sword", "shield"] },
    { "name": "Anna", "items": ["bow"] }
  ]
}

Den Weg zu einem Wert beschreibt man wie in JavaScript selbst: data.users[0].name ist "Max" – erst der Schlüssel users, dann der Index 0 im Array, dann der Schlüssel name.

Regeln

  • Nur doppelte Anführungszeichen – für Strings UND für Schlüssel.
  • Kein Komma nach dem letzten Element in einem Objekt oder Array.
  • Keine Kommentare – auch nicht // oder /* */.
  • Sonderzeichen in Strings werden escaped: \" (Anführungszeichen), \\ (Backslash), \n (Zeilenumbruch), ä (Unicode, hier „ä“).
  • Dateiendung: .json.
  • Kodierung: UTF-8.
