Objekte & JSON

Zusammengehörige Daten als Schlüssel-Wert-Paare speichern – und als JSON austauschen.

Objekt anlegen & benutzen

const user = {
  name: "Max",
  age: 30,
  skills: ["HTML", "CSS"],
  greet() {                         // Methode = Funktion im Objekt
    return `Hi, ich bin ${this.name}`;
  }
};

user.name;             // "Max"   – Punkt-Schreibweise
user["age"];           // 30      – Klammer-Schreibweise (für Variablen als Schlüssel)
user.greet();          // "Hi, ich bin Max"

user.age = 31;         // ändern
user.city = "Berlin";  // neue Eigenschaft
delete user.city;      // entfernen
"name" in user;        // true – existiert der Schlüssel?

Nützliche Helfer

BefehlErgebnis
Object.keys(user)Array aller Schlüssel: ["name", "age", …]
Object.values(user)Array aller Werte
Object.entries(user)Array aus [schlüssel, wert]-Paaren
{ ...user }Kopie des Objekts
{ ...user, age: 40 }Kopie mit geändertem Wert
 
for (const [key, value] of Object.entries(user)) {
  console.log(key, "=", value);
}

Destructuring – Werte auspacken

const { name, age } = user;              // statt user.name, user.age
const { name: userName } = user;         // umbenennen
const [first, second] = ["a", "b"];      // funktioniert auch mit Arrays

function show({ name, age }) {           // direkt in Parametern
  console.log(name, age);
}

JSON

JSON ist ein Textformat für Daten – fast wie JavaScript-Objekte, aber Schlüssel stehen immer in doppelten Anführungszeichen. Man braucht es zum Speichern (localStorage) und zum Austausch mit Servern.

const text = JSON.stringify(user);        // Objekt → Text
// '{"name":"Max","age":30,"skills":["HTML","CSS"]}'

const copy = JSON.parse(text);            // Text → Objekt

JSON.stringify(user, null, 2);            // schön eingerückt

Tipps & typische Fehler

  • const bei Objekten verhindert nur das Neu-Zuweisen – der Inhalt lässt sich trotzdem ändern.
  • Objekte werden als Referenz übergeben: const b = a; ist keine Kopie – ändert man b, ändert sich a.
  • In JSON gibt es keine Funktionen, keine Kommentare und kein Komma nach dem letzten Eintrag.
