Funktionen

Code mit def bündeln: Parameter, Standardwerte, return, beliebig viele Argumente mit *args/**kwargs, kurze lambda-Funktionen und Type Hints.

Was ist das?

Eine Funktion ist ein benannter Block Code, den man beliebig oft aufrufen kann. Sie bekommt Werte über Parameter und gibt mit return ein Ergebnis zurück. In Python beginnt sie mit def; Typen für Parameter und Rückgabe sind freiwillig.

def & Parameter

# functions.py
def greet(name):                    # name ist ein Parameter
    """Begrüßt eine Person."""      # Docstring: erscheint bei help(greet)
    print(f"Hallo {name}!")

def add(a, b):
    return a + b                    # Ergebnis zurückgeben

greet("Anna")                       # Aufruf mit Argument "Anna"
total = add(3, 4)
print(total)                        # 7

# Argumente mit Namen übergeben – Reihenfolge ist dann egal
print(add(b=10, a=1))               # 11
python functions.py

Eine Funktion muss oberhalb der Stelle definiert sein, an der sie aufgerufen wird – Python liest die Datei von oben nach unten.

Standardwerte

# defaults.py
def power(base, exponent=2):        # exponent ist freiwillig
    return base ** exponent

print(power(5))                     # 25  – exponent = 2
print(power(5, 3))                  # 125
print(power(exponent=4, base=2))    # 16

# Parameter mit Standardwert stehen immer HINTER denen ohne.
python defaults.py

return

# returns.py
def divide(a, b):
    if b == 0:
        return None                 # früh aussteigen
    return a / b

def min_max(numbers):
    return min(numbers), max(numbers)   # mehrere Werte = ein Tupel

def log(message):
    print("[log]", message)         # kein return -> gibt None zurück

print(divide(10, 4))                # 2.5
print(divide(1, 0))                 # None

lowest, highest = min_max([4, 9, 2])    # Tupel direkt auspacken
print(lowest, highest)              # 2 9

print(log("Test"))                  # erst "[log] Test", dann None

*args und **kwargs

Für Funktionen mit beliebig vielen Argumenten. Die Namen args und kwargs sind nur üblich – entscheidend sind die Sternchen.

# varargs.py
def total(*args):                   # sammelt Positions-Argumente in einem Tupel
    print("args:", args)
    return sum(args)

def show(**kwargs):                 # sammelt benannte Argumente in einem Dict
    for key, value in kwargs.items():
        print(f"{key} = {value}")

print(total(1, 2, 3))               # args: (1, 2, 3) -> 6
show(name="Anna", age=25)

# Umgekehrt: Liste/Dict beim AUFRUF auspacken
numbers = [1, 2, 3]
print(total(*numbers))              # wie total(1, 2, 3)
settings = {"name": "Max", "age": 30}
show(**settings)                    # wie show(name="Max", age=30)
python varargs.py

lambda

Eine lambda ist eine namenlose Mini-Funktion aus einem Ausdruck – wie die Pfeilfunktion (x) => x * 2 in JS oder [](int x) { return x * 2; } in C++. Man braucht sie fast nur als Argument für andere Funktionen.

# lambdas.py
double = lambda x: x * 2            # dasselbe wie:  def double(x): return x * 2
print(double(5))                    # 10

players = [("Anna", 150), ("Max", 120), ("Kim", 180)]

# key = "wonach sortieren?" – hier nach dem zweiten Wert (Punkte)
players.sort(key=lambda player: player[1], reverse=True)
print(players)                      # Kim, Anna, Max

longest = max(["a", "abc", "ab"], key=len)   # normale Funktionen gehen auch
print(longest)                      # abc
python lambdas.py

Type Hints

Type Hints schreiben dazu, welche Typen erwartet werden. Python selbst prüft sie nicht beim Ausführen – sie helfen dem Editor (Autovervollständigung, Warnungen) und allen, die den Code lesen.

# hints.py
def area(width: float, height: float) -> float:
    return width * height

def find_user(user_id: int) -> str | None:      # str ODER None
    users = {1: "Anna", 2: "Max"}
    return users.get(user_id)

def average(values: list[float]) -> float:
    return sum(values) / len(values)

count: int = 0                                  # auch für Variablen möglich

print(area(3, 4.5))
print(find_user(2), find_user(99))
print(average([1.0, 2.0, 4.5]))
python hints.py

Tipps & typische Fehler

  • Nie eine Liste oder ein Dict als Standardwert: def add(item, items=[]) benutzt bei jedem Aufruf dieselbe Liste. Richtig: items=None und in der Funktion if items is None: items = [].
  • return vergessen → die Funktion liefert None. Typischer Folgefehler: TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'.
  • greet ist die Funktion selbst, greet() ruft sie auf. Fehlen die Klammern, passiert nichts.
  • Variablen, die in einer Funktion angelegt werden, sind nur dort sichtbar (lokal). Eine globale Variable in einer Funktion zu ändern braucht global name – besser den Wert als Parameter übergeben und zurückgeben.
  • Listen und Dicts werden als Referenz übergeben: Ändert die Funktion die Liste, ändert sie das Original.
