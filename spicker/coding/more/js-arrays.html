Arrays

Listen von Werten – und die wichtigsten Methoden zum Suchen, Filtern, Umwandeln und Sortieren.

Grundlagen

const fruits = ["Apfel", "Birne", "Kiwi"];

fruits[0];            // "Apfel" – Index beginnt bei 0
fruits.length;        // 3
fruits[fruits.length - 1];   // letztes Element: "Kiwi"
fruits.at(-1);        // auch letztes Element

Methoden verketten

const entries = [
  { tag: "<a>",    lang: "html", link: "a.html" },
  { tag: "for",    lang: "cpp",  link: "" },
  { tag: "<img>",  lang: "html", link: "img.html" }
];

const htmlTags = entries
  .filter(e => e.lang === "html")                 // nur HTML
  .map(e => e.tag)                                // nur die Namen
  .sort((a, b) => a.localeCompare(b, "de"));      // alphabetisch

console.log(htmlTags);   // ["<a>", "<img>"]

Sortieren richtig

[10, 9, 1].sort();                     // [1, 10, 9]  – sortiert als TEXT!
[10, 9, 1].sort((a, b) => a - b);      // [1, 9, 10]  – Zahlen aufsteigend
[10, 9, 1].sort((a, b) => b - a);      // [10, 9, 1]  – absteigend
names.sort((a, b) => a.localeCompare(b, "de"));   // Texte mit Umlauten

reduce – alles zu einem Wert

const prices = [4.5, 10, 2];
const total = prices.reduce((sum, price) => sum + price, 0);   // 16.5
//                           ↑ Zwischenstand  ↑ aktuelles       ↑ Startwert

Tipps & typische Fehler

  • sort() und reverse() verändern das Original – vorher mit [...arr] kopieren, wenn du es noch brauchst.
  • map und filter geben immer ein neues Array zurück.
  • console.table(array) zeigt Arrays von Objekten als übersichtliche Tabelle.
