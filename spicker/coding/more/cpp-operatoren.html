Die Ganzzahl-Falle

int correct = 7;
int total = 9;

double wrong = correct / total;                             // 0 !  (int / int = int)
double right = static_cast<double>(correct) / total;        // 0.777…
double percent = 100.0 * correct / total;                   // 77.7… (100.0 macht es zur Kommazahl)

std::cout << "Falsch: " << wrong << "\n";
std::cout << "Richtig: " << right << "\n";

Sobald eine Seite eine Kommazahl ist, rechnet C++ mit Kommazahlen.

Typumwandlung (Cast)

double price = 9.99;
int rounded = static_cast<int>(price);        // 9 – schneidet ab, rundet nicht!
int proper = static_cast<int>(std::round(price));   // 10 – mit <cmath>

char letter = 'A';
int code = static_cast<int>(letter);          // 65 (ASCII-Code)

// Text ↔ Zahl (mit <string>)
int number = std::stoi("42");                 // string → int
double value = std::stod("3.14");             // string → double
std::string text = std::to_string(42);        // Zahl → string
SchreibweiseBewertung
static_cast<int>(x)Modernes C++ – klar erkennbar, vom Compiler geprüft
(int)xAlter C-Stil – funktioniert, aber unauffällig und weniger sicher

Vorrang (wichtigste Regeln)

  1. Klammern ( )
  2. !, ++, --
  3. *, /, %
  4. +, -
  5. Vergleiche <, >, == …
  6. &&, dann ||
  7. Zuweisung =, += …

Im Zweifel Klammern setzen – das macht den Code auch lesbarer.

Tipps & typische Fehler

  • = weist zu, == vergleicht. if (x = 5) ist immer wahr und ein klassischer Fehler – der Compiler warnt mit -Wall.
  • i++ und ++i sind in einer eigenen Zeile gleich. Innerhalb eines Ausdrucks liefert i++ den alten Wert, ++i den neuen.
  • Überlauf: int hat Grenzen (ca. ±2,1 Milliarden). Für größere Zahlen long long verwenden.
