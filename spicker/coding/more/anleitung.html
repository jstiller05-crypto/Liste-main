So funktioniert der Spicker

Wofür diese Liste da ist, wie sie aufgebaut ist, welche Funktionen sie hat – und wie du am besten damit lernst.

Wofür ist der Spicker?

Der Spicker ist ein persönliches Nachschlagewerk: Alles, was man beim Programmieren gelernt hat, steht an einem Ort – HTML, CSS, JavaScript, TypeScript, C++, C, C#, Node.js, SQL, PHP, Lua, Swift und das Terminal. Dazu kommen die IT-Grundlagen dahinter: wie Computer intern funktionieren, von Bits und Zahlensystemen über Hardware, Betriebssystem und Netzwerk bis zu Protokollen, IT-Sicherheit und sprachunabhängigen Programmier-Grundlagen.

  • Nachschlagen: Schnell die Syntax oder ein Beispiel finden, statt lange im Internet zu suchen.
  • Lernen: Jede Detailseite erklärt ein Thema von Grund auf, mit Beispielen und typischen Fehlern.
  • Fortschritt sehen: Pro Seite speicherst du, wie gut du das Thema schon verstanden hast.

Suchen, filtern und sortieren

  1. Ins Suchfeld klicken – das Filter-Menü klappt darunter auf.
  2. Einen Suchbegriff tippen, z. B. schleife, fetch oder flex.
  3. Optional eine oder mehrere Sprachen oder Bereiche wählen (z. B. HTML + CSS + JavaScript gleichzeitig, oder einen IT-Bereich wie Netzwerk).
  4. Optional eine oder mehrere Kategorien wählen (z. B. Layout, OOP, Daten).
  5. Unter Sortieren nach „Empfohlen“, A – Z, Z – A oder nach Sprache/Bereich wählen.

Alle Filter wirken zusammen: Suche „schleife“ + Sprache „C++“ zeigt nur die C++-Schleifen. Innerhalb einer Gruppe reicht es, wenn einer der gewählten Werte passt (HTML oder CSS oder JS). Ein zweiter Klick auf einen Button wählt ihn wieder ab – ist in einer Gruppe nichts ausgewählt, wird alles gezeigt. Das Menü schließt sich, sobald du woanders hinklickst.

Im Filter „Sprache/Bereich“ stehen hinter den Programmiersprachen jetzt auch IT-Bereiche: IT, Daten, Hardware, System, Netzwerk, Protokolle, Sicherheit und Programmieren – einer davon ausgewählt zeigt nur die IT-Grundlagen-Einträge dieses Bereichs.

Empfohlen ist die Sortierung beim Öffnen der Seite und zeigt die komplette Lernreihenfolge von Stufe 0 bis 90: zuerst der Spicker selbst (Anleitung), dann IT-Grundbegriffe, Daten & Zahlensysteme, Hardware, Betriebssystem, Netzwerk, Protokolle, IT-Sicherheit und Programmier-Grundlagen – zum Schluss die Sprachen-Überblicke, danach alles andere A – Z. So siehst du zuerst die Grundlagen, bevor Detail-Befehle kommen. Sobald du etwas ins Suchfeld tippst, springt die Sortierung automatisch auf A – Z; ist das Suchfeld wieder leer, kommt „Empfohlen“ zurück.

Der Browser merkt sich Suche, Filter, Sortierung und wie weit du gescrollt hast. Wenn du eine Detailseite öffnest und über den Pfeil unten rechts zurückkommst, stehst du wieder an derselben Stelle der Liste.

Tipp: Die Suche findet auch Teile von Wörtern. arr findet also Array, Arrays und arr.map.

  • Darunter: der Zurück-Pfeil zur Liste.

Wo wird die Bewertung gespeichert?

So geöffnetAdresse beginnt mitGespeichert in
Per Doppelklick auf die HTML-Dateifile://dem Browser (localStorage) – nur in diesem Browser auf diesem Rechner
Über den lokalen Serverhttp://localhost:3000einer Datenbank-Datei (data/progress.db) – bleibt erhalten, auch wenn der Browser-Speicher gelöscht wird
Im Internet veröffentlichthttps://…dem Browser (localStorage) des jeweiligen Besuchers

Wer vorher im Browser bewertet hat und dann zum ersten Mal den Server benutzt, verliert nichts: Die alten Werte werden einmalig automatisch in die Datenbank übernommen.

Server starten unter Windows: start.bat im Projektordner doppelklicken. Das Skript startet den Server unsichtbar (falls er nicht schon läuft) und öffnet danach den Spicker im Browser. Mit autostart-install.bat startet er bei jeder Anmeldung automatisch, stop-server.bat beendet ihn.

Server starten unter Linux (oder von Hand unter Windows):

# im Projektordner (dort, wo server.js liegt)
node --version          # muss 22.5 oder neuer sein
node server.js          # Server starten, Strg + C beendet ihn

# dann im Browser öffnen:
# http://localhost:3000/
Der Server braucht keine npm-Pakete – nur Node.js. Er ist nur auf dem eigenen Rechner erreichbar, nicht im Netzwerk.

So lernst du am besten

  1. Einleitung und „Was ist das?“ lesen – erst verstehen, wofür etwas da ist.
  2. Das Beispiel selbst abtippen, nicht kopieren. Beim Tippen merkt man sich die Syntax viel besser. Den Copy-Button erst benutzen, wenn du etwas schnell testen willst.
  3. Vorher raten, dann ausführen: Überlege, was in der Konsole stehen wird – und prüfe es dann.
  4. Etwas verändern: Andere Werte einsetzen, eine Zeile löschen, absichtlich einen Fehler einbauen. Was passiert?
  5. „Tipps & typische Fehler“ als Quiz nutzen: Kannst du erklären, warum das ein Fehler ist?
  6. Unbekannte Begriffe anklicken: Die Smart-Links führen direkt zur Erklärung.
  7. Ehrlich bewerten und die Seite später wieder aufrufen (siehe Tabelle unten).
  8. Selbst etwas bauen: Ein kleines eigenes Projekt mit dem Gelernten zeigt am schnellsten, was noch fehlt.
BewertungBedeutet ungefährWann wiederholen?
0–2Noch nie benutzt, nur überflogenMorgen noch einmal durcharbeiten
3–4Gelesen und grob verstandenIn 2–3 Tagen, dann das Beispiel selbst abtippen

Kurz und oft wiederholen bringt mehr als einmal lange lernen. Lieber jeden Tag 20 Minuten als einmal pro Woche drei Stunden.

Tipps & typische Fehler

  • Das Filter-Menü geht nur auf, solange das Suchfeld (oder etwas im Menü) angeklickt ist – einfach wieder ins Suchfeld klicken.
  • Bewertungen im Browser-Speicher sind weg, wenn du die Browserdaten löschst. Mit dem lokalen Server passiert das nicht.
  • Die Seiten funktionieren auch ohne Internet – alles liegt lokal auf dem Rechner.
  • Entwicklerwerkzeuge öffnen (F12 → Konsole): Dort siehst du genau, was die Seite gerade macht, z. B. [filter], [progress] oder [smart-link].
