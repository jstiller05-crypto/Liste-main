INSERT, UPDATE & DELETE

Datensätze einfügen, ändern und löschen.

INSERT – einfügen

INSERT INTO users (name, email, points)
VALUES ('Max', 'max@example.com', 120);

-- mehrere auf einmal
INSERT INTO users (name, email) VALUES
    ('Anna', 'anna@example.com'),
    ('Tom',  'tom@example.com');     -- points bekommt den DEFAULT-Wert

UPDATE – ändern

UPDATE users
SET points = points + 10,           -- relativ zum alten Wert
    level  = 2
WHERE id = 1;
Ohne WHERE werden ALLE Zeilen geändert. Tipp: Erst mit SELECT … WHERE … prüfen, welche Zeilen getroffen werden, dann dieselbe Bedingung beim UPDATE verwenden.

DELETE – löschen

DELETE FROM users WHERE id = 3;

DELETE FROM users WHERE points = 0 AND created_at < '2025-01-01';
DELETE FROM users; ohne WHERE leert die ganze Tabelle.

Transaktionen – alles oder nichts

BEGIN;                                          -- Transaktion starten
UPDATE accounts SET balance = balance - 50 WHERE id = 1;
UPDATE accounts SET balance = balance + 50 WHERE id = 2;
COMMIT;                                         -- beide Änderungen übernehmen
-- ROLLBACK;                                    -- oder: alles zurücknehmen

Geht zwischendurch etwas schief, sorgt ROLLBACK dafür, dass kein halber Zustand gespeichert wird.

Tipps & typische Fehler

  • Viele Tools (z. B. MySQL Workbench) haben einen „Safe Update Mode“, der UPDATE/DELETE ohne WHERE blockiert.
  • Statt Datensätze wirklich zu löschen, markiert man sie oft nur (deleted_at setzen) – „Soft Delete“.
  • Werte aus Formularen nie direkt in den SQL-Text einbauen, sondern mit Platzhaltern (siehe Sicherheit).
