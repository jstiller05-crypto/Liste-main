Dateien, Ordner & Pfade

Wie Computer Daten dauerhaft ablegen – und wie man eine Datei eindeutig findet, egal auf welchem Betriebssystem.

Datei

Eine Datei (englisch file) ist eine benannte, dauerhaft gespeicherte Ansammlung von Daten auf einem Datenträger (Festplatte, SSD, USB-Stick …) – ein Text, ein Bild, ein Programm oder auch nur ein paar Einstellungen.

Dateiendung

Die Dateiendung ist das Kürzel nach dem letzten Punkt im Dateinamen und verrät (meist) das Dateiformat. Das Betriebssystem nutzt sie, um zu wissen, mit welchem Programm es die Datei öffnen soll.

EndungTypischer Inhalt
.txtreiner Text, ohne Formatierung
.htmleine Webseite (wie diese hier)
.jsonstrukturierte Daten, z. B. für fetch-Antworten
.exeein ausführbares Programm (Windows)
.zipmehrere Dateien komprimiert in einer Datei
Eine Dateiendung ist nur eine ÜBLICHE Abmachung, kein Naturgesetz: Eine Datei bleibt technisch dieselbe, auch wenn man bild.jpg in bild.txt umbenennt – nur weiß dann kein Programm mehr automatisch, was damit gemeint ist.

Ordner / Verzeichnis

Ein Ordner (auch Verzeichnis, englisch directory oder folder) ist ein Container, der Dateien UND weitere Ordner enthalten kann. So entsteht ein Baum aus ineinander verschachtelten Ordnern – ganz oben steht das Wurzelverzeichnis (root), z. B. C:\ unter Windows oder / unter Linux/macOS.

Pfad

Der Pfad ist die Adresse einer Datei oder eines Ordners im Dateibaum.

ArtBedeutungBeispiel
absolutvollständiger Weg ab dem WurzelverzeichnisC:\Dev\liste-main\index.html
relativWeg ausgehend von der AKTUELLEN Datei/Ordner../shared/list.js

Windows trennt Ordner mit einem Backslash \, Linux/macOS (und das Web) mit einem normalen Schrägstrich /. In relativen Pfaden bedeutet .. „einen Ordner nach oben“ – genau das steckt z. B. in diesem Spicker hinter ../shared/core.css: eine Ebene aus more/ heraus, dann in shared/ hinein.

coding/
├── index.html
├── links.js
├── theme.css
└── more/
    └── it-dateien.html   ← diese Seite
        lädt "../../shared/core.css"
             └─┬─┘└───┬───┘
       1x hoch (more→coding) 2x hoch (coding→spicker), dann shared/

Textdatei vs. Binärdatei

Eine Textdatei enthält nur Zeichen, die ein Mensch direkt lesen kann (Buchstaben, Zahlen, Satzzeichen), z. B. .txt, .html oder .json. Eine Binärdatei enthält rohe Bytes, die nur im richtigen Programm einen Sinn ergeben – z. B. ein Bild, eine ausführbare Datei oder eine gepackte .zip. Öffnet man eine Binärdatei in einem Texteditor, sieht man meist nur wirres Zeichenrauschen.

Dateigröße

Die Dateigröße gibt an, wie viel Speicherplatz eine Datei belegt – gemessen in Byte und den größeren Einheiten KB, MB, GB … Was genau ein Byte ist und warum „1000“ dabei nicht immer „1000“ bedeutet, erklärt der nächste Abschnitt des Spickers (Daten & Zahlensysteme).

Tipps & typische Fehler

  • Ein doppelter Klick öffnet eine Datei über ihre Endung – ändert man die Endung, kann das Betriebssystem das falsche Programm vorschlagen.
  • Pfade mit Leerzeichen im Terminal brauchen Anführungszeichen: cd "Meine Dateien" – sonst wird das Leerzeichen als Trenner zwischen zwei Argumenten missverstanden.
  • .. ist IMMER relativ zum aktuellen Ordner gemeint, nicht zu einem festen Ort – derselbe Pfad ../x zeigt aus zwei verschiedenen Ordnern heraus auf zwei verschiedene Ziele.
