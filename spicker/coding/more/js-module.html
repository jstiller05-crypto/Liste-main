Module (import / export)

Code auf mehrere Dateien verteilen und gezielt importieren.

Was ist das?

Wird eine JS-Datei groß, teilt man sie auf. Mit export gibt eine Datei Funktionen oder Werte frei, mit import holt eine andere Datei sie sich.

Beispiel

// mathUtils.js
export function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
export const PI_ROUNDED = 3.14;

// Standard-Export (einer pro Datei)
export default function greet(name) {
  return `Hallo ${name}`;
}
// app.js
import greet, { randomInt, PI_ROUNDED } from "./mathUtils.js";

console.log(greet("Max"));
console.log(randomInt(1, 6));

Im HTML einbinden

<script type="module" src="app.js"></script>

type="module" ist Pflicht. Module laden automatisch wie mit defer.

Tipps & typische Fehler

  • Pfade brauchen ./ und die Endung .js: "./utils.js".
  • Module funktionieren nicht über file:// – einen lokalen Server verwenden (z. B. „Live Server“ in VS Code).
  • Variablen in Modulen sind nicht automatisch global – nur was exportiert wird, ist außen sichtbar.
