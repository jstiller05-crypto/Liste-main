C++

Zeiger (*)

Was ist das?

Ein Zeiger ist eine Variable, die die Speicheradresse einer anderen Variable speichert. Der `*`-Operator wird zur Deklaration und Dereferenzierung verwendet.

Syntax

int *zeiger;                // Deklaration eines Zeigers auf int
zeiger = &variable;         // Adresse von variable in zeiger speichern
int wert = *zeiger;         // Wert auslesen, auf den zeiger zeigt
*zeiger = 42;               // Wert durch Zeiger ändern

Beispiel

#include <iostream>
using namespace std;

int main() {
    int alter = 25;
    int *pAlter;                   // Zeiger auf int deklarieren
    
    pAlter = &alter;               // & = Adresse von 'alter'
    
    cout << "Wert: " << alter << endl;      // 25
    cout << "Adresse: " << pAlter << endl;  // z.B. 0x7fff5fbff8ac
    cout << "Wert via Zeiger: " << *pAlter << endl; // 25
    
    *pAlter = 30;                  // Wert ändern
    cout << "Neuer Wert: " << alter << endl;   // 30
    
    return 0;
}

Wichtige Operatoren

  • & : Address-of Operator (gibt die Adresse)
  • * : Dereference Operator (gibt den Wert an der Adresse)

Wann nutzt man Zeiger?

  • Dynamische Speicherzuweisung (`new` und `delete`)
  • Funktionen mit Referenzen übergeben
  • Arrays und Strings manipulieren
  • Datenstrukturen wie Listen und Bäume

Wichtige Hinweise

  • Null-Zeiger: `int *p = nullptr;` (nicht initialisiert)
  • Zeiger auf Zeiger: `int **pZeiger = &pAlter;`
  • Achte auf Speicherlecks! Mit `new` reservierte Speicher mit `delete` freigeben
