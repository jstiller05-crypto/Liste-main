Map & Set

Nachschlagetabellen mit beliebigen Schlüsseln und Mengen ohne doppelte Werte.

Map

const highscores = new Map();
highscores.set("Max", 120);
highscores.set("Anna", 150);

highscores.get("Max");          // 120
highscores.has("Tom");          // false
highscores.delete("Anna");
highscores.size;                // 1

for (const [name, score] of highscores) {
  console.log(name, score);
}

// Schlüssel dürfen beliebige Werte sein – auch Objekte oder Elemente
const clicks = new Map();
clicks.set(document.body, 0);

Set

const tags = new Set(["html", "css", "html"]);   // Duplikat fällt weg
tags.add("js");
tags.has("css");        // true
tags.delete("html");
tags.size;              // 2

// Duplikate aus einem Array entfernen
const unique = [...new Set([3, 1, 3, 2, 1])];   // [3, 1, 2]

Wann was?

Brauchst du …Nimm
eine geordnete ListeArray
Daten mit festen Feldern (name, age)Objekt
Nachschlagen mit dynamischen Schlüsseln, häufig hinzufügen/löschenMap
eindeutige Werte / „kommt es vor?“ schnell prüfenSet

Tipps & typische Fehler

  • map.size statt .length.
  • Map und Set lassen sich nicht direkt mit JSON.stringify speichern – vorher mit [...map] bzw. [...set] in ein Array umwandeln.
