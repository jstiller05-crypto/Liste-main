Nützliche Browser-APIs

Zwischenablage, Elemente beim Scrollen erkennen, Standort, Vollbild, Teilen und mehr.

Zwischenablage

async function copyText(text) {
  try {
    await navigator.clipboard.writeText(text);
    console.log("[clipboard] kopiert");
  } catch (error) {
    console.error("[clipboard] nicht erlaubt:", error);
  }
}

IntersectionObserver – beim Scrollen einblenden

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add("visible");     // CSS übernimmt die Animation
      observer.unobserve(entry.target);          // nur einmal
    }
  });
}, { threshold: 0.2 });                          // 20 % sichtbar

document.querySelectorAll(".fade-in").forEach(el => observer.observe(el));
.fade-in         { opacity: 0; transform: translateY(20px); transition: 0.5s; }
.fade-in.visible { opacity: 1; transform: none; }

Auch ideal für „Lazy Loading“ oder Endlos-Scrollen – viel effizienter als auf scroll zu hören.

if ("share" in navigator) {
  shareButton.hidden = false;
} else {
  console.info("[share] nicht unterstützt – Button bleibt versteckt");
}

Tipps & typische Fehler

  • Viele APIs (Zwischenablage, Standort, Kamera) funktionieren nur über https:// oder localhost.
  • Berechtigungen nur anfragen, wenn der Nutzer etwas angeklickt hat – nicht beim Laden der Seite.
  • Ob ein Browser eine API kann, steht auf caniuse.com.
