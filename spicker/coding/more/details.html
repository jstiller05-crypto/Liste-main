HTML · Interaktiv

<details>

Ein auf- und zuklappbarer Bereich – ganz ohne JavaScript.

Was ist das?

<details> versteckt seinen Inhalt, bis man auf die Überschrift klickt. Die Überschrift steht im Kind-Element <summary>. Perfekt für FAQs, Spoiler oder „Mehr anzeigen“.

Syntax

<details>
  <summary>Immer sichtbarer Titel</summary>
  Inhalt, der erst nach dem Klick erscheint.
</details>

Beispiel

<details>
  <summary>Lösung anzeigen</summary>
  <p>Die Antwort ist <code>i &lt; 10</code>.</p>
</details>

<details open>
  <summary>Schon geöffnet</summary>
  <p>Dank <code>open</code> ist dieser Bereich von Anfang an offen.</p>
</details>
Lösung anzeigen

Die Antwort ist i < 10.

Wichtige Attribute

AttributBedeutung
openBereich ist von Anfang an geöffnet
nameGleicher Name bei mehreren <details> → nur eines kann gleichzeitig offen sein (Akkordeon)

Mit JavaScript reagieren

const box = document.querySelector("details");
box.addEventListener("toggle", () => {
  console.log("offen?", box.open);   // true oder false
});

Tipps & typische Fehler

  • <summary> muss das erste Kind von <details> sein.
  • Das Dreieck vor dem Titel kannst du per CSS mit summary::marker gestalten oder entfernen (list-style: none).
