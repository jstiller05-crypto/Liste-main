Daten abfragen (SELECT)

Daten lesen, filtern, sortieren und begrenzen.

Grundform

SELECT name, points        -- welche Spalten (* = alle)
FROM users                 -- aus welcher Tabelle
WHERE points > 100         -- welche Zeilen
ORDER BY points DESC       -- Sortierung
LIMIT 10;                  -- wie viele

Die Reihenfolge der Teile ist fest: SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT.

WHERE – filtern

BedingungBeispiel
Vergleichpoints >= 100, name = 'Max', level <> 1 (ungleich)
UND / ODER / NICHTpoints > 50 AND level = 2, NOT done
Bereichpoints BETWEEN 50 AND 100
Listename IN ('Max', 'Anna')
Musteremail LIKE '%@example.com' (% = beliebig viele Zeichen, _ = genau eins)
Leeremail IS NULL / email IS NOT NULL

Sortieren & begrenzen

SELECT * FROM users ORDER BY name;                 -- A–Z
SELECT * FROM users ORDER BY points DESC, name ASC; -- erst Punkte absteigend, dann Name
SELECT * FROM users ORDER BY points DESC LIMIT 3;  -- Top 3
SELECT * FROM users LIMIT 10 OFFSET 20;            -- Seite 3 bei 10 pro Seite

Weitere Helfer

SELECT DISTINCT level FROM users;                 -- jeden Wert nur einmal
SELECT name AS spieler, points * 2 AS doppelt       -- AS = Spalte umbenennen, rechnen
FROM users;

SELECT name,
       CASE WHEN points >= 100 THEN 'Profi' ELSE 'Anfänger' END AS rang
FROM users;

Tipps & typische Fehler

  • SELECT * ist praktisch zum Ausprobieren – im Programm lieber die benötigten Spalten nennen.
  • NULL bedeutet „kein Wert“ und wird mit IS NULL geprüft, nicht mit = NULL.
  • Ob Groß-/Kleinschreibung bei Textvergleichen zählt, hängt von der Datenbank ab.
