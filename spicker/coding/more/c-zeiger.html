Zeiger & Arrays in C

Adressen, Zeiger-Arithmetik und warum Arrays und Zeiger so eng verwandt sind.

Zeiger-Grundlagen

int score = 42;
int *ptr = &score;           /* & = Adresse von score */

printf("%d\n", *ptr);        /* * = Wert an der Adresse → 42 */
*ptr = 50;                   /* ändert score */
printf("%d\n", score);       /* 50 */

int *empty = NULL;           /* zeigt nirgendwohin */
if (empty != NULL) { /* nur dann benutzen */ }

Werte in Funktionen ändern

C kennt keine Referenzen. Soll eine Funktion eine Variable ändern, übergibt man ihre Adresse:

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 1, y = 2;
swap(&x, &y);                /* x = 2, y = 1 */

Arrays und Zeiger

int numbers[5] = {10, 20, 30, 40, 50};
int *p = numbers;             /* Array-Name = Adresse des ersten Elements */

printf("%d\n", p[2]);         /* 30 */
printf("%d\n", *(p + 2));     /* 30 – Zeiger-Arithmetik: 2 Elemente weiter */

/* Arrays an Funktionen: Größe geht verloren → mitgeben! */
int sum(const int *values, size_t count) {
    int total = 0;
    for (size_t i = 0; i < count; i++) {
        total += values[i];
    }
    return total;
}

size_t count = sizeof numbers / sizeof numbers[0];   /* nur hier, im selben Block! */
printf("Summe: %d\n", sum(numbers, count));

Tipps & typische Fehler

  • sizeof auf einen Array-Parameter in einer Funktion liefert die Größe des Zeigers, nicht des Arrays – deshalb die Länge mitgeben.
  • Nicht initialisierte Zeiger zeigen irgendwohin. Immer mit einer Adresse oder NULL starten.
  • Die Grundlagen sind wie in C++ – siehe auch die C++-Seite zu Zeigern.
