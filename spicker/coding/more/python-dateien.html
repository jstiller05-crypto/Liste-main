Dateien & JSON

Textdateien mit open und with lesen und schreiben, Pfade mit pathlib bauen und Daten als JSON speichern.

Was ist das?

Variablen leben nur, solange das Programm läuft. Was bleiben soll – Einstellungen, Spielstände, Messwerte – schreibt man in eine Datei. Python öffnet sie mit open(); der with-Block sorgt dafür, dass sie am Ende sicher wieder geschlossen wird.

open mit with

# Aufbau
with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()
# hier ist die Datei schon wieder geschlossen – auch nach einem Fehler
ModusBedeutungDatei fehltDatei existiert
"r"lesen (Standard)Fehlerwird gelesen
"w"schreibenwird angelegtwird geleert!
"a"anhängen (append)wird angelegtText kommt ans Ende
"x"neu anlegenwird angelegtFehler
"rb" / "wb"Binärdaten (Bilder …)wie r / w, aber ohne Text-Kodierung

Schreiben

# write_file.py
lines = ["Erste Zeile", "Zweite Zeile", "Dritte Zeile"]

with open("notes.txt", "w", encoding="utf-8") as file:
    for line in lines:
        file.write(line + "\n")         # write() macht KEINEN Zeilenumbruch selbst

with open("notes.txt", "a", encoding="utf-8") as file:
    file.write("Angehängt\n")           # "a" = ans Ende schreiben

print("notes.txt geschrieben")
python write_file.py
cat notes.txt        # Inhalt im Terminal anzeigen

Lesen

# read_file.py  (vorher write_file.py ausführen)

# 1) Alles auf einmal als ein Text
with open("notes.txt", encoding="utf-8") as file:
    content = file.read()
print(content)

# 2) Zeile für Zeile – braucht auch bei riesigen Dateien wenig Speicher
with open("notes.txt", encoding="utf-8") as file:
    for number, line in enumerate(file, start=1):
        print(number, line.rstrip())    # rstrip entfernt das \n am Zeilenende

# 3) Alle Zeilen als Liste
with open("notes.txt", encoding="utf-8") as file:
    lines = file.read().splitlines()
print(len(lines), "Zeilen")
python read_file.py

pathlib – Pfade bequem

Das Modul pathlib behandelt Pfade als Objekte statt als Text. Mit / setzt man Teile zusammen – das funktioniert auf Linux und Windows gleich.

# paths.py
from pathlib import Path

home = Path.home()                      # /home/benutzername
folder = Path("data")                   # relativer Pfad (zum aktuellen Ordner)
file_path = folder / "scores.txt"       # data/scores.txt

folder.mkdir(exist_ok=True)             # Ordner anlegen, kein Fehler falls vorhanden
file_path.write_text("Anna 150\nMax 120\n", encoding="utf-8")

print(file_path.exists())               # True
print(file_path.read_text(encoding="utf-8"))
print(file_path.name)                   # scores.txt
print(file_path.stem)                   # scores
print(file_path.suffix)                 # .txt
print(file_path.parent)                 # data
print(file_path.resolve())              # absoluter Pfad

for path in folder.glob("*.txt"):       # alle .txt-Dateien im Ordner
    print(path, path.stat().st_size, "Bytes")

# Ordner, in dem DIESES Skript liegt (unabhängig davon, von wo man es startet)
script_folder = Path(__file__).parent
print(script_folder)
python paths.py

Das json-Modul

JSON passt fast 1:1 auf Python: Objekt ↔ dict, Array ↔ list, true/false/null ↔ True/False/None.

# save_json.py
import json
from pathlib import Path

settings = {
    "name": "Anna",
    "volume": 0.8,
    "fullscreen": True,
    "recent": ["level1", "level2"],
    "last_save": None,
}
file_path = Path("settings.json")

# Schreiben: dict -> JSON-Datei
with open(file_path, "w", encoding="utf-8") as file:
    json.dump(settings, file, indent=2, ensure_ascii=False)
    # indent=2           -> schön eingerückt
    # ensure_ascii=False -> Umlaute bleiben lesbar (ä statt ä)

# Lesen: JSON-Datei -> dict
with open(file_path, encoding="utf-8") as file:
    loaded = json.load(file)

print(loaded["name"], loaded["recent"][0])

# Dasselbe mit Text statt Datei: dumps / loads (s = string)
text = json.dumps({"points": 10})
print(text)                             # {"points": 10}
print(json.loads('{"ok": true}'))       # {'ok': True}
python save_json.py
cat settings.json

Tipps & typische Fehler

  • Immer encoding="utf-8" angeben – sonst gibt es Ärger mit Umlauten, sobald das Skript auf einem anderen System läuft.
  • "w" löscht den bisherigen Inhalt sofort beim Öffnen. Zum Ergänzen "a" nehmen.
  • FileNotFoundError – relative Pfade gelten ab dem Ordner, in dem man python gestartet hat, nicht ab dem Ordner des Skripts. Abhilfe: Path(__file__).parent / "datei.txt".
  • PermissionError – keine Schreibrechte im Ordner (z. B. /etc). Im eigenen Home-Ordner arbeiten.
  • json.decoder.JSONDecodeError – die Datei ist kein gültiges JSON (oft: Komma am Ende, einfache Anführungszeichen). Siehe JSON-Syntax.
  • JSON kennt keine Tupel und Sets: Ein Tupel kommt als Liste zurück, ein Set muss man vorher in eine Liste umwandeln.
