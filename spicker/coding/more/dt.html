<dt>

Der Begriff in einer Beschreibungsliste (<dl>).

Was ist das?

<dt> (description term) ist der Begriff, der erklärt wird. Die Erklärung folgt im nächsten <dd>. <dt> steht immer innerhalb von <dl>.

Beispiel

<dl>
  <dt>HTML</dt>
  <dd>Beschreibt die Struktur einer Webseite.</dd>

  <dt>CSS</dt>
  <dd>Bestimmt das Aussehen.</dd>

  <dt>JavaScript</dt>
  <dt>JS</dt>                      <!-- mehrere Begriffe … -->
  <dd>Macht die Seite interaktiv.</dd>  <!-- … eine Beschreibung -->
</dl>
HTML
Beschreibt die Struktur einer Webseite.
CSS
Bestimmt das Aussehen.

Tipps & typische Fehler

  • Browser zeigen <dt> normal an. Mit dt { font-weight: bold; } hebst du die Begriffe hervor.
