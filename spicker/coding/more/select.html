HTML · Formulare

<select>

Ein Auswahlmenü (Dropdown), aus dem man eine oder mehrere Optionen wählt.

Was ist das?

<select> enthält <option>-Einträge. Abgeschickt bzw. in JavaScript ausgelesen wird der value der gewählten Option.

Beispiel

<label for="country">Land</label>
<select id="country" name="country">
  <option value="">– bitte wählen –</option>
  <option value="de">Deutschland</option>
  <option value="at">Österreich</option>
  <option value="ch">Schweiz</option>
</select>

Wichtige Attribute

AttributBedeutung
nameName beim Abschicken
multipleMehrfachauswahl (mit Strg/Shift)
sizeAnzahl sichtbarer Zeilen – dann Liste statt Dropdown
requiredPflichtfeld – funktioniert mit einer ersten Option value=""
disabledGanzes Menü deaktiviert

Mit JavaScript

const select = document.getElementById("country");

// Auswahl lesen, sobald sie sich ändert
select.addEventListener("change", () => {
  console.log("Wert:", select.value);                               // "de"
  console.log("Text:", select.options[select.selectedIndex].text);  // "Deutschland"
});

// Auswahl per Code setzen
select.value = "at";

// Option hinzufügen
select.add(new Option("Liechtenstein", "li"));

Aussehen anpassen (CSS)

select {
  padding: 8px 12px;
  border: 1px solid #444;
  border-radius: 8px;
  background: #2b2b2b;
  color: #f2f2f2;
}

Tipps & typische Fehler

  • Beim Ereignis change reagieren, nicht bei click.
  • Die aufgeklappte Liste zeichnet das Betriebssystem – sie lässt sich kaum gestalten.
  • Viele Optionen? Mit <optgroup> gruppieren oder ein Eingabefeld mit <datalist> anbieten.
