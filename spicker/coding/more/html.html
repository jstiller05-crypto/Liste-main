HTML · Grundgerüst

<html>

Das Wurzelelement: Es umschließt die komplette HTML-Seite.

Was ist das?

Alles außer der <!DOCTYPE html>-Zeile steht innerhalb von <html>. Darin gibt es genau zwei Kinder: <head> und <body>.

Grundgerüst einer Seite

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="utf-8">
  <title>Meine Seite</title>
</head>
<body>
  <h1>Hallo Welt</h1>
</body>
</html>

Wichtige Attribute

AttributBedeutung
langSprache der Seite, z. B. de oder en. Wichtig für Screenreader, Silbentrennung und Übersetzer

Tipps & typische Fehler

  • <!DOCTYPE html> gehört immer in die erste Zeile – sonst schaltet der Browser in einen alten Kompatibilitätsmodus.
  • lang nie vergessen.
