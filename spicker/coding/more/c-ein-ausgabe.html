printf & scanf

Formatierte Ausgabe und Eingabe mit Platzhaltern.

printf – ausgeben

#include <stdio.h>

int main(void) {
    int age = 17;
    double price = 9.5;
    char grade = 'A';
    const char *name = "Max";

    printf("Name: %s\n", name);
    printf("Alter: %d Jahre\n", age);
    printf("Preis: %.2f Euro\n", price);       /* 2 Nachkommastellen */
    printf("Note: %c\n", grade);
    printf("%s ist %d und hat Note %c\n", name, age, grade);
    return 0;
}

scanf – einlesen

int age;
printf("Alter: ");
if (scanf("%d", &age) != 1) {          /* & = Adresse der Variable übergeben! */
    fprintf(stderr, "Ungültige Eingabe\n");
    return 1;
}

char name[50];
printf("Name: ");
scanf("%49s", name);                   /* bei Arrays kein & · 49 = max. Zeichen (Platz für \0) */

scanf gibt zurück, wie viele Werte erfolgreich gelesen wurden – immer prüfen.

Ganze Zeile sicher lesen

char line[100];
if (fgets(line, sizeof line, stdin) != NULL) {
    line[strcspn(line, "\n")] = '\0';     /* Zeilenumbruch entfernen (string.h) */
    printf("Gelesen: %s\n", line);
}

Tipps & typische Fehler

  • Falscher Platzhalter (%d für double) gibt Unsinn aus – der Compiler warnt mit -Wall.
  • Bei scanf das & vor normalen Variablen nicht vergessen.
  • Fehlermeldungen mit fprintf(stderr, …) ausgeben – dem C-Gegenstück zu std::cerr.
