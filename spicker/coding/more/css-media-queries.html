Media Queries & Responsive Design

Unterschiedliches CSS je nach Bildschirmgröße – damit die Seite auf Handy und PC gut aussieht.

Was ist das?

Eine Media Query ist eine Bedingung: Die Regeln darin gelten nur, wenn sie zutrifft – z. B. „Fenster schmaler als 600px“.

Syntax

@media (max-width: 600px) {
  /* gilt nur bis 600px Breite */
  .sidebar { display: none; }
}

Mobile First

Gängige Methode: Erst für kleine Bildschirme schreiben, dann mit min-width für größere erweitern.

/* Standard: Handy – alles untereinander */
.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* ab Tablet: 2 Spalten */
@media (min-width: 600px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}

/* ab Desktop: 4 Spalten */
@media (min-width: 1000px) {
  .cards { grid-template-columns: repeat(4, 1fr); }
}

Weitere Bedingungen

(min-width: 1000px)Fenster mindestens 1000px breit
(orientation: portrait)Hochformat
(prefers-color-scheme: dark)Nutzer hat Dark Mode eingestellt
(prefers-reduced-motion: reduce)Nutzer möchte weniger Animationen
(hover: hover)Gerät hat eine Maus (kein Touch)
printBeim Drucken
 
@media (min-width: 600px) and (max-width: 999px) { … }   /* beides */

Pflicht im HTML

<meta name="viewport" content="width=device-width, initial-scale=1">

Ohne diese Zeile tut das Handy so, als wäre es ein breiter Bildschirm – und Media Queries greifen nicht.

Tipps & typische Fehler

  • Breakpoints nach dem Inhalt wählen: Dort, wo das Layout „bricht“, nicht nach bestimmten Geräten.
  • In den Entwicklertools (F12 → Handy-Symbol) kannst du verschiedene Bildschirmgrößen testen.
  • Viel Responsivität geht auch ohne Media Queries: flex-wrap, auto-fill, minmax(), clamp().
