position & z-index

Elemente verschieben, übereinanderlegen, an den Bildschirm heften oder beim Scrollen festkleben.

Die Werte von position

WertVerhaltenBezugspunkt für top/left …
staticStandard – normaler Fluss, top/left wirken nicht–
relativeBleibt im Fluss, lässt sich aber verschiebenEigene ursprüngliche Position
absoluteAus dem Fluss genommen, schwebtNächstes Eltern-Element mit position ≠ static
fixedKlebt am Bildschirm, scrollt nicht mitBrowserfenster
stickyNormal, bis es beim Scrollen eine Kante erreicht – dann klebt esScroll-Container

Beispiel: Badge oben rechts an einer Karte

.card {
  position: relative;        /* Bezugspunkt für das Kind */
}

.card .badge {
  position: absolute;
  top: 8px;
  right: 8px;
}

Weitere Beispiele

/* Header bleibt beim Scrollen oben */
header {
  position: sticky;
  top: 0;
  z-index: 100;
}

/* Button immer unten rechts im Fenster */
.back-to-top {
  position: fixed;
  right: 16px;
  bottom: 16px;
}

/* Overlay über die ganze Seite */
.overlay {
  position: fixed;
  inset: 0;                  /* Kurzform für top/right/bottom/left: 0 */
  background: rgb(0 0 0 / 60%);
}

z-index – Was liegt oben?

Überlappen sich Elemente, liegt das mit dem höheren z-index oben. z-index wirkt nur bei Elementen mit position (außer static) sowie bei Flex-/Grid-Kindern.

Tipps & typische Fehler

  • absolute ohne positioniertes Eltern-Element bezieht sich auf die ganze Seite – dann landet es oft „irgendwo“.
  • sticky braucht immer einen Wert wie top: 0, sonst klebt nichts.
  • Für normales Layout lieber Flexbox/Grid nutzen – absolute nur für Überlagerungen.
