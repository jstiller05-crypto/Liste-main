HTML · Struktur

Container (<div> & Co.)

Container fassen andere Elemente zusammen – für Struktur, Layout und Styling.

Was ist das?

Ein Container ist ein Element, das andere Elemente umschließt. Es gibt zwei Arten:

  • Semantische Container sagen, was drin ist: <header>, <main>, <footer>, <nav>, <article>, <section>, <aside>.
  • Neutrale Container haben keine Bedeutung: <div> (Block) und <span> (im Text).

Beispiel

<main>
  <section>
    <h2>Neueste Einträge</h2>
    <div class="card-grid">      <!-- div nur fürs Layout -->
      <div class="card">Karte 1</div>
      <div class="card">Karte 2</div>
      <div class="card">Karte 3</div>
    </div>
  </section>
</main>

<section> und <span>

<section> ist ein thematischer Abschnitt, der eine eigene Überschrift hat – wie ein Kapitel. <span> ist das Gegenstück zu <div> für einzelne Wörter im Text, z. B. um sie per CSS oder JavaScript anzusprechen.

<section>
  <h2>Kapitel 1: Grundlagen</h2>
  <p>Der Preis beträgt <span class="price">19,99 €</span>.</p>
</section>

Layout mit CSS

/* Flexbox: Elemente in einer Reihe */
.card-row {
  display: flex;
  gap: 16px;
}

/* Grid: Elemente in einem Raster */
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* 3 gleich breite Spalten */
  gap: 16px;
}

Welcher Container?

ElementWann?
<header> / <footer>Kopf- bzw. Fußbereich
<main>Hauptinhalt (einmal pro Seite)
<nav>Navigationslinks
<article>Eigenständiger Inhalt
<section>Thematischer Abschnitt mit Überschrift
<aside>Randinfos
<div>Nur Layout/Styling, wenn nichts anderes passt
<span>Wie div, aber mitten im Text

Tipps & typische Fehler

  • Erst überlegen, ob ein semantischer Container passt – <div> ist der letzte Ausweg.
  • Zu viele verschachtelte <div>s („div-Suppe“) machen den Code schwer lesbar.
