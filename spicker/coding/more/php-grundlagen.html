Variablen, Datentypen & Ausgabe

Variablen mit $, Texte zusammensetzen, rechnen und Werte ausgeben.

Variablen

<?php
$name = "Max";          // Variablen beginnen immer mit $
$age = 17;
$price = 9.99;
$isActive = true;
$nothing = null;

const MAX_LEVEL = 10;   // Konstante (ohne $)

echo $name;             // Ausgabe
var_dump($price);       // Typ und Wert anzeigen: float(9.99) – zum Debuggen

Strings

$name = "Max";

echo "Hallo $name!";          // doppelte Anführungszeichen: Variablen werden ersetzt
echo 'Hallo $name!';          // einfache: bleibt wörtlich "$name"
echo "Hallo " . $name . "!";  // . verbindet Texte (nicht +!)
echo "Punkte: {$user['points']}";   // komplexe Ausdrücke in { }

strlen($name);                // 3
strtoupper($name);            // "MAX"
str_contains($name, "a");     // true (PHP 8)
trim("  Hi  ");               // "Hi"
explode(",", "a,b,c");        // ["a", "b", "c"]
implode(", ", ["a", "b"]);    // "a, b"

Tipps & typische Fehler

  • Das $ nie vergessen – name ohne $ ist keine Variable.
  • Texte werden mit . verbunden. + würde versuchen zu rechnen.
  • var_dump() und print_r() sind die wichtigsten Werkzeuge zur Fehlersuche.
