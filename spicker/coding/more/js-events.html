Events

Auf Klicks, Eingaben, Tasten und mehr reagieren.

Grundprinzip

const button = document.querySelector("#saveBtn");

button.addEventListener("click", (event) => {
  console.log("Geklickt!", event);
});
//                      ↑ Ereignis  ↑ Funktion, die dann ausgeführt wird

Häufige Events

EventWann?
clickKlick (auch Enter/Leertaste auf Buttons)
inputBei jeder Änderung in einem Feld (jeder Tastendruck)
changeFeld verlassen bzw. Auswahl geändert (select, checkbox)
submitFormular wird abgeschickt
keydown / keyupTaste gedrückt / losgelassen
mouseenter / mouseleaveMaus kommt / geht
focus / blurElement bekommt / verliert Fokus
scrollSeite oder Element wird gescrollt
DOMContentLoadedHTML ist fertig geladen
loadAlles inkl. Bilder ist geladen

Das Event-Objekt

document.addEventListener("keydown", (event) => {
  console.log(event.key);           // z. B. "Enter", "a", "Escape"
  if (event.key === "Escape") closeMenu();
  if (event.ctrlKey && event.key === "s") {
    event.preventDefault();         // Browser-Standard (Speichern-Dialog) verhindern
    save();
  }
});

form.addEventListener("submit", (event) => {
  event.preventDefault();           // Seite NICHT neu laden
});
Eigenschaft/MethodeBedeutung
event.targetElement, auf das tatsächlich geklickt wurde
event.currentTargetElement, an dem der Listener hängt
event.keyGedrückte Taste
event.preventDefault()Standardverhalten verhindern (Link folgen, Formular senden)
event.stopPropagation()Event nicht an Eltern weitergeben

Event Delegation – ein Listener für viele Elemente

// Statt jedem Button einen Listener zu geben:
document.querySelector(".toolbar").addEventListener("click", (event) => {
  const button = event.target.closest("button");   // welcher Button?
  if (!button) return;                             // Klick daneben
  console.log("Aktion:", button.dataset.action);
});

Funktioniert auch für Elemente, die erst später per JavaScript hinzukommen.

Listener entfernen

function onScroll() { … }
window.addEventListener("scroll", onScroll);
window.removeEventListener("scroll", onScroll);   // gleiche Funktion übergeben

button.addEventListener("click", handler, { once: true });   // nur einmal auslösen

Tipps & typische Fehler

  • Funktion ohne () übergeben: addEventListener("click", save) – mit Klammern läuft sie sofort.
  • onclick="…" im HTML funktioniert, addEventListener ist aber sauberer und erlaubt mehrere Listener.
  • Bei Such-Feldern input nehmen, bei <select> und Checkboxen change.
