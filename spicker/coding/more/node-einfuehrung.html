Node.js · Grundlagen

Node.js

JavaScript außerhalb des Browsers – für Server, Kommandozeilen-Tools und Automatisierung.

Was ist das?

Node.js ist eine Laufzeitumgebung, die JavaScript direkt auf dem Computer ausführt – ohne Browser. Damit baut man Webserver, APIs, Build-Tools oder kleine Skripte. Die Sprache ist dieselbe JavaScript, das du schon kennst.

Browser-JS vs. Node.js

BrowserNode.js
Läuft …in der Webseiteauf dem Computer/Server
Hat document, window, DOMJaNein
Dateien lesen/schreibenNeinJa (fs)
Server startenNeinJa (http, Express)
Paketeper <script>per npm
Globales ObjektwindowglobalThis / process

Installieren & prüfen

Die LTS-Version (Long Term Support) installieren. npm wird automatisch mitinstalliert.

SystemInstallation
WindowsInstaller von nodejs.org oder winget install OpenJS.NodeJS.LTS
Linux (Debian/Ubuntu)sudo apt install nodejs npm – oft ältere Version; aktueller über nvm: nvm install --lts
 
node -v      # Version von Node.js anzeigen, z. B. v22.x
npm -v       # Version von npm

Erstes Programm

// hello.js
const name = "Welt";
console.log(`Hallo ${name}!`);
console.log("Node-Version:", process.version);
node hello.js          # ausführen
node --watch hello.js  # bei jeder Änderung automatisch neu starten

REPL – Node interaktiv

node               # ohne Datei: interaktive Konsole
> 2 + 3
5
> .exit            # beenden (oder zweimal Strg+C)

Wofür wird Node.js genutzt?

  • Webserver und REST-APIs (oft mit Express)
  • Echtzeit-Anwendungen wie Chats (WebSockets)
  • Build-Werkzeuge für Frontends (Vite, Webpack …)
  • Kommandozeilen-Tools und Automatisierung
  • Desktop-Apps mit Electron (z. B. VS Code)

Tipps & typische Fehler

  • Alles, was du über JavaScript-Grundlagen weißt (Variablen, Arrays, Funktionen, async/await), gilt 1:1 in Node.
  • Fehler wie „document is not defined“ bedeuten: Browser-Code läuft in Node – dort gibt es kein DOM.
  • Im Terminal von VS Code (Strg+ö) kannst du Node-Befehle direkt ausführen.
