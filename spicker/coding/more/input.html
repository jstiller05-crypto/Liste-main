HTML · Formulare

<input>

Das vielseitigste Formularelement: Textfeld, Checkbox, Datum, Farbe, Schieberegler und mehr – je nach type.

Was ist das?

<input> ist ein leeres Element (kein End-Tag). Was es darstellt, bestimmt das Attribut type. Ohne type ist es ein normales Textfeld.

Syntax

<input type="text" id="username" name="username" placeholder="Dein Name">

Die wichtigsten Typen

typeErgebnis
textEinzeiliges Textfeld (Standard)
passwordText wird als Punkte angezeigt
emailPrüft auf gültige E-Mail, Handy zeigt @-Tastatur
numberNur Zahlen, mit Pfeilen zum Hoch-/Runterzählen
checkboxHäkchen – mehrere wählbar
radioAuswahlpunkt – nur einer aus der Gruppe (gleicher name)
rangeSchieberegler
date / timeDatums- bzw. Uhrzeitauswahl
colorFarbwähler
fileDatei hochladen
searchSuchfeld (mit Löschen-Kreuz)
submitAbsende-Button (besser: <button type="submit">)

Beispiele

<input type="text" placeholder="Suchen …">
<input type="number" min="1" max="10" value="5">
<input type="range" min="0" max="100" value="30">
<input type="color" value="#4f8cff">
<input type="date">

<label><input type="checkbox" checked> Newsletter</label>

<label><input type="radio" name="level" value="anfaenger" checked> Anfänger</label>
<label><input type="radio" name="level" value="profi"> Profi</label>

Wichtige Attribute

AttributBedeutung
nameName, unter dem der Wert abgeschickt wird
valueAktueller bzw. Startwert
placeholderGrauer Hinweistext, solange das Feld leer ist
requiredPflichtfeld – Formular geht ohne Eingabe nicht raus
disabledFeld ist ausgegraut und wird nicht abgeschickt
readonlyNur lesen, aber wird abgeschickt
min / max / stepGrenzen und Schrittweite bei Zahlen, Datum, Range
maxlengthMaximale Anzahl Zeichen
patternRegex, die die Eingabe erfüllen muss
autocompleteBrowser-Vorschläge, z. B. off oder email
listID einer <datalist> mit Vorschlägen

Wert mit JavaScript lesen

So reagierst du auf jede Eingabe, z. B. für eine Live-Suche:

const input = document.getElementById("searchInput");

input.addEventListener("input", () => {   // bei jedem Tastendruck
  console.log("Eingabe:", input.value);
});

// Checkbox: nicht .value, sondern .checked
const box = document.querySelector('input[type="checkbox"]');
console.log("angehakt?", box.checked);    // true / false

Tipps & typische Fehler

  • placeholder ersetzt kein <label> – der Hinweis verschwindet, sobald man tippt.
  • Radio-Buttons gehören nur dann zusammen, wenn sie denselben name haben.
  • input.value ist immer ein Text (String) – auch bei type="number". Zum Rechnen mit Number(input.value) umwandeln.
