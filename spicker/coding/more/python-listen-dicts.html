Listen, Tupel, Dicts & Sets

Die vier eingebauten Sammlungen – dazu Slicing und List Comprehensions, mit denen man Listen in einer Zeile baut.

Was ist das?

Sammlungen speichern mehrere Werte unter einem Namen. Python hat vier eingebaute – man erkennt sie an den Klammern:

TypSchreibweiseEigenschaftenIn C++ / JS / Lua
list[1, 2, 3]geordnet, veränderbarstd::vector / Array / Tabelle
tuple(1, 2, 3)geordnet, nicht veränderbarstd::tuple / – / –
dict{"a": 1}Schlüssel → Wertstd::map / Objekt, Map / Tabelle
set{1, 2, 3}ohne Doppelte, ohne Reihenfolgestd::set / Set / –

list – Liste

# lists.py
fruits = ["Apfel", "Birne", "Kiwi"]

print(fruits[0])                # Apfel  – Index beginnt bei 0
print(fruits[-1])               # Kiwi   – negativer Index zählt von hinten
print(len(fruits))              # 3

fruits.append("Mango")          # hinten anhängen
fruits.insert(1, "Zitrone")     # an Position 1 einfügen
fruits.remove("Birne")          # ersten Treffer mit diesem Wert entfernen
last = fruits.pop()             # letztes Element entfernen und zurückgeben
fruits[0] = "Ananas"            # Element ersetzen

print("Kiwi" in fruits)         # True – ist der Wert enthalten?
print(fruits.index("Kiwi"))     # Position des Werts

fruits.sort()                   # sortiert die Liste SELBST (gibt None zurück)
print(fruits)
print(sorted(fruits, reverse=True))   # neue Liste, Original bleibt

numbers = [3, 1, 2]
print(sum(numbers), min(numbers), max(numbers))
print(numbers + [9, 8])         # Listen verbinden
print([0] * 5)                  # [0, 0, 0, 0, 0]

Slicing – Ausschnitte

liste[start:ende] liefert einen Ausschnitt als neue Liste. Der Start zählt mit, das Ende nicht – wie bei range(). Funktioniert genauso bei Text und Tupeln.

# slicing.py
letters = ["a", "b", "c", "d", "e", "f"]

print(letters[1:4])     # ['b', 'c', 'd']  – Index 1 bis 3
print(letters[:2])      # ['a', 'b']       – von Anfang an
print(letters[3:])      # ['d', 'e', 'f']  – bis zum Ende
print(letters[-2:])     # ['e', 'f']       – die letzten zwei
print(letters[::2])     # ['a', 'c', 'e']  – jedes zweite (Schrittweite 2)
print(letters[::-1])    # umgekehrte Reihenfolge
copy = letters[:]       # flache Kopie der ganzen Liste

print("Python"[0:3])    # Pyt

tuple – Tupel

Ein Tupel ist eine Liste, die man nach dem Anlegen nicht mehr ändern kann. Gut für Werte, die zusammengehören: Koordinaten, RGB-Farben, mehrere Rückgabewerte.

# tuples.py
point = (3, 5)
print(point[0])             # 3

x, y = point                # auspacken (unpacking)
print(x, y)

single = (42,)              # Tupel mit EINEM Element braucht das Komma
print(type(single))

try:
    point[0] = 10           # Tupel sind unveränderbar
except TypeError as error:
    print("Fehler:", error)

dict – Wörterbuch

# dicts.py
player = {
    "name": "Max",
    "level": 3,
    "items": ["Schwert", "Brot"],
}

print(player["name"])               # Max
player["health"] = 20               # neuer Eintrag
player["level"] += 1                # Wert ändern
del player["items"]                 # Eintrag löschen

# Fehlt der Schlüssel, wirft [] einen KeyError – get() nicht
print(player.get("mana"))           # None
print(player.get("mana", 0))        # 0 als Ersatzwert

print("name" in player)             # True – prüft die SCHLÜSSEL

for key, value in player.items():   # Schlüssel und Wert zusammen
    print(key, "=", value)

print(list(player.keys()))          # alle Schlüssel
print(list(player.values()))        # alle Werte

set – Menge

# sets.py
tags = {"python", "linux", "python"}    # Doppelte verschwinden
print(tags)                              # {'python', 'linux'}

tags.add("git")
tags.discard("linux")                    # entfernen (kein Fehler, falls nicht da)
print("git" in tags)                     # True – sehr schnell, auch bei vielen Werten

a = {1, 2, 3}
b = {3, 4}
print(a | b)        # Vereinigung   {1, 2, 3, 4}
print(a & b)        # Schnittmenge  {3}
print(a - b)        # Differenz     {1, 2}

# Häufigster Einsatz: Doppelte aus einer Liste entfernen
names = ["Anna", "Max", "Anna"]
print(list(set(names)))

empty_set = set()   # ACHTUNG: {} ist ein leeres dict, kein Set

List Comprehensions

Eine Comprehension baut eine neue Liste aus einer vorhandenen – in einer Zeile. Aufbau: [ausdruck for element in folge if bedingung]. Entspricht map und filter in JavaScript.

# comprehension.py
numbers = [1, 2, 3, 4, 5, 6]

# Lange Form mit Schleife …
squares = []
for n in numbers:
    squares.append(n * n)

# … und dasselbe als Comprehension
squares = [n * n for n in numbers]
print(squares)                              # [1, 4, 9, 16, 25, 36]

even = [n for n in numbers if n % 2 == 0]   # filtern
print(even)                                 # [2, 4, 6]

names = ["anna", "max"]
print([name.capitalize() for name in names])

# Geht auch für dict und set
lengths = {name: len(name) for name in names}
print(lengths)                              # {'anna': 4, 'max': 3}

Tipps & typische Fehler

  • b = a kopiert eine Liste nicht – beide Namen zeigen auf dieselbe Liste. Kopie: b = a.copy() oder b = a[:].
  • items = items.sort() macht aus der Liste None, weil sort() nichts zurückgibt.
  • IndexError: list index out of range – Index zu groß. Eine Liste mit 3 Elementen hat die Indizes 0, 1, 2.
  • KeyError – Schlüssel fehlt im Dict. Mit in prüfen oder get() nehmen.
  • Dict-Schlüssel müssen unveränderbar sein: Text, Zahl oder Tupel – keine Liste.
  • Comprehensions kurz halten. Braucht man zwei Zeilen zum Verstehen, ist eine normale Schleife besser.
