Array

Ein Array speichert mehrere Werte hintereinander, jeder direkt über seinen Index (0, 1, 2 …) erreichbar – dadurch sehr schneller Zugriff auf ein bestimmtes Element.

std::vector<int> v;let arr = [];local t = {}

Verkettete Liste

Eine verkettete Liste besteht aus Knoten, die jeweils einen Verweis auf den NÄCHSTEN Knoten halten, statt wie ein Array zusammenhängend im Speicher zu liegen. Einfügen/Löschen mitten in der Liste ist dadurch günstig – dafür ist der direkte Zugriff per Index langsamer, weil man sich erst Knoten für Knoten durchhangeln muss.

C++JavaScriptLua
std::list<int> (eingebaut)nicht eingebaut – selbst bauen oder Array nutzennicht eingebaut – selbst bauen oder Table nutzen

Stack

Ein Stack funktioniert nach dem Prinzip LIFO (Last In, First Out) – wie ein Stapel Teller: Man legt oben drauf und nimmt auch wieder von oben.

C++JavaScriptLua
std::stack<int>Array: push() / pop()Table: table.insert/table.remove am Ende

Queue

Eine Queue (Warteschlange) funktioniert nach FIFO (First In, First Out) – wer zuerst kommt, wird zuerst bedient.

C++JavaScriptLua
std::queue<int>Array: push() / shift()Table: table.insert/table.remove(t,1)

Baum

Ein Baum ist eine hierarchische Struktur aus Knoten: ein Wurzelknoten ganz oben, jeder Knoten kann beliebig viele Kindknoten haben (bei einem Binärbaum maximal zwei). Praktisch überall, wo Dinge natürlich verschachtelt sind – von Dateisystemen bis zu HTML-Elementen im DOM.

Hash-Tabelle

Eine Hash-Tabelle speichert Schlüssel-Wert-Paare und berechnet aus dem Schlüssel per Hash-Funktion (siehe Sicherheits-Teil des Spickers) direkt eine Speicherposition – dadurch im Schnitt SEHR schneller Zugriff, ohne alles durchsuchen zu müssen.

C++JavaScriptLua
std::map / std::unordered_mapMapTable – ist in Lua direkt eine Hash-Tabelle!

Tipps & typische Fehler

  • Es gibt keine „beste“ Datenstruktur – die Wahl hängt davon ab, was man am häufigsten tut: schneller Index-Zugriff (Array), oft Einfügen/Löschen (verkettete Liste), Verarbeitung in fester Reihenfolge (Stack/Queue) oder schnelles Nachschlagen (Hash-Tabelle).
  • Eine Lua-Table ist ungewöhnlich flexibel: Sie kann gleichzeitig wie ein Array UND wie eine Hash-Tabelle benutzt werden – praktisch, aber auch leicht verwirrend für Einsteiger.
  • Einen Stack mit einer Queue zu verwechseln führt zu Daten in GENAU umgekehrter Reihenfolge – ein klassischer, aber tückischer Logikfehler.
