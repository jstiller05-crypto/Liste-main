Nützliche Tricks (beide Systeme)

  • Tab vervollständigt Datei- und Ordnernamen.
  • Pfeil hoch holt den letzten Befehl zurück.
  • befehl --help (Linux) bzw. Get-Help befehl (PowerShell) zeigt die Hilfe.
  • && führt den zweiten Befehl nur aus, wenn der erste geklappt hat: npm install && npm start (PowerShell 7+ und Bash).
  • Pfade mit Leerzeichen in Anführungszeichen setzen: cd "Mein Ordner".

Zeilenenden: CRLF vs. LF

Windows beendet Textzeilen mit CRLF (\r\n), Linux mit LF (\n). Meist egal, aber Shell-Skripte mit CRLF laufen auf Linux nicht („bad interpreter“). In VS Code steht unten rechts CRLF/LF – ein Klick darauf stellt es um.

Tipps & typische Fehler

  • Linux unterscheidet Datei.txt und datei.txt – auf Windows ist es dieselbe Datei. Das führt oft zu Fehlern, wenn Projekte auf Linux umziehen.
  • Unter Windows lässt sich mit WSL (wsl --install) ein echtes Linux im Terminal nutzen – praktisch zum Testen.
  • Befehle aus dem Internet nie blind mit sudo bzw. als Administrator ausführen.
