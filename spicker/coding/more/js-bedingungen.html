if / else & switch

Code nur ausführen, wenn eine Bedingung erfüllt ist.

if / else if / else

const points = 72;

if (points >= 90) {
  console.log("Sehr gut");
} else if (points >= 60) {
  console.log("Bestanden");        // ← wird ausgeführt
} else {
  console.log("Nicht bestanden");
}

Die Bedingungen werden von oben nach unten geprüft – der erste Treffer gewinnt, der Rest wird übersprungen.

Mehrere Bedingungen

if (age >= 16 && hasPermission) { … }   // beides
if (day === "Sa" || day === "So") { … } // eins von beiden
if (!list.includes(item)) { … }         // NICHT enthalten

switch – viele feste Werte

switch (filterState.sort) {
  case "az":
    console.log("A bis Z");
    break;                 // ohne break läuft es in den nächsten case weiter!
  case "za":
    console.log("Z bis A");
    break;
  default:                 // wenn kein case passt
    console.warn("Unbekannt");
}

Kurzformen

// Ternär – für kurze Entscheidungen, die einen Wert liefern
const text = isOpen ? "Schließen" : "Öffnen";

// Early Return – verschachtelte ifs vermeiden
function save(data) {
  if (!data) return;       // bei fehlenden Daten sofort raus
  // … eigentliche Arbeit
}

Tipps & typische Fehler

  • Geschweifte Klammern immer setzen, auch bei einer Zeile – das verhindert Fehler beim späteren Erweitern.
  • Mit === vergleichen, nicht mit =.
  • Viele else if für feste Werte? Dann ist switch oder ein Objekt als Nachschlagetabelle übersichtlicher.
