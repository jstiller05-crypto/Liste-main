<option>

Ein Eintrag in einer Auswahlliste (<select>) oder Vorschlagsliste (<datalist>).

Was ist das?

Jede Auswahlmöglichkeit eines <select> ist ein <option>. Der Text zwischen den Tags wird angezeigt, der value wird abgeschickt bzw. in JavaScript ausgelesen.

Beispiel

<label for="sort">Sortieren nach</label>
<select id="sort">
  <option value="az">A – Z</option>
  <option value="za">Z – A</option>
  <option value="language" selected>Sprache</option>
  <option value="" disabled>– bald mehr –</option>
</select>

Wichtige Attribute

AttributBedeutung
valueWert, der abgeschickt/ausgelesen wird (fehlt er, wird der Text genommen)
selectedDiese Option ist vorausgewählt
disabledOption ist sichtbar, aber nicht wählbar

Auswahl mit JavaScript lesen

So reagierst du auf eine neue Auswahl, z. B. für eine Sortierung:

const select = document.getElementById("sort");
select.addEventListener("change", () => {
  console.log("Gewählt:", select.value);   // z. B. "az"
});

Tipps & typische Fehler

  • Ohne selected ist die erste Option vorausgewählt.
