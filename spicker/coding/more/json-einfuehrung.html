JSON

Ein reines Textformat für strukturierte Daten – aus JavaScript geboren, heute von praktisch jeder Sprache lesbar.

Was ist das?

JSON (JavaScript Object Notation) ist ein reines Textformat für strukturierte Daten. Anders als eine Programmiersprache kann JSON nichts ausführen – es beschreibt nur Daten: Objekte, Listen, Zahlen, Text und Wahrheitswerte.

Woher kommt das?

JSON wurde Anfang der 2000er-Jahre von Douglas Crockford beschrieben – abgeleitet aus der Schreibweise für Objekte in JavaScript selbst (daher der Name). Heute ist JSON längst sprachunabhängig: Jede gängige Sprache kann JSON lesen und schreiben, auch wenn sie selbst gar keine „JS-Objekte“ kennt.

Erstes Beispiel

{
  "name": "Max",
  "age": 17,
  "isStudent": true,
  "hobbies": ["chess", "coding"],
  "address": {
    "city": "Berlin",
    "zip": "10115"
  }
}

Hier stecken schon alle sechs Bausteine drin: ein string ("Max"), eine number (17), ein boolean (true), ein array (["chess", "coding"]) und ein verschachteltes object (address). Mehr dazu: JSON-Datentypen.

JSON sieht aus wie ein JavaScript-Objekt, ist aber strenger:

Tipps & typische Fehler

  • JSON ist eine Teilmenge der JS-Objekt-Syntax, nicht dasselbe – ein gültiges JS-Objekt ist nicht automatisch gültiges JSON.
  • Die genauen Regeln stehen auf JSON-Syntax, das Arbeiten damit in JS/Node/PHP/Lua/C++ auf JSON verwenden.
