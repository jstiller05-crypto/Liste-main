Lua · Daten

Tabellen

Die einzige Datenstruktur in Lua – gleichzeitig Liste, Wörterbuch, Objekt und Modul.

Als Liste (Array)

local fruits = { "Apfel", "Birne", "Kiwi" }

print(fruits[1])        --> Apfel   (Index beginnt bei 1!)
print(#fruits)          --> 3
fruits[#fruits + 1] = "Mango"          -- hinten anhängen

table.insert(fruits, "Pflaume")        -- hinten anhängen
table.insert(fruits, 1, "Zitrone")     -- an Position 1 einfügen
table.remove(fruits, 2)                -- Element 2 entfernen
table.sort(fruits)                     -- alphabetisch sortieren
print(table.concat(fruits, ", "))      -- zu einem Text verbinden

Als Wörterbuch / Objekt

local player = {
    name = "Max",
    level = 3,
    inventory = { "Schwert", "Brot" }
}

print(player.name)            --> Max
print(player["level"])        --> 3
player.health = 20            -- neues Feld
player.level = nil            -- Feld entfernen

for key, value in pairs(player) do
    print(key, value)
end

Sortieren mit eigener Regel

local players = {
    { name = "Max",  score = 120 },
    { name = "Anna", score = 150 },
}

table.sort(players, function(a, b)
    return a.score > b.score        -- höchster Score zuerst
end)

Wichtige Funktionen

FunktionWirkung
#tLänge einer Liste
table.insert(t, x)Anhängen
table.insert(t, i, x)An Position i einfügen
table.remove(t, i)Entfernen (und zurückgeben)
table.sort(t, fn)Sortieren
table.concat(t, ", ")Zu String verbinden
ipairs(t)Liste der Reihe nach durchlaufen
pairs(t)Alle Schlüssel durchlaufen
next(t) == nilPrüfen, ob Tabelle leer ist

Tipps & typische Fehler

  • Tabellen werden als Referenz weitergegeben: local b = a ist keine Kopie.
  • # funktioniert nur zuverlässig bei Listen ohne Lücken (nil in der Mitte).
  • Kopie einer Liste: local copy = { table.unpack(original) } (in 5.1: unpack).
