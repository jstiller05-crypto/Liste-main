Bedingungen, Schleifen & Methoden

if, switch-Ausdrücke, Schleifen und eigene Methoden.

if & switch

int points = 72;

if (points >= 90) {
    Console.WriteLine("Sehr gut");
} else if (points >= 60) {
    Console.WriteLine("Bestanden");
} else {
    Console.WriteLine("Nicht bestanden");
}

// switch-Ausdruck (modern, liefert einen Wert)
string grade = points switch {
    >= 90 => "sehr gut",
    >= 60 => "bestanden",
    _     => "nicht bestanden"      // _ = alles andere
};

Schleifen

for (int i = 0; i < 5; i++) {
    Console.WriteLine(i);
}

var colors = new List<string> { "rot", "grün", "blau" };
foreach (var color in colors) {
    Console.WriteLine(color);
}

int tries = 0;
while (tries < 3) { tries++; }

do {
    // läuft mindestens einmal
} while (false);

break und continue funktionieren wie in C++ und JavaScript.

Methoden

static int Add(int a, int b) {
    return a + b;
}

static string Greet(string name, string greeting = "Hallo") => $"{greeting}, {name}!";   // Kurzform

// mehrere Rückgabewerte mit Tupel
static (int min, int max) MinMax(List<int> values) => (values.Min(), values.Max());

var (low, high) = MinMax(new List<int> { 4, 9, 1 });
Console.WriteLine($"{low} – {high}");

Methodennamen schreibt man in C# in PascalCase: CalculateTotal, nicht calculateTotal.

Tipps & typische Fehler

  • => bei Methoden ist eine Kurzschreibweise für { return …; }.
  • Beim switch-Ausdruck muss jeder Fall abgedeckt sein – _ fängt den Rest.
