Einführung & Installation

Python auf Arch installieren, im REPL ausprobieren, das erste Skript starten – und verstehen, warum die Einrückung zählt.

Was ist das?

Um Python-Programme auszuführen, braucht man den Interpreter – das Programm python. Er liest eine .py-Datei und führt sie sofort aus. Einen eigenen Schritt „kompilieren“ wie bei C++ gibt es nicht.

Installieren auf Arch

Auf Arch/CachyOS ist Python fast immer schon da, weil viele Systemprogramme es brauchen. Zuerst prüfen:

python --version     # zeigt z. B. "Python 3.14.x"

Falls der Befehl fehlt:

sudo pacman -S python
Teil des BefehlsBedeutung
sudoBefehl mit Administrator-Rechten ausführen (fragt nach dem Passwort)
pacmanDer Paketmanager von Arch
-S„Sync“ – ein Paket aus den Paketquellen installieren
pythonName des Pakets (Python 3)

Der REPL – Python zum Ausprobieren

REPL heißt Read–Eval–Print Loop: lesen, auswerten, ausgeben, wiederholen. Startet man python ohne Datei, kann man Zeile für Zeile testen. >>> ist die Eingabe-Aufforderung – die tippt man nicht mit.

$ python
>>> 2 + 3
5
>>> name = "Max"
>>> name.upper()
'MAX'
>>> help(str.upper)      # eingebaute Hilfe, mit q verlassen
>>> exit()               # beenden (oder Strg+D)

Ein Skript schreiben und ausführen

Diesen Text als hello.py speichern:

# hello.py
print("Hallo Welt!")
print("2 + 3 =", 2 + 3)

Im Terminal in den Ordner der Datei wechseln und starten:

python hello.py

Direkt ausführbar machen (Shebang)

Steht in der ersten Zeile ein „Shebang“, kann Linux das Skript wie ein Programm starten:

#!/usr/bin/env python
print("Ich bin ein ausführbares Skript")
chmod +x hello.py    # Ausführbar-Bit setzen (einmalig)
./hello.py           # starten – ohne "python" davor

Einrückung statt geschweifter Klammern

In C++, JS oder C# umschließen { } einen Block. In Python beginnt ein Block nach einem Doppelpunkt und besteht aus allen Zeilen, die gleich weit eingerückt sind (üblich: 4 Leerzeichen).

# indent.py
temperature = 25

if temperature > 20:
    print("Es ist warm")           # gehört zum if
    print("T-Shirt reicht")        # gehört auch zum if
print("Diese Zeile läuft immer")   # nicht eingerückt = nach dem if

Tipps & typische Fehler

  • IndentationError: unexpected indent – eine Zeile ist eingerückt, obwohl kein Block offen ist.
  • IndentationError: expected an indented block – nach einem Doppelpunkt fehlt die eingerückte Zeile. Soll der Block (noch) leer bleiben, schreibt man pass.
  • TabError – Tabs und Leerzeichen gemischt. Im Editor „Leerzeichen statt Tabs“ einstellen.
  • Der Doppelpunkt nach if, for, def … wird am Anfang oft vergessen → SyntaxError: expected ':'.
  • Eigene Datei nicht wie ein Modul nennen (random.py, json.py) – sonst lädt import random die eigene Datei.
