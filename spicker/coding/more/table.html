HTML · Tabellen

Tabellen (<table>)

Stellt Daten in Zeilen und Spalten dar.

Was ist das?

Eine Tabelle ist aus mehreren Elementen aufgebaut:

ElementBedeutung
<table>Die ganze Tabelle
<caption>Titel der Tabelle (optional, als erstes Kind)
<thead>Kopfbereich mit den Spaltenüberschriften
<tbody>Hauptteil mit den Daten
<tfoot>Fußbereich, z. B. Summen
<tr>table row – eine Zeile
<th>table header – Überschriftszelle (fett, zentriert)
<td>table data – normale Datenzelle

Beispiel

<table>
  <caption>Meine Lernzeiten</caption>
  <thead>
    <tr>
      <th>Tag</th>
      <th>Sprache</th>
      <th>Minuten</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Montag</td>
      <td>C++</td>
      <td>90</td>
    </tr>
    <tr>
      <td>Dienstag</td>
      <td>JavaScript</td>
      <td>45</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Summe</td>   <!-- Zelle über 2 Spalten -->
      <td>135</td>
    </tr>
  </tfoot>
</table>
Meine Lernzeiten
TagSpracheMinuten
MontagC++90
DienstagJavaScript45
Summe135

Wichtige Attribute

AttributBedeutung
colspanZelle geht über mehrere Spalten (<td colspan="2">)
rowspanZelle geht über mehrere Zeilen
scopeBei <th>: col oder row – sagt Screenreadern, wofür die Überschrift gilt

Tabellen gestalten (CSS)

table {
  border-collapse: collapse;   /* doppelte Rahmen zusammenfassen */
  width: 100%;
}

th, td {
  border: 1px solid #4a4a4a;
  padding: 8px 12px;
  text-align: left;
}

tbody tr:nth-child(even) {     /* jede zweite Zeile */
  background-color: #2b2b2b;
}

tbody tr:hover {
  background-color: #3a3a3a;   /* Zeile beim Drüberfahren */
}

Tabelle mit JavaScript füllen

Zeilen lassen sich auch per JavaScript erzeugen, z. B. aus einer Liste von Daten:

const tbody = document.querySelector("#myTable tbody");

const row = document.createElement("tr");   // neue Zeile
const cell = document.createElement("td");  // neue Zelle
cell.textContent = "Montag";
row.appendChild(cell);                      // Zelle in Zeile
tbody.appendChild(row);                     // Zeile in Tabelle

Tipps & typische Fehler

  • Tabellen nur für Daten verwenden, nicht fürs Seitenlayout – dafür gibt es Flexbox und Grid.
  • Jede Zeile sollte gleich viele Zellen haben (Spannen mit colspan mitgezählt).
  • Auf schmalen Bildschirmen: die Tabelle in ein <div style="overflow-x: auto"> packen, dann kann man seitlich scrollen.
