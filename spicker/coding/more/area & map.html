<map> & <area>

Macht bestimmte Bereiche eines Bildes klickbar (Image-Map).

Was ist das?

Mit einer Image-Map legst du über ein Bild unsichtbare, klickbare Flächen – z. B. Länder auf einer Karte oder Teile eines Schreibtisch-Fotos. <map> ist der Container, jedes <area> ist eine klickbare Fläche.

So hängt alles zusammen

  1. Das Bild bekommt usemap="#name" (mit #).
  2. <map> bekommt name="name" (ohne #).
  3. In <map> stehen die <area>-Flächen mit Form (shape), Koordinaten (coords) und Ziel (href).

Syntax

<img src="bild.jpg" alt="…" usemap="#mapname">

<map name="mapname">
  <area shape="rect" coords="x1,y1,x2,y2" href="ziel.html" alt="…">
</map>

Beispiel

<img src="workplace.jpg" alt="Arbeitsplatz" usemap="#workmap" width="400" height="379">

<map name="workmap">
  <!-- Rechteck: linke obere Ecke (34,44) bis rechte untere Ecke (270,350) -->
  <area shape="rect" coords="34,44,270,350" href="computer.html" alt="Computer">

  <!-- Kreis: Mittelpunkt (337,300), Radius 44 -->
  <area shape="circle" coords="337,300,44" href="kaffee.html" alt="Kaffeetasse">

  <!-- Vieleck: beliebig viele Punkte x,y -->
  <area shape="poly" coords="290,172,333,104,388,172" href="lampe.html" alt="Lampe">
</map>

Formen und Koordinaten

shapecoordsBedeutung
rectx1,y1,x2,y2Linke obere und rechte untere Ecke
circlex,y,rMittelpunkt und Radius
polyx1,y1,x2,y2,x3,y3,…Eckpunkte eines Vielecks
default–Der ganze Rest des Bildes

Alle Werte sind Pixel, gemessen von der linken oberen Ecke des Bildes (0,0).

Wichtige Attribute

AttributBedeutung
name (map)Name, auf den usemap verweist
usemap (img)# + Name der Map
shape (area)rect, circle, poly oder default
coords (area)Koordinaten der Fläche
href (area)Ziel beim Klick
alt (area)Beschreibung der Fläche (Pflicht, wenn href gesetzt)
target (area)z. B. _blank für neuen Tab

Koordinaten herausfinden

Am einfachsten mit JavaScript: Klick ins Bild, und die Konsole (F12) zeigt die Position.

const image = document.querySelector('img[usemap]');

image.addEventListener("click", (event) => {
  // offsetX/Y = Position relativ zum Bild
  console.log("x:", event.offsetX, "y:", event.offsetY);
});

Mit JavaScript auf Flächen reagieren

document.querySelectorAll("area").forEach((area) => {
  area.addEventListener("click", (event) => {
    event.preventDefault();            // Link nicht öffnen
    console.log("Geklickt:", area.alt);
  });
});

Tipps & typische Fehler

  • Größte Falle: Wird das Bild per CSS skaliert (z. B. max-width: 100%), passen die Koordinaten nicht mehr – sie gelten immer für die Originalgröße.
  • Die Flächen sind unsichtbar. Nutzer wissen nicht, wo sie klicken können – ein Hinweis im Text hilft.
  • Für moderne, responsive Seiten ist oft ein SVG mit Links die flexiblere Lösung.
  • usemap braucht das #, name nicht – das wird leicht verwechselt.
