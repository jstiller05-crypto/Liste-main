HTML · Formulare

<output>

Zeigt das Ergebnis einer Berechnung oder Aktion an.

Was ist das?

<output> ist ein Platz für ein Ergebnis, das aus Eingaben entsteht – z. B. eine Summe oder der Wert eines Schiebereglers. Mit for gibst du an, aus welchen Feldern das Ergebnis berechnet wird.

Beispiel: Rechner

<form id="calc">
  <input type="number" id="a" value="2"> +
  <input type="number" id="b" value="3"> =
  <output id="result" for="a b">5</output>
</form>

<script>
  const form = document.getElementById("calc");
  form.addEventListener("input", () => {
    const a = Number(document.getElementById("a").value);
    const b = Number(document.getElementById("b").value);
    document.getElementById("result").value = a + b;
  });
</script>

Beispiel: Wert eines Schiebereglers

<input type="range" id="volume" min="0" max="100" value="40"
       oninput="volumeValue.value = this.value">
<output id="volumeValue">40</output> %
40 %

Wichtige Attribute

AttributBedeutung
forIDs der Felder, aus denen das Ergebnis entsteht (mit Leerzeichen getrennt)
nameName, falls das Ergebnis mitgeschickt werden soll

Tipps & typische Fehler

  • Screenreader lesen Änderungen in <output> automatisch vor – ein Vorteil gegenüber <span>.
  • Nicht vergessen: Eingaben sind Texte. Vor dem Rechnen mit Number() umwandeln.
