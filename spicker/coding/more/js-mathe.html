Zufallszahlen

// Ganze Zahl von min bis max (beide inklusive)
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

randomInt(1, 6);     // Würfel: 1–6

// Zufälliges Element aus einem Array
const colors = ["rot", "grün", "blau"];
const pick = colors[Math.floor(Math.random() * colors.length)];

Zahlen umwandeln & formatieren

Number("3.5");            // 3.5
parseFloat("3.5 kg");     // 3.5
parseInt("08", 10);       // 8
Number.isNaN(Number("x"));   // true – ungültige Zahl erkennen

(3.14159).toFixed(2);     // "3.14"  – Achtung: Ergebnis ist Text

// Nach deutschem Format
(1234.5).toLocaleString("de-DE");                                   // "1.234,5"
(19.9).toLocaleString("de-DE", { style: "currency", currency: "EUR" });   // "19,90 €"

Kommazahlen-Falle

0.1 + 0.2;                        // 0.30000000000000004 !
Math.round((0.1 + 0.2) * 100) / 100;   // 0.3 – auf 2 Stellen runden

Datum & Uhrzeit

const now = new Date();

now.getFullYear();     // 2026
now.getMonth();        // 0–11  (Januar = 0!)
now.getDate();         // Tag im Monat 1–31
now.getDay();          // Wochentag 0–6 (Sonntag = 0)
now.getHours();        // 0–23

now.toLocaleDateString("de-DE");   // "28.9.2026"
now.toLocaleTimeString("de-DE");   // "14:05:33"

const birthday = new Date(2026, 11, 24);   // 24. Dezember 2026 (Monat 11!)
const diffMs = birthday - now;              // Differenz in Millisekunden
const diffDays = Math.ceil(diffMs / (1000 * 60 * 60 * 24));

Tipps & typische Fehler

  • Monate zählen bei Date ab 0 – eine der bekanntesten JavaScript-Fallen.
  • toFixed liefert einen String. Zum Weiterrechnen wieder Number() drumherum.
  • Division durch 0 ergibt Infinity, keinen Fehler.
