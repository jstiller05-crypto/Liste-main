Konsole, Fehler & Debugging

Ausgaben in der Konsole, Fehler abfangen und Fehler finden.

Die Konsole

F12 → Tab „Konsole“. Hier erscheinen Ausgaben und Fehlermeldungen. Du kannst dort auch direkt JavaScript eintippen.

BefehlWirkung
console.log(a, b)Normale Ausgabe
console.warn(…)Gelbe Warnung
console.error(…)Roter Fehler
console.table(array)Arrays/Objekte als Tabelle
console.group("Name") … console.groupEnd()Ausgaben einklappbar gruppieren
console.time("x") … console.timeEnd("x")Zeit messen
console.clear()Konsole leeren
 
console.log("[filter] Ergebnis:", result.length, result);   // Präfix in [ ] macht Ausgaben leicht auffindbar

Fehler abfangen: try / catch

try {
  const data = JSON.parse(text);        // kann fehlschlagen
  console.log(data);
} catch (error) {
  console.error("Ungültiges JSON:", error.message);
} finally {
  console.log("läuft immer – mit oder ohne Fehler");
}

Eigene Fehler werfen

function divide(a, b) {
  if (b === 0) {
    throw new Error("Division durch 0 ist nicht erlaubt");
  }
  return a / b;
}

Debugger

function calculate(values) {
  debugger;           // Browser hält hier an, wenn F12 offen ist
  return values.reduce((a, b) => a + b, 0);
}

Im Tab „Quellen“ kannst du dann Zeile für Zeile weitergehen und alle Variablen ansehen. Haltepunkte setzt man dort auch per Klick auf die Zeilennummer.

Tipps & typische Fehler

  • Die Fehlermeldung nennt Datei und Zeile – draufklicken springt direkt zur Stelle.
  • Nach dem ersten Fehler stoppt das Skript. Oft verschwinden weitere Fehler, wenn man den ersten behebt.
  • Vor dem Veröffentlichen überflüssige console.log entfernen oder reduzieren.
