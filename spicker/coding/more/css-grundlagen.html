CSS-Grundlagen

Wie eine CSS-Regel aufgebaut ist, wie CSS in die Seite kommt und welche Regel am Ende gewinnt.

Aufbau einer Regel

h1 {                 /* Selektor: WELCHE Elemente */
  color: #4f8cff;    /* Eigenschaft: Wert;  → eine Deklaration */
  font-size: 2rem;
}
BegriffBeispielBedeutung
Selektorh1Welche Elemente betroffen sind
EigenschaftcolorWas geändert wird
Wert#4f8cffWie es geändert wird
Deklarationcolor: #4f8cff;Eigenschaft + Wert, endet mit ;
Regelh1 { … }Selektor + alle Deklarationen in { }

CSS einbinden

<!-- 1) externe Datei (empfohlen) -->
<link rel="stylesheet" href="style.css">

<!-- 2) im <head> -->
<style> p { color: gray; } </style>

<!-- 3) direkt am Element -->
<p style="color: gray;">Text</p>

Kaskade: Welche Regel gewinnt?

Gelten mehrere Regeln für dasselbe Element, entscheidet der Browser in dieser Reihenfolge:

  1. Wichtigkeit: !important schlägt alles (nur im Notfall verwenden).
  2. Spezifität: style="…" > #id > .klasse / [attribut] / :hover > element.
  3. Reihenfolge: Bei Gleichstand gewinnt die Regel, die später kommt.
p { color: gray; }
.intro { color: white; }   /* gewinnt: Klasse ist spezifischer als Element */
p { color: red; }          /* verliert trotzdem gegen .intro */

Vererbung

Manche Eigenschaften werden an Kind-Elemente weitergegeben – vor allem Text-Eigenschaften wie color, font-family, line-height. Box-Eigenschaften wie margin, padding, border werden nicht vererbt.

body {
  font-family: Arial, sans-serif;  /* gilt für die ganze Seite */
  color: #f2f2f2;
}

a { color: inherit; }   /* inherit: Wert vom Eltern-Element übernehmen */

Browser-Standards zurücksetzen

* {
  box-sizing: border-box;   /* padding zählt zur Breite */
}

body {
  margin: 0;                /* Browser geben body 8px Rand */
}

Tipps & typische Fehler

  • Jede Deklaration mit ; abschließen – ein fehlendes Semikolon macht oft die nächste Zeile kaputt.
  • CSS ignoriert Fehler still. Wirkt eine Regel nicht: F12 → Elemente → rechts bei „Styles“ nachsehen, ob sie durchgestrichen ist.
  • !important möglichst vermeiden – lieber einen spezifischeren Selektor verwenden.
