C++

Referenzen (&)

Was ist das?

Eine Referenz ist ein Alias für eine existierende Variable. Sie verweist auf dieselbe Speicherstelle und kann wie die Original-Variable verwendet werden.

Syntax

Typ &referenz = variable;   // Referenz erstellen
// referenz ist jetzt ein Alias für variable

Beispiel

#include <iostream>
using namespace std;

int main() {
    int alter = 25;
    int &rAlter = alter;        // rAlter ist Referenz zu alter
    
    cout << "alter: " << alter << endl;     // 25
    cout << "rAlter: " << rAlter << endl;   // 25 (derselbe Wert)
    
    rAlter = 30;                // Ändert BEIDE Variablen
    
    cout << "alter: " << alter << endl;     // 30
    cout << "rAlter: " << rAlter << endl;   // 30
    
    return 0;
}

Referenzen in Funktionen

void veraendereWert(int &x) {
    x = 100;  // Ändert die Original-Variable!
}

int main() {
    int alter = 20;
    veraendereWert(alter);    // alter wird zu 100
    return 0;
}

Unterschied: Referenz vs. Zeiger

  • Referenz: Kann nicht NULL sein, automatisch dereferenziert, kein * nötig
  • Zeiger: Kann NULL sein, muss dereferenziert werden (*), kann geändert werden

Wichtige Hinweise

  • Referenzen müssen bei der Deklaration initialisiert werden
  • Eine Referenz kann nicht auf eine andere Variable verweisen
  • Konstante Referenzen: `const int &r = x;` (können nicht verändert werden)
