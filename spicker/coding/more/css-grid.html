Grid

Ein zweidimensionales Raster aus Zeilen und Spalten – für Seitenlayouts und Galerien.

Was ist das?

Mit display: grid legst du Spalten (und Zeilen) fest, in die die Kinder automatisch einsortiert werden. Anders als Flexbox denkt Grid in zwei Richtungen gleichzeitig.

Grundbeispiel

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* 3 gleich breite Spalten */
  gap: 12px;
}

Spalten festlegen

grid-template-columns: 200px 1fr;               /* feste Sidebar + Rest */
grid-template-columns: 1fr 2fr 1fr;             /* Mitte doppelt so breit */
grid-template-columns: repeat(4, 1fr);          /* 4 gleiche Spalten */

/* Responsive ohne Media Query: so viele Spalten wie passen, jede mind. 200px */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

Elemente über mehrere Zellen

.featured {
  grid-column: span 2;       /* über 2 Spalten */
  grid-row: span 2;          /* über 2 Zeilen */
}

.full-width {
  grid-column: 1 / -1;       /* von Linie 1 bis zur letzten Linie */
}

Seitenlayout mit Bereichsnamen

.page {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
}

header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: main; }
footer { grid-area: footer; }

Wichtige Eigenschaften

EigenschaftWirkung
grid-template-columns / -rowsSpalten / Zeilen definieren
gapAbstand zwischen Zellen
grid-column / grid-rowPosition/Spannweite eines Kindes
grid-template-areasLayout mit Namen „zeichnen“
justify-items / align-itemsAusrichtung innerhalb der Zellen
place-items: centerKurzform: alles zentrieren

Tipps & typische Fehler

  • fr = Anteil am freien Platz – nur in Grid verfügbar.
  • F12 → beim Grid-Container auf das kleine „grid“-Symbol klicken, dann zeigt der Browser die Rasterlinien an.
  • Grid und Flexbox lassen sich kombinieren: Grid für das Seitenlayout, Flexbox innerhalb der Bereiche.
