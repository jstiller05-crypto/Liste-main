<figure>

Fasst ein Bild, Diagramm, Code-Beispiel oder Zitat mit seiner Beschriftung zusammen.

Was ist das?

<figure> ist ein Container für eigenständige Inhalte, auf die der Text verweist („siehe Abbildung 1“). Die Beschriftung steht in <figcaption>.

Beispiele

<!-- Bild mit Bildunterschrift -->
<figure>
  <img src="setup.jpg" alt="Schreibtisch mit Laptop und Monitor">
  <figcaption>Abb. 1: Mein Programmier-Setup</figcaption>
</figure>

<!-- Code mit Beschriftung -->
<figure>
  <pre><code>console.log("Hallo");</code></pre>
  <figcaption>Ausgabe in der Browser-Konsole</figcaption>
</figure>

Tipps & typische Fehler

  • Browser geben <figure> einen Außenabstand (margin: 40px). Mit figure { margin: 0; } entfernst du ihn.
  • Bilder ohne Beschriftung brauchen kein <figure>.

Verwandte Seiten

<figcaption> <img> <blockquote> / <q> <caption>
