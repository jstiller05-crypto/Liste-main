C

Die Vorgängerin von C++ – klein, schnell und nah an der Hardware.

Was ist das?

C wurde Anfang der 1970er für das Betriebssystem Unix entwickelt. Bis heute sind Betriebssysteme (Linux-Kernel, Teile von Windows), Mikrocontroller-Programme, Datenbanken und Interpreter (z. B. Lua, Python) in C geschrieben. C++ ist aus C entstanden – fast jeder C-Code ist auch gültiges C++.

Tipps & typische Fehler

  • Dateiendung .c, Header .h. Mit gcc statt g++ kompilieren.
  • C prüft sehr wenig – falsche Speicherzugriffe führen oft nicht zu einer Fehlermeldung, sondern zu seltsamem Verhalten. Warnungen (-Wall -Wextra) immer einschalten.
  • Wer C++ kann, kann schon viel C: Variablen, Schleifen, if, Funktionen und Zeiger sind gleich.
