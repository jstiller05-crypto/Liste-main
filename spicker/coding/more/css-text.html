Beispiel

body {
  font-family: "Segoe UI", Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

h1 {
  font-size: 2.5rem;
  font-weight: 700;
  letter-spacing: 0.5px;
}

.label {
  font-size: 0.8rem;
  text-transform: uppercase;
  letter-spacing: 1px;
}

Eigene Schriften einbinden

<!-- Google Fonts im <head> -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap">
/* oder eigene Datei */
@font-face {
  font-family: "MeineSchrift";
  src: url("fonts/meineschrift.woff2") format("woff2");
}

body {
  font-family: "MeineSchrift", Arial, sans-serif;   /* Arial als Ersatz */
}

Langen Text mit „…“ abschneiden

.one-line {
  white-space: nowrap;      /* nicht umbrechen */
  overflow: hidden;         /* Überstand verstecken */
  text-overflow: ellipsis;  /* … anzeigen */
}

Tipps & typische Fehler

  • Immer eine Ersatz-Schrift angeben (sans-serif, serif, monospace), falls die gewünschte fehlt.
  • Schriftnamen mit Leerzeichen in Anführungszeichen: "Segoe UI".
  • rem statt px für Schriftgrößen – dann respektiert die Seite die Schriftgröße, die der Nutzer im Browser eingestellt hat.
