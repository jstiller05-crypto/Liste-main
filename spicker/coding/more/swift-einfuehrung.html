Swift

Apples moderne Programmiersprache für iPhone-, iPad-, Mac- und Watch-Apps – aber auch für Server und Kommandozeile.

Was ist das?

Swift wurde 2014 von Apple als Nachfolger von Objective-C vorgestellt. Die Sprache ist sicher (z. B. keine Null-Zeiger-Abstürze dank Optionals), schnell und gut lesbar. Apps für Apple-Geräte baut man mit Swift + SwiftUI in Xcode.

Nur auf macOS: Xcode, SwiftUI-Vorschau und der iPhone-Simulator gibt es ausschließlich auf einem Mac. Die Sprache Swift selbst läuft auch auf Windows und Linux.

Installieren (ohne Mac)

SystemInstallation
Windowswinget install Swift.Toolchain (Anleitung auf swift.org, braucht Visual Studio Build Tools)
LinuxInstaller swiftly von swift.org oder das passende Paket für die Distribution
macOSXcode aus dem App Store installieren – Swift ist dabei

Prüfen mit swift --version. In VS Code gibt es die offizielle Erweiterung „Swift“.

Erstes Programm

// main.swift
let name = "Welt"
print("Hallo \(name)!")          // \( ) setzt Werte in Text ein
swift main.swift                 # direkt ausführen

swift package init --type executable   # neues Projekt
swift run                              # bauen und starten

Tipps & typische Fehler

  • Keine Semikolons nötig.
  • Swift ist streng typisiert, erkennt Typen aber meist selbst.
  • Für Swift ohne Installation: Online-Spielwiesen wie swiftfiddle.com.
