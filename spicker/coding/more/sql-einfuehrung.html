SQL

Die Sprache, mit der man Daten in relationalen Datenbanken speichert, abfragt und ändert.

Was ist das?

SQL (Structured Query Language) spricht mit Datenbanken wie MySQL, MariaDB, PostgreSQL oder SQLite. Die Daten liegen in Tabellen – ähnlich wie in einer Tabellenkalkulation: Jede Zeile ist ein Datensatz, jede Spalte eine Eigenschaft.

Aufbau einer Tabelle

idnameemailpoints
1Maxmax@example.com120
2Annaanna@example.com150
3Tomtom@example.com90
BegriffBedeutung
DatenbankSammlung zusammengehöriger Tabellen
TabelleEine Sorte Daten, z. B. users
Zeile / DatensatzEin einzelner Eintrag
Spalte / FeldEine Eigenschaft mit festem Datentyp
PrimärschlüsselEindeutige ID jeder Zeile (meist id)
FremdschlüsselVerweis auf die ID in einer anderen Tabelle

Die vier Grundbefehle (CRUD)

AktionSQLBeispiel
Create – anlegenINSERTINSERT INTO users (name) VALUES ('Max');
Read – lesenSELECTSELECT * FROM users;
Update – ändernUPDATEUPDATE users SET points = 130 WHERE id = 1;
Delete – löschenDELETEDELETE FROM users WHERE id = 3;

Schreibregeln

-- Kommentar über eine Zeile
/* Kommentar über
   mehrere Zeilen */

SELECT name, points      -- Schlüsselwörter üblicherweise GROSS
FROM users               -- Tabellen- und Spaltennamen klein
WHERE points > 100;      -- jede Anweisung endet mit ;

Womit anfangen?

DatenbankGut für

Zum Ausprobieren: „DB Browser for SQLite“ oder die VS-Code-Erweiterung „SQLite Viewer“, bei MySQL „phpMyAdmin“ oder „HeidiSQL“.

Tipps & typische Fehler

  • Texte stehen in einfachen Anführungszeichen: 'Max'.
  • Die Grundbefehle sind in allen SQL-Datenbanken gleich, Details (Datentypen, Funktionen) unterscheiden sich leicht.
  • UPDATE und DELETE immer mit WHERE – sonst betrifft es alle Zeilen.
