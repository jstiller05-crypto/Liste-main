ID-Attribut (id)

Gibt einem Element einen eindeutigen Namen – für JavaScript, Sprungmarken, Labels und CSS.

Was ist das?

Eine id darf auf einer Seite nur ein einziges Mal vorkommen – wie ein Personalausweis für das Element. Im CSS sprichst du sie mit # an.

Syntax

<!-- HTML -->
<table id="dynamicTable">…</table>

/* CSS */
#dataTable {
  width: 100%;
}

Wofür man IDs braucht

<!-- 1) JavaScript: Element finden -->
<input id="searchInput">
<script>
  const input = document.getElementById("searchInput");
</script>

<!-- 2) Sprungmarke: Link springt zum Element -->
<a href="#kontakt">Zum Kontakt</a>
<section id="kontakt">…</section>

<!-- 3) Label mit Feld verbinden -->
<label for="email">E-Mail</label>
<input id="email" type="email">

<!-- 4) Andere Seite an bestimmter Stelle öffnen -->
<a href="anleitung.html#schritt-2">Anleitung, Schritt 2</a>

Tipps & typische Fehler

  • Jede ID nur einmal pro Seite – sonst findet getElementById nur das erste Element.
  • Keine Leerzeichen, nicht mit einer Ziffer beginnen: id="sort-select" statt id="1 select".
  • Fürs Styling lieber Klassen verwenden: ID-Regeln sind sehr „stark“ und schwer zu überschreiben.
