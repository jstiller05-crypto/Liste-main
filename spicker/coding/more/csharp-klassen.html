Klassen, Properties & Interfaces

Objektorientierung in C#: Klassen, Eigenschaften, Konstruktoren, Vererbung und Interfaces.

Klasse mit Properties

public class Player {
    public string Name { get; }                 // nur lesbar (im Konstruktor setzbar)
    public int Score { get; private set; }      // lesbar, aber nur intern änderbar
    public int Level { get; set; } = 1;         // mit Standardwert

    public Player(string name) {                // Konstruktor
        Name = name;
    }

    public void AddScore(int points) {
        if (points < 0) throw new ArgumentException("Punkte dürfen nicht negativ sein");
        Score += points;
    }

    public override string ToString() => $"{Name} ({Score} Punkte)";
}

var player = new Player("Max");
player.AddScore(50);
Console.WriteLine(player);    // Max (50 Punkte)

Properties ({ get; set; }) sind die C#-Art von Getter und Setter – ohne sie selbst schreiben zu müssen.

record – kurze Datenklassen

public record Task(string Question, int Answer);

var t = new Task("3 + 4", 7);
Console.WriteLine(t);                  // Task { Question = 3 + 4, Answer = 7 }

Vererbung & Interfaces

public interface IShape {
    double Area();
}

public abstract class Shape : IShape {
    public abstract double Area();
    public virtual string Describe() => $"Fläche: {Area():F2}";
}

public class Circle : Shape {
    private readonly double radius;
    public Circle(double radius) => this.radius = radius;
    public override double Area() => Math.PI * radius * radius;
}

List<IShape> shapes = new() { new Circle(2) };
foreach (var s in shapes) Console.WriteLine(s.Area());

Fehlerbehandlung

try {
    player.AddScore(-5);
} catch (ArgumentException ex) {
    Console.Error.WriteLine($"[Fehler] {ex.Message}");
} finally {
    Console.WriteLine("fertig");
}

Tipps & typische Fehler

  • Interfaces beginnen per Konvention mit I: IShape, IDisposable.
  • Zugriff: public, private (Standard), protected, internal (nur im eigenen Projekt).
  • Kein delete nötig – der Garbage Collector räumt auf.
