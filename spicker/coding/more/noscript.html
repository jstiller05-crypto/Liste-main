<noscript>

Wird nur angezeigt, wenn JavaScript im Browser ausgeschaltet ist.

Was ist das?

Braucht deine Seite JavaScript (z. B. für Filter oder eine Suche), kannst du mit <noscript> einen Hinweis für Nutzer ohne JavaScript anzeigen.

Beispiel

<noscript>
  <p>Diese Seite braucht JavaScript für die Suche und die Filter.
     Bitte aktiviere JavaScript in deinem Browser.</p>
</noscript>

Tipps & typische Fehler

  • Heute haben fast alle Nutzer JavaScript aktiv – der Hinweis ist trotzdem guter Stil.
  • Steht meist ganz oben im <body>.
