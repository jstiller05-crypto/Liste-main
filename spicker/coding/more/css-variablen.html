CSS-Variablen

Werte wie Farben oder Abstände einmal festlegen und überall wiederverwenden.

Was ist das?

CSS-Variablen (Custom Properties) beginnen mit zwei Bindestrichen. Mit var() setzt du sie ein. Änderst du den Wert an einer Stelle, ändert er sich überall.

Beispiel

:root {                      /* :root = das <html>-Element → gilt überall */
  --accent: #4f8cff;
  --bg: #333333;
  --radius: 8px;
  --space: 16px;
}

.button {
  background: var(--accent);
  border-radius: var(--radius);
  padding: calc(var(--space) / 2) var(--space);
}

.card {
  background: var(--bg);
  border-radius: var(--radius);
}

Ersatzwert

color: var(--text-color, white);   /* white, falls --text-color nicht existiert */

Themes (z. B. Hell/Dunkel)

:root {
  --bg: #ffffff;
  --text: #222222;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #222222;
    --text: #f2f2f2;
  }
}

body {
  background: var(--bg);
  color: var(--text);
}

Mit JavaScript ändern

// lesen
const accent = getComputedStyle(document.documentElement).getPropertyValue("--accent");

// setzen – ändert sofort alle Stellen, die var(--accent) nutzen
document.documentElement.style.setProperty("--accent", "#ff5f8c");

Tipps & typische Fehler

  • Namen beschreiben den Zweck (--accent, --card-bg), nicht die Farbe (--blau).
  • Groß-/Kleinschreibung zählt: --Accent und --accent sind verschieden.
  • Variablen werden vererbt – du kannst sie auch nur für einen Bereich überschreiben: .dark-box { --bg: #000; }.
