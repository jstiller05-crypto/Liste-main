HTML · Interaktiv

<dialog>

Ein Dialogfenster (Popup/Modal), das über JavaScript geöffnet und geschlossen wird.

Was ist das?

<dialog> ist ein eingebautes Popup. Mit showModal() erscheint es über der Seite, der Hintergrund wird abgedunkelt und ist gesperrt. Mit Esc oder close() geht es wieder zu.

Beispiel

<button id="openBtn">Info anzeigen</button>

<dialog id="infoDialog">
  <h2>Hinweis</h2>
  <p>Das ist ein Dialog.</p>
  <form method="dialog">
    <button>Schließen</button>   <!-- method="dialog" schließt automatisch -->
  </form>
</dialog>

<script>
  const dialog = document.getElementById("infoDialog");
  document.getElementById("openBtn").addEventListener("click", () => {
    dialog.showModal();
  });
</script>

Wichtige Befehle (JavaScript)

BefehlWirkung
dialog.showModal()Öffnet als Modal (Hintergrund gesperrt, Esc schließt)
dialog.show()Öffnet ohne Sperre des Hintergrunds
dialog.close()Schließt den Dialog
dialog.opentrue, wenn der Dialog offen ist

Hintergrund gestalten (CSS)

dialog::backdrop {
  background: rgba(0, 0, 0, 0.6);  /* abgedunkelter Hintergrund */
}

Tipps & typische Fehler

  • Nicht das Attribut open direkt setzen, um ein Modal zu öffnen – dann fehlen Abdunklung und Esc. Immer showModal() verwenden.
  • Ein Schließen-Button gehört immer in den Dialog.
