Klammern in JavaScript

[], () und {} – drei Klammerarten mit jeweils eigenen Aufgaben.

Übersicht

KlammerNameWofür
[ ]eckige KlammernArrays (Listen) erstellen und auf Einträge zugreifen
( )runde KlammernFunktionen aufrufen/definieren, Bedingungen, Rechen-Reihenfolge
{ }geschweifte KlammernObjekte erstellen, Codeblöcke umschließen

[ ] – Arrays

const colors = ["rot", "grün", "blau"];   // Array erstellen

console.log(colors[0]);        // "rot"  – Zählung beginnt bei 0!
console.log(colors.length);    // 3
colors[1] = "gelb";            // Eintrag ändern

const user = { name: "Max" };
console.log(user["name"]);     // "Max" – auch für Objekt-Eigenschaften

( ) – Funktionen, Bedingungen, Gruppierung

function greet(name) {          // Parameter in ()
  return "Hallo " + name;
}
greet("Max");                   // Funktion aufrufen: ()

if (age >= 18) { … }            // Bedingung in ()
for (let i = 0; i < 3; i++) { … }

const result = (2 + 3) * 4;     // Gruppierung: 20 statt 14
const add = (a, b) => a + b;    // Pfeilfunktion

{ } – Objekte und Blöcke

// Objekt: Schlüssel-Wert-Paare
const user = {
  name: "Max",
  age: 30
};
console.log(user.name);          // "Max"

// Block: gehört zu if, for, function …
if (user.age >= 18) {
  console.log("volljährig");
}

// Destructuring: Werte auspacken
const { name, age } = user;

// Template-String: ${ } setzt Werte in Text ein
console.log(`${name} ist ${age} Jahre alt`);

Kombiniert

const entries = [                     // [ ] Array …
  { tag: "<a>", lang: "html" },       // { } … aus Objekten
  { tag: "for", lang: "cpp" }
];

entries.forEach((entry) => {          // ( ) Parameter, { } Block
  console.log(entry.tag);
});

Tipps & typische Fehler

  • Jede öffnende Klammer braucht eine schließende. VS Code färbt zusammengehörige Klammern gleich ein.
  • Fehlermeldung „Unexpected token“ oder „missing ) after argument list“? Meist fehlt irgendwo eine Klammer.
  • Leere Klammern haben auch Bedeutung: [] = leeres Array, {} = leeres Objekt, fn() = Aufruf ohne Argumente.
