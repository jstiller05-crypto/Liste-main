Klassen

Eigene Datentypen mit class bauen: __init__ und self, Methoden, Vererbung – und @dataclass für Klassen, die vor allem Daten halten.

Was ist das?

Eine Klasse ist ein Bauplan: Sie legt fest, welche Daten (Attribute) und welche Funktionen (Methoden) zusammengehören. Aus dem Bauplan erzeugt man beliebig viele Objekte (Instanzen), jedes mit eigenen Werten. list, str und dict sind selbst Klassen – mit class baut man eigene.

class

# player.py
class Player:
    """Ein Spieler mit Namen und Lebenspunkten."""

    def __init__(self, name, health=100):   # Konstruktor: läuft bei Player(...)
        self.name = name                    # Attribute am Objekt anlegen
        self.health = health

    def take_damage(self, amount):          # Methode – self ist IMMER der erste Parameter
        self.health = max(0, self.health - amount)

    def is_alive(self):
        return self.health > 0


anna = Player("Anna")                       # Objekt erzeugen – kein "new" wie in C++/JS
max_player = Player("Max", health=50)

anna.take_damage(30)                        # self wird automatisch übergeben
print(anna.name, anna.health)               # Anna 70
print(max_player.is_alive())                # True
python player.py

# account.py
class Account:
    interest_rate = 0.02                    # Klassenattribut: für ALLE Objekte gleich

    def __init__(self, owner):
        self.owner = owner
        self._balance = 0                   # _ = intern

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Betrag muss positiv sein")
        self._balance += amount

    @property                               # macht aus der Methode ein Nur-Lese-Attribut
    def balance(self):
        return self._balance

    def __str__(self):
        return f"Konto von {self.owner}: {self._balance} €"


account = Account("Anna")
account.deposit(100)
print(account.balance)                      # 100 – ohne Klammern, dank @property
print(account)                              # Konto von Anna: 100 €
python account.py

Vererbung

Eine Klasse kann eine andere erweitern: Sie übernimmt alle Attribute und Methoden und ergänzt oder ersetzt einzelne. Die Basisklasse steht in Klammern hinter dem Namen.

# animals.py
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def introduce(self):
        return f"{self.name} sagt {self.speak()}"


class Dog(Animal):                          # Dog erbt von Animal
    def speak(self):                        # Methode überschreiben
        return "Wuff"


class Puppy(Dog):
    def __init__(self, name, age_weeks):
        super().__init__(name)              # Konstruktor der Basisklasse aufrufen
        self.age_weeks = age_weeks

    def speak(self):
        return super().speak() + "!"        # Basis-Methode nutzen und erweitern


for animal in [Animal("Etwas"), Dog("Rex"), Puppy("Bello", 8)]:
    print(animal.introduce())               # jedes Objekt benutzt SEIN speak()

print(isinstance(Puppy("Fifi", 3), Animal)) # True – ein Puppy ist auch ein Animal
python animals.py

@dataclass

Viele Klassen speichern nur ein paar Werte. Der Dekorator @dataclass schreibt dafür __init__, eine lesbare Ausgabe und den Vergleich mit == automatisch. Entspricht grob einem struct in C++.

# point.py
from dataclasses import dataclass, field

@dataclass
class Point:
    x: float                                # Type Hints sind hier Pflicht
    y: float = 0.0                          # mit Standardwert

    def distance_to_origin(self) -> float:  # eigene Methoden bleiben möglich
        return (self.x ** 2 + self.y ** 2) ** 0.5


@dataclass
class Inventory:
    owner: str
    items: list[str] = field(default_factory=list)   # so bekommt JEDES Objekt eine eigene Liste


p1 = Point(3, 4)
p2 = Point(3, 4)
print(p1)                                   # Point(x=3, y=4)
print(p1 == p2)                             # True – Vergleich nach Inhalt
print(p1.distance_to_origin())              # 5.0

bag = Inventory("Anna")
bag.items.append("Schwert")
print(bag)
python point.py

Tipps & typische Fehler

  • TypeError: take_damage() takes 1 positional argument but 2 were given – in der Methode fehlt self als erster Parameter.
  • NameError: name 'health' is not defined – innerhalb der Klasse immer self.health schreiben, nicht nur health.
  • Listen nicht als Klassenattribut anlegen (items = [] direkt unter class) – alle Objekte teilen sich dann dieselbe Liste. In __init__ mit self.items = [] anlegen.
  • super().__init__(...) vergessen → die Attribute der Basisklasse fehlen (AttributeError).
  • Klassennamen schreibt man in CamelCase, Methoden und Attribute in snake_case.
  • Nicht alles braucht eine Klasse: Für zwei, drei zusammengehörige Werte reicht oft ein Dict oder eine @dataclass.
