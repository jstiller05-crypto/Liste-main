XML

Auszeichnungssprache für strukturierte Daten – wie HTML, aber mit frei erfundenen Tags statt einem festen Satz.

Was ist das?

XML (eXtensible Markup Language) ist eine Auszeichnungssprache für strukturierte Daten. Anders als HTML gibt es keine feste Liste erlaubter Tags – <book>, <user> oder <rechnung> sind genauso gültig wie jedes andere selbst erfundene Tag. „Extensible“ (erweiterbar) heißt genau das: Die Sprache legt nur die SYNTAX fest, nicht die Tag-Namen.

Woher kommt das?

XML wurde 1998 vom W3C als Standard verabschiedet – als vereinfachter Nachfolger von SGML, derselben Familie, aus der auch HTML stammt.

Erstes Beispiel

<library>
  <book id="1">
    <title>Clean Code</title>
    <author>Robert C. Martin</author>
  </book>
  <book id="2">
    <title>Eloquent JavaScript</title>
    <author>Marijn Haverbeke</author>
  </book>
</library>

<library> ist das Wurzelelement, jedes <book> trägt ein Attribut (id) und enthält wiederum eigene Kind-Elemente. Mehr dazu: XML-Syntax.

Wann JSON, wann XML?

  • JSON: die erste Wahl für APIs und eigene Konfiguration – kompakter und leichter zu lesen.
  • XML: wenn ein Format schon XML vorschreibt (SVG, Office, Android), oder wenn man Attribute UND Text im selben Element braucht, oder eine formale Validierung per DTD/XSD will.
