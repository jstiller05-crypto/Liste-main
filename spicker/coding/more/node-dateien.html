Dateien mit fs

Dateien und Ordner lesen, schreiben und prüfen.

Lesen & schreiben (async/await)

import { readFile, writeFile, appendFile } from "node:fs/promises";

async function main() {
  try {
    await writeFile("notes.txt", "Erste Zeile\n", "utf-8");   // erstellen/überschreiben
    await appendFile("notes.txt", "Zweite Zeile\n");           // anhängen

    const content = await readFile("notes.txt", "utf-8");
    console.log("[fs] Inhalt:\n" + content);
  } catch (error) {
    console.error("[fs] Fehler:", error.message);
  }
}

main();

JSON-Datei als kleine Datenbank

import { readFile, writeFile } from "node:fs/promises";

async function loadScores() {
  try {
    const text = await readFile("scores.json", "utf-8");
    return JSON.parse(text);
  } catch {
    return [];                       // Datei fehlt noch → leere Liste
  }
}

async function saveScore(name, points) {
  const scores = await loadScores();
  scores.push({ name, points, date: new Date().toISOString() });
  await writeFile("scores.json", JSON.stringify(scores, null, 2));
  console.log(`[scores] ${name} gespeichert (${scores.length} Einträge)`);
}

await saveScore("Max", 120);

Ordner & Prüfungen

import { mkdir, readdir, stat, rm } from "node:fs/promises";
import { existsSync } from "node:fs";

await mkdir("data/saves", { recursive: true });   // Ordner (samt Unterordnern) anlegen
const files = await readdir("data");              // Dateinamen im Ordner
const info = await stat("notes.txt");             // Größe, Änderungsdatum …
console.log(info.size, "Bytes");

if (existsSync("old.txt")) {
  await rm("old.txt");                            // löschen (endgültig!)
}

Drei Schreibweisen

VarianteBeispielBewertung
Promisesawait readFile(…)Modern, empfohlen
SynchronreadFileSync(…)Einfach, blockiert aber das Programm – ok für kleine Skripte
CallbacksreadFile(…, (err, data) => {})Alter Stil

Tipps & typische Fehler

  • Die Kodierung "utf-8" angeben – sonst bekommst du einen Buffer statt Text.
  • Relative Pfade gelten vom Ordner aus, in dem du node startest – nicht vom Ordner der Datei. Sicherer: path.join(import.meta.dirname, …).
  • rm löscht ohne Papierkorb.
