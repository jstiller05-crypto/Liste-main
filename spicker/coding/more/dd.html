<dd>

Die Beschreibung zu einem Begriff in einer Beschreibungsliste (<dl>).

Was ist das?

<dd> (description details) erklärt den vorherigen <dt>-Begriff. Browser rücken <dd> standardmäßig ein.

Beispiel

<dl>
  <dt>HTML</dt>
  <dd>Beschreibt die Struktur einer Webseite.</dd>

  <dt>CSS</dt>
  <dd>Bestimmt das Aussehen.</dd>

  <dt>JavaScript</dt>
  <dt>JS</dt>                      <!-- mehrere Begriffe … -->
  <dd>Macht die Seite interaktiv.</dd>  <!-- … eine Beschreibung -->
</dl>
HTML
Beschreibt die Struktur einer Webseite.
CSS
Bestimmt das Aussehen.

Tipps & typische Fehler

  • <dd> darf auch Absätze, Listen oder Links enthalten.
