HTML · Text

<mark>

Hebt Text wie mit einem Textmarker hervor.

Was ist das?

<mark> markiert Stellen, die in einem bestimmten Zusammenhang relevant sind – typisch: Suchtreffer im Text.

Beispiel

<p>Suchergebnis für „Tabelle“: Eine <mark>Tabelle</mark> besteht aus Zeilen und Spalten.</p>

Suchergebnis für „Tabelle“: Eine Tabelle besteht aus Zeilen und Spalten.

Tipps & typische Fehler

  • Die gelbe Standardfarbe kannst du mit CSS ändern: mark { background: …; }.
  • Für „wichtig“ ist <strong> passender, für Betonung <em>.
