Variablen & Datentypen

let, const und die Grundtypen: Text, Zahlen, Wahrheitswerte, null und undefined.

Variablen anlegen

let score = 0;          // kann später geändert werden
const name = "Max";     // kann NICHT neu zugewiesen werden
score = 10;             // ok
// name = "Tom";        // Fehler: Assignment to constant variable

var old = 1;            // alte Schreibweise – heute nicht mehr verwenden
SchlüsselwortNeu zuweisen?Wann?
constNeinStandard – immer, wenn sich die Variable nicht ändert
letJaZähler, Zwischenergebnisse, Werte, die sich ändern
varJaVeraltet – hat verwirrende Regeln, nicht mehr nutzen

console.log(typeof "Hallo");   // "string"
console.log(typeof 42);        // "number"
console.log(typeof true);      // "boolean"
console.log(typeof [1, 2]);    // "object"  – Arrays sind Objekte
console.log(Array.isArray([1, 2]));  // true – so prüft man auf Array

Typen umwandeln

Number("42");        // 42
Number("abc");       // NaN  (Not a Number)
parseInt("42px");    // 42   – liest Zahl am Anfang
String(42);          // "42"
Boolean("");         // false
Boolean("text");     // true

// Achtung: + mit Text hängt an statt zu rechnen
"5" + 3;             // "53"
Number("5") + 3;     // 8

Truthy & Falsy

In Bedingungen wird jeder Wert zu true oder false. Diese Werte gelten als falsy:

false, 0, "", null, undefined, NaN   // alles andere ist truthy

const input = "";
if (!input) {
  console.log("Feld ist leer");
}

Gültigkeitsbereich (Scope)

const a = 1;             // global – überall sichtbar

if (true) {
  const b = 2;           // nur innerhalb dieser { } sichtbar
  console.log(a, b);     // 1 2
}
// console.log(b);       // Fehler: b is not defined

Tipps & typische Fehler

  • Standardmäßig const nehmen, let nur wenn nötig – so siehst du sofort, was sich ändert.
  • Variablennamen: camelCase (userName), nicht mit Zahl beginnen, keine Leerzeichen.
  • Werte aus Eingabefeldern (input.value) sind immer Strings – vor dem Rechnen umwandeln.
