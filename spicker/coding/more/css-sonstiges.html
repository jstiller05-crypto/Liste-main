Weitere nützliche Eigenschaften

Kleinere Eigenschaften, die man ständig braucht: Cursor, Listen, Bilder, Scrollen, Umbrüche.

Übersicht

EigenschaftBeispielWirkung
cursorpointer, not-allowed, text, grabMauszeiger über dem Element
list-stylenoneAufzählungspunkte entfernen
object-fitcover, containWie ein Bild seine Box füllt
aspect-ratio16 / 9Festes Seitenverhältnis
overflow-wrapbreak-wordSehr lange Wörter umbrechen
user-selectnoneText nicht markierbar
pointer-eventsnoneKlicks gehen durch das Element hindurch
scroll-behaviorsmoothWeiches Scrollen bei Sprungmarken
outline2px solid #4f8cffRahmen außen, ohne Platz zu verbrauchen (Fokus)
filterblur(4px), grayscale(1)Grafik-Filter
accent-color#4f8cffFarbe von Checkboxen, Radios, Schiebereglern
allunsetAlle Browser-Styles eines Elements zurücksetzen

Beispiele

html { scroll-behavior: smooth; }              /* Sprunglinks scrollen weich */

nav ul { list-style: none; padding: 0; }      /* Menü ohne Punkte */

.avatar {
  width: 80px;
  aspect-ratio: 1;                            /* quadratisch */
  object-fit: cover;                          /* Bild füllt, ohne zu verzerren */
  border-radius: 50%;
}

input[type="checkbox"] { accent-color: #4f8cff; }

.disabled { opacity: .5; pointer-events: none; cursor: not-allowed; }
  cursor: pointer   cursor: not-allowed

  • Vieles davon lässt sich in den Entwicklertools (F12) live ausprobieren: Element wählen, bei „Styles“ eine neue Eigenschaft eintippen.
