const, constexpr & auto

Werte unveränderlich machen und den Compiler den Typ bestimmen lassen.

const – nicht veränderbar

const int MAX_LEVEL = 10;
// MAX_LEVEL = 11;      // Fehler: assignment of read-only variable

const double PI = 3.14159;

Konstanten schützen vor versehentlichen Änderungen und machen klar, welche Werte fest sind.

const bei Referenzen & Methoden

// Parameter: nur lesen, keine Kopie
void printName(const std::string& name) {
    std::cout << name << "\n";
}

class Player {
public:
    int getScore() const {   // const-Methode: ändert das Objekt nicht
        return score;
    }
private:
    int score = 0;
};

constexpr – zur Compile-Zeit berechnet

constexpr int SECONDS_PER_DAY = 24 * 60 * 60;   // steht schon beim Kompilieren fest

constexpr int square(int x) {
    return x * x;
}
constexpr int area = square(5);   // 25, berechnet vom Compiler

auto – Typ automatisch

auto count = 5;              // int
auto price = 9.99;           // double
auto name = std::string("Max");
auto it = numbers.begin();   // std::vector<int>::iterator – spart Tipparbeit

for (const auto& entry : entries) {   // häufigster Einsatz
    // …
}

Der Typ steht trotzdem fest – auto heißt nur, dass der Compiler ihn aus dem Startwert ableitet.

Typ-Aliase

using Score = int;
using TaskList = std::vector<std::pair<std::string, int>>;

TaskList tasks;   // statt des langen Typs

Tipps & typische Fehler

  • Faustregel: Alles const, was sich nicht ändern muss.
  • auto bei langen oder offensichtlichen Typen nutzen – bei einfachen Zahlen ist der ausgeschriebene Typ oft lesbarer.
  • Konstanten-Namen oft in GROSSBUCHSTABEN: MAX_LEVEL.
