Strings

Text untersuchen, zerlegen, zusammensetzen und formatieren – mit den Methoden, die jeder str schon mitbringt.

Was ist das?

Ein String (str) ist eine Zeichenkette – Text in einfachen oder doppelten Anführungszeichen. Strings sind in Python unveränderbar: Jede Methode liefert einen neuen String, das Original bleibt, wie es ist.

Schreibweisen

# quotes.py
a = "doppelte Anführungszeichen"
b = 'einfache – völlig gleichwertig'
c = "It's okay"                     # ' innerhalb von " braucht kein Escape
d = "Zeile 1\nZeile 2\tmit Tab"     # \n = Zeilenumbruch, \t = Tabulator
e = r"\d+\n"                        # r = roh: \n bleibt \n (gut für Regex)
f = """Text über
mehrere Zeilen"""                   # drei Anführungszeichen

print(a, b, c, d, e, f, sep="\n")

String-Methoden

# methods.py
text = "  Hallo Welt  "

print(text.strip())                 # "Hallo Welt" – Leerraum an beiden Enden weg
print(text.lower())                 # alles klein
print(text.upper())                 # alles groß
print(text.strip().replace("Welt", "Python"))   # Methoden verketten

name = "anna schmidt"
print(name.capitalize())            # Anna schmidt
print(name.title())                 # Anna Schmidt
print(len(name))                    # 12 – Länge mit len(), nicht .length

print(name.startswith("anna"))      # True
print(name.endswith(".py"))         # False
print("sch" in name)                # True – enthält?
print(name.find("sch"))             # 5  – Position, -1 wenn nicht gefunden
print(name.count("n"))              # 2

print("42".isdigit())               # True – nur Ziffern?
print("abc".isalpha())              # True – nur Buchstaben?

print(name[0], name[-1])            # a t  – einzelne Zeichen per Index
print(name[:4])                     # anna – Slicing wie bei Listen

split & join

split zerlegt einen Text in eine Liste, join setzt eine Liste zu einem Text zusammen. Ungewohnt: join ruft man auf dem Trennzeichen auf, nicht auf der Liste.

# splitjoin.py
line = "Anna;25;Berlin"
parts = line.split(";")             # ['Anna', '25', 'Berlin']
print(parts)

name, age, city = parts             # direkt in Variablen auspacken
print(name, int(age) + 1, city)

words = "viele   Leerzeichen  hier".split()   # ohne Argument: an Leerraum trennen
print(words)                        # ['viele', 'Leerzeichen', 'hier']

print(", ".join(words))             # viele, Leerzeichen, hier
print("-".join(["2026", "01", "31"]))   # 2026-01-31

text = "Zeile 1\nZeile 2\nZeile 3"
for row in text.splitlines():       # an Zeilenumbrüchen trennen
    print(">", row)

# join braucht Strings – Zahlen vorher umwandeln
numbers = [1, 2, 3]
print(" + ".join(str(n) for n in numbers))    # 1 + 2 + 3

Formatierung

Der übliche Weg sind f-Strings. Hinter einem Doppelpunkt steht die Format-Angabe:

# formatting.py
price = 1234.5
name = "Kiwi"
ratio = 0.256

print(f"{price:.2f} €")             # 1234.50 €   – 2 Nachkommastellen
print(f"{price:10.2f}|")            # auf 10 Zeichen Breite, rechtsbündig
print(f"{name:<10}|{name:^10}|{name:>10}|")   # links, mittig, rechts
print(f"{ratio:.1%}")               # 25.6%       – als Prozent
print(f"{255:x} {255:b}")           # ff 11111111 – hexadezimal, binär
print(f"{42:05d}")                  # 00042

# Kleine Tabelle
for item, cost in [("Brot", 2.5), ("Käse", 12.99)]:
    print(f"{item:<8}{cost:>8.2f}")

# Ältere Schreibweisen – begegnen einem in fremdem Code
print("Hallo {}, du bist {}".format("Anna", 25))
print("Hallo %s, du bist %d" % ("Anna", 25))

Tipps & typische Fehler

  • text.upper() allein ändert nichts – das Ergebnis muss man speichern: text = text.upper().
  • TypeError: 'str' object does not support item assignment – text[0] = "X" geht nicht. Stattdessen neu zusammenbauen: "X" + text[1:].
  • input() und Zeilen aus Dateien haben oft Leerraum oder \n am Ende – vor dem Vergleichen strip() aufrufen.
  • Vergleiche beachten Groß-/Kleinschreibung: "Ja" == "ja" ist False. Vorher lower().
  • Viele Textstücke nicht in einer Schleife mit += sammeln, sondern in eine Liste legen und am Ende "".join(liste).
