Tabellen anlegen (CREATE TABLE)

Tabellen mit Spalten, Datentypen und Regeln erstellen, ändern und löschen.

CREATE TABLE

CREATE TABLE users (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,   -- SQLite
 -- id         INT PRIMARY KEY AUTO_INCREMENT,      -- MySQL
    name       VARCHAR(100) NOT NULL,
    email      VARCHAR(255) NOT NULL UNIQUE,
    points     INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS users ( … );   -- kein Fehler, wenn es sie schon gibt

Wichtige Datentypen

TypSpeichert
INT / INTEGERGanze Zahlen
DECIMAL(10,2)Exakte Kommazahlen (Geldbeträge)
FLOAT / REALUngefähre Kommazahlen
VARCHAR(n)Text bis n Zeichen
TEXTLanger Text
BOOLEANwahr/falsch (intern oft 0/1)
DATE / DATETIME / TIMESTAMPDatum / Datum+Uhrzeit

Regeln (Constraints)

RegelBedeutung
PRIMARY KEYEindeutige ID der Zeile, nie leer
AUTO_INCREMENT / AUTOINCREMENTID wird automatisch hochgezählt
NOT NULLFeld darf nicht leer sein
UNIQUEWert darf nur einmal vorkommen (z. B. E-Mail)
DEFAULT wertStandardwert, wenn nichts angegeben wird
FOREIGN KEY … REFERENCESVerweis auf eine andere Tabelle
CHECK (points >= 0)Eigene Bedingung

Tabellen ändern & löschen

ALTER TABLE users ADD COLUMN level INT DEFAULT 1;      -- Spalte hinzufügen
ALTER TABLE users RENAME COLUMN points TO score;        -- umbenennen
ALTER TABLE users DROP COLUMN level;                    -- Spalte entfernen

DROP TABLE users;                -- Tabelle samt Daten löschen – endgültig!
DROP TABLE IF EXISTS users;

DROP und DELETE lassen sich nicht rückgängig machen. Vorher eine Sicherung (Backup) machen.

Tipps & typische Fehler

  • Tabellennamen im Plural und klein (users, tasks), Spalten im Singular (name, email).
  • Für Geld nie FLOAT verwenden – Rundungsfehler. Besser DECIMAL oder in Cent als INT.
  • Jede Tabelle bekommt einen Primärschlüssel.
