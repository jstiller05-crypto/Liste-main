npm & package.json

Pakete installieren, Projekte einrichten und Skripte starten.

Projekt anlegen

mkdir mein-projekt
cd mein-projekt
npm init -y            # erstellt package.json mit Standardwerten

Pakete installieren

npm install express            # Abhängigkeit fürs Programm
npm install --save-dev nodemon # nur für die Entwicklung
npm install                    # alle Pakete aus package.json installieren
npm uninstall express          # entfernen
npm update                     # aktualisieren
npx cowsay "Hallo"             # Paket einmalig ausführen, ohne es zu installieren
Datei/OrdnerBedeutung
package.jsonProjektbeschreibung: Name, Skripte, benötigte Pakete
package-lock.jsonExakte Versionen aller Pakete – mit committen
node_modules/Die heruntergeladenen Pakete – nicht committen

package.json

{
  "name": "mein-projekt",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "node server.js",
    "dev": "node --watch server.js"
  },
  "dependencies": {
    "express": "^4.19.0"
  },
  "devDependencies": {
    "nodemon": "^3.1.0"
  }
}
FeldBedeutung
"type": "module"import/export statt require verwenden
scriptsEigene Befehle, gestartet mit npm run name
dependenciesPakete, die das Programm zum Laufen braucht
devDependenciesNur fürs Entwickeln (Tests, Tools)
^4.19.0Version 4.19.0 oder neuer, aber unter 5.0.0

Skripte ausführen

npm start        # führt "start" aus (Kurzform)
npm run dev      # führt "dev" aus

Tipps & typische Fehler

  • node_modules nie ins Git-Repository – mit npm install lässt sich der Ordner jederzeit neu erzeugen.
  • Vor dem Installieren eines unbekannten Pakets kurz prüfen: Wird es gepflegt? Wie viele Downloads? Pakete können Sicherheitslücken enthalten.
  • npm audit zeigt bekannte Sicherheitsprobleme in den installierten Paketen.
