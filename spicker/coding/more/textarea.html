HTML · Formulare

<textarea>

Ein mehrzeiliges Textfeld für längere Eingaben wie Nachrichten oder Kommentare.

Was ist das?

Anders als <input> hat <textarea> ein End-Tag. Text zwischen den Tags ist der Startinhalt.

Beispiel

<label for="message">Nachricht</label>
<textarea id="message" name="message" rows="4" cols="40"
          maxlength="500" placeholder="Schreib etwas …"></textarea>

Wichtige Attribute

AttributBedeutung
rows / colsSichtbare Zeilen / Zeichen pro Zeile
maxlengthMaximale Zeichenanzahl
placeholderHinweistext, solange leer
requiredPflichtfeld
readonly / disabledNur lesen / deaktiviert
wraphard = Zeilenumbrüche werden mitgeschickt

Zeichenzähler mit JavaScript

<textarea id="bio" maxlength="200"></textarea>
<p id="counter">0 / 200</p>

<script>
  const bio = document.getElementById("bio");
  const counter = document.getElementById("counter");

  bio.addEventListener("input", () => {
    counter.textContent = bio.value.length + " / 200";
  });
</script>

Größe steuern (CSS)

textarea {
  width: 100%;
  resize: vertical;   /* nur in der Höhe ziehbar: none | both | horizontal | vertical */
}

Tipps & typische Fehler

  • Keine Leerzeichen oder Zeilenumbrüche zwischen <textarea> und </textarea> lassen – sie werden sonst Teil des Inhalts.
  • Inhalt per JavaScript immer über .value lesen und setzen, nicht über .textContent.
