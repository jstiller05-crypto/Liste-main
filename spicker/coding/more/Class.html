CSS-Klassen (class)

Mit Klassen gibst du Elementen einen Namen, um sie mit CSS zu gestalten oder mit JavaScript zu finden.

Was ist das?

Das Attribut class gibt einem Element einen oder mehrere Namen. Im CSS sprichst du die Klasse mit einem Punkt an. Anders als eine ID darf eine Klasse beliebig oft auf der Seite vorkommen.

Syntax

<!-- HTML -->
<div class="card">Inhalt</div>

/* CSS */
.card {
  padding: 16px;
  border-radius: 10px;
}

Mehrere Klassen kombinieren

<button class="button filter-btn active">HTML</button>

/* trifft alle Buttons */
.button { padding: 6px 14px; }

/* trifft nur Buttons, die AUCH "active" haben (ohne Leerzeichen!) */
.button.active { background: #4f8cff; }

/* trifft .button INNERHALB von .button-row (mit Leerzeichen) */
.button-row .button { margin: 4px; }

So lassen sich z. B. Filter-Buttons bauen: alle teilen .button, der gewählte bekommt zusätzlich .active.

Klassen mit JavaScript ändern

BefehlWirkung
el.classList.add("active")Klasse hinzufügen
el.classList.remove("active")Klasse entfernen
el.classList.toggle("active")An/aus umschalten
el.classList.contains("active")Prüfen: true/false
document.querySelectorAll(".card")Alle Elemente mit der Klasse finden

Tipps & typische Fehler

  • Klassennamen beschreiben, was etwas ist (.warning), nicht wie es aussieht (.red-text).
  • Keine Leerzeichen im Namen – Bindestriche verwenden: class="filter-group".
  • Groß-/Kleinschreibung zählt: .Card und .card sind verschieden.
