Variable

Eine Variable ist ein benannter Speicherplatz für einen Wert, der sich im Lauf des Programms ändern kann. Die ausführliche Erklärung je Sprache steht bereits bei den Sprachseiten des Spickers – hier nur der direkte Vergleich:

C++JavaScriptLua
int x = 5;let x = 5;local x = 5

Datentyp

Der Datentyp legt fest, welche Art Wert eine Variable speichert (Zahl, Text, Wahrheitswert …) und bestimmt, welche Operationen damit erlaubt sind.

C++JavaScriptLua
int, double, bool, string – fest deklariertnumber, string, boolean – dynamischnumber, string, boolean – dynamisch

Kontrollstruktur (if / Schleife)

Eine Kontrollstruktur steuert, OB und WIE OFT ein Codeblock ausgeführt wird – die zwei wichtigsten sind Bedingungen (if) und Schleifen.

C++JavaScriptLua
if (x > 0) { } else { }if (x > 0) { } else { }if x > 0 then … else … end
for (int i=0; i<5; i++) { }for (let i=0; i<5; i++) { }for i=1,5 do … end

Funktion

Eine Funktion ist ein benannter, wiederverwendbarer Codeblock, den man mit unterschiedlichen Eingabewerten (Parametern) aufrufen kann, statt denselben Code immer wieder abzuschreiben.

C++JavaScriptLua
int add(int a, int b) { return a+b; }function add(a, b) { return a+b; }function add(a, b) return a+b end

Rekursion

Rekursion heißt: Eine Funktion ruft SICH SELBST auf, um ein Problem in kleinere, gleichartige Teilprobleme zu zerlegen – bis ein „Basisfall“ erreicht ist, der ohne weiteren Aufruf direkt beantwortet werden kann. Am Beispiel Fakultät (5! = 5·4·3·2·1):

C++JavaScriptLua
int f(int n){ return n<=1 ? 1 : n*f(n-1); } function f(n){ return n<=1 ? 1 : n*f(n-1); } function f(n) if n<=1 then return 1 else return n*f(n-1) end end
Ohne Basisfall (hier n <= 1) ruft sich eine rekursive Funktion unendlich oft selbst auf – das Programm stürzt irgendwann mit einem „Stack Overflow“ ab.

Kommentar

Ein Kommentar ist Text im Quellcode, den der Compiler/Interpreter komplett ignoriert – gedacht für Erklärungen an andere Menschen (oder das eigene zukünftige Ich).

C++JavaScriptLua
// Kommentar// Kommentar-- Kommentar

Tipps & typische Fehler

  • Diese Seite erklärt die GEMEINSAMEN Konzepte – wie genau Variablen, Schleifen, Funktionen in C++, JavaScript oder Lua im Detail funktionieren, steht bereits ausführlich bei den jeweiligen Sprachseiten des Spickers.
  • Ein Kommentar, der nicht mehr zum Code passt (weil der Code sich geändert hat, der Kommentar aber nicht), ist schlimmer als gar kein Kommentar – er führt in die Irre.
  • Rekursion ist elegant, aber nicht immer die schnellste Lösung – manchmal ist eine Schleife mit derselben Wirkung einfacher nachzuvollziehen und sparsamer im Speicher.
