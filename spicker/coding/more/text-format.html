Tipps & typische Fehler

  • Soll etwas nur anders aussehen, ist CSS die bessere Wahl (font-weight, text-decoration).
  • <u> sparsam einsetzen – Unterstrichenes wird schnell für einen Link gehalten.
  • <sup> und <sub> verändern die Zeilenhöhe leicht. Mit line-height: 0 bei sup, sub lässt sich das ausgleichen.
