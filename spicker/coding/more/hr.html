HTML · Text

<hr>

Trennt zwei inhaltliche Abschnitte – wird als waagerechte Linie dargestellt.

Was ist das?

<hr> steht für einen thematischen Wechsel, z. B. einen Szenenwechsel in einer Geschichte. Wie <br> ist es ein leeres Element ohne End-Tag.

Beispiel

<p>Kapitel 1 endet hier.</p>
<hr>
<p>Kapitel 2 beginnt.</p>

Kapitel 1 endet hier.

Kapitel 2 beginnt.

Linie mit CSS gestalten

hr {
  border: none;
  border-top: 1px solid #4a4a4a;
  margin: 24px 0;
}

Tipps & typische Fehler

  • Ist die Linie nur Dekoration ohne inhaltlichen Wechsel, reicht ein CSS-Rahmen (border-bottom).

Verwandte Seiten

<br> / <wbr>
