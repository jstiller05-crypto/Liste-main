C++ · Daten

std::map, set & pair

Werte über einen Schlüssel nachschlagen, doppelte Einträge vermeiden und Paare bilden.

std::map – Schlüssel → Wert

#include <map>

std::map<std::string, int> highscores;
highscores["Max"] = 120;           // einfügen oder überschreiben
highscores["Anna"] = 150;
highscores.insert({"Tom", 90});

std::cout << highscores["Anna"] << "\n";   // 150

if (highscores.count("Lisa") == 0) {       // existiert der Schlüssel?
    std::cout << "Lisa hat noch keinen Highscore\n";
}
// C++20: highscores.contains("Lisa")

for (const auto& [name, score] : highscores) {   // automatisch nach Schlüssel sortiert
    std::cout << name << ": " << score << "\n";
}

highscores.erase("Tom");

Achtung: map["Unbekannt"] legt den Schlüssel mit Wert 0 an. Zum reinen Nachsehen count(), find() oder at() verwenden.

std::unordered_map

Wie map, aber unsortiert und bei vielen Einträgen meist schneller. #include <unordered_map>

std::set – jeder Wert nur einmal

#include <set>

std::set<int> usedNumbers;
usedNumbers.insert(5);
usedNumbers.insert(3);
usedNumbers.insert(5);           // wird ignoriert – schon vorhanden

std::cout << usedNumbers.size() << "\n";   // 2
if (usedNumbers.count(3)) { /* schon benutzt */ }

std::pair

std::pair<std::string, int> entry = {"Max", 120};
std::cout << entry.first << " " << entry.second << "\n";

auto [name, score] = entry;      // auspacken (structured binding)

Welcher Container?

ContainerWann?
std::vectorListe in fester Reihenfolge – Standardwahl
std::arrayFeste Anzahl, bekannt beim Kompilieren
std::mapNachschlagen per Schlüssel, sortiert
std::unordered_mapNachschlagen per Schlüssel, schnell, unsortiert
std::setEindeutige Werte, sortiert

Tipps & typische Fehler

  • Beim Durchlaufen einer map ist die Reihenfolge immer nach Schlüssel sortiert.
  • Mit einem std::set lassen sich z. B. doppelte Zufallsaufgaben vermeiden.
