display & Sichtbarkeit

Wie sich ein Element im Layout verhält – als Block, im Textfluss oder gar nicht.

Die wichtigsten Werte

displayVerhaltenTypisch für
blockNeue Zeile, volle Breite, width/height wirkendiv, p, h1, section
inlineIm Textfluss, width/height wirken nichtspan, a, strong
inline-blockIm Textfluss, aber width/height/padding wirkenButtons, Badges
flexFlexbox-Container (Kinder in Reihe/Spalte)Menüs, Leisten, Karten
gridGrid-Container (Raster)Seitenlayouts, Galerien
noneElement verschwindet komplettAusblenden

Beispiel

<span class="badge">Neu</span> <span class="badge">CSS</span>
.badge {
  display: inline-block;    /* bleibt in der Zeile, padding wirkt aber richtig */
  padding: 2px 10px;
  border-radius: 999px;
  background: #4f8cff;
}

Ausblenden – drei Wege

CSSSichtbar?Nimmt Platz ein?Klickbar?
display: noneNeinNeinNein
visibility: hiddenNeinJa (Lücke bleibt)Nein
opacity: 0NeinJaJa!
 
// Mit JavaScript ein-/ausblenden
element.style.display = "none";   // weg
element.style.display = "";       // zurück zum CSS-Wert

// oder besser über eine Klasse:
element.classList.toggle("hidden");   // CSS: .hidden { display: none; }

Tipps & typische Fehler

  • display: none lässt sich nicht animieren – für Ein-/Ausblend-Effekte opacity + visibility nutzen.
  • Das HTML-Attribut hidden wirkt wie display: none.
