HTML · Grundgerüst

<body>

Enthält alles, was auf der Seite sichtbar ist.

Was ist das?

Überschriften, Texte, Bilder, Tabellen, Formulare – alles Sichtbare steht in <body>. Pro Seite gibt es genau ein <body>.

Typischer Aufbau

<body>
  <header>Logo, Titel, Navigation</header>
  <nav>Hauptmenü</nav>
  <main>
    <article>Der eigentliche Inhalt</article>
    <aside>Randinfos</aside>
  </main>
  <footer>Impressum, Kontakt</footer>
</body>

Tipps & typische Fehler

  • Wenn du CSS auf body setzt (z. B. background-color, font-family), gilt es für die ganze Seite.
  • Browser geben body standardmäßig margin: 8px. Viele setzen deshalb body { margin: 0; }.

Verwandte Seiten
