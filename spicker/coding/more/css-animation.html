Transition, Transform & Animation

Weiche Übergänge, Verschieben/Drehen/Skalieren und selbst definierte Animationen.

transition – weicher Übergang

Ändert sich ein Wert (z. B. bei :hover), springt er normalerweise sofort. Mit transition wird daraus ein Übergang.

.button {
  background: #3a3a3a;
  transition: background-color 0.2s ease, transform 0.2s ease;
  /*          Eigenschaft     Dauer Kurve */
}

.button:hover {
  background: #4f8cff;
  transform: translateY(-2px);
}

transform – verändern ohne das Layout zu stören

FunktionWirkung
translate(20px, 10px)Verschieben (x, y)
translateY(-2px)Nur senkrecht verschieben
scale(1.1)Vergrößern (1 = normal)
rotate(45deg)Drehen
skew(10deg)Neigen
 
transform: translateY(-2px) scale(1.05);   /* mehrere kombinieren */

@keyframes – eigene Animation

@keyframes pulse {
  0%   { transform: scale(1);    opacity: 1; }
  50%  { transform: scale(1.1);  opacity: 0.7; }
  100% { transform: scale(1);    opacity: 1; }
}

.dot {
  animation: pulse 1.5s ease-in-out infinite;
  /*         Name  Dauer Kurve     Wiederholung */
}

Wichtige Werte

EigenschaftBeispiele
Zeitkurveease, linear, ease-in, ease-out, ease-in-out
animation-iteration-count1, 3, infinite
animation-directionnormal, alternate (hin und zurück)
animation-delay0.5s – Verzögerung
animation-fill-modeforwards – Endzustand beibehalten

Tipps & typische Fehler

  • Am flüssigsten laufen transform und opacity – width, top oder margin zu animieren ruckelt eher.
  • transition: all ist bequem, animiert aber auch Dinge, die man nicht will – lieber die Eigenschaften nennen.
  • Rücksicht auf Nutzer, die Bewegung nicht vertragen: @media (prefers-reduced-motion: reduce) { * { animation: none; } }.
