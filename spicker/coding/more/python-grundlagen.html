Variablen, Datentypen & Ein-/Ausgabe

Werte speichern, Typen umwandeln, mit print ausgeben, mit input einlesen – und Text bequem mit f-Strings zusammenbauen.

Was ist das?

Eine Variable ist ein Name für einen Wert. In Python legt man sie einfach durch eine Zuweisung an – ohne Schlüsselwort (let, local) und ohne Typangabe (int). Der Typ gehört zum Wert, nicht zum Namen: Dieselbe Variable darf später einen Wert eines anderen Typs bekommen.

Variablen

# variables.py
age = 25                 # Ganzzahl
price = 9.99             # Kommazahl (mit Punkt!)
name = "Anna"            # Text
is_student = True        # Wahrheitswert

age = age + 1            # neuen Wert zuweisen
age += 1                 # Kurzform, dasselbe
x, y = 10, 20            # zwei Variablen in einer Zeile
x, y = y, x              # Werte tauschen – ohne Hilfsvariable

print(age, price, name, is_student, x, y)
python variables.py

Namen schreibt man in Python klein mit Unterstrich (user_name, „snake_case“). Konstanten schreibt man groß (MAX_PLAYERS = 4) – das ist nur eine Abmachung, Python verhindert das Ändern nicht.

Typumwandlung

Python wandelt Typen nicht heimlich um: "3" + 4 ist ein Fehler (in JS käme "34" heraus). Man wandelt ausdrücklich um, indem man den Typnamen wie eine Funktion aufruft.

# convert.py
text = "42"
number = int(text)            # "42"  -> 42
print(number + 8)             # 50

print(float("3.5") * 2)       # 7.0
print(str(99) + " Punkte")    # "99 Punkte"
print(int(3.99))              # 3   – schneidet ab, rundet NICHT
print(round(3.99))            # 4   – rundet
print(round(3.14159, 2))      # 3.14 – auf 2 Nachkommastellen

print(bool(0), bool(""), bool([]))    # False False False – "leer" ist falsch
print(bool(5), bool("a"), bool([0]))  # True True True
python convert.py

Ausgabe mit print()

# output.py
print("Hallo")                      # eine Zeile
print("a", "b", "c")                # mehrere Werte, getrennt durch Leerzeichen
print("a", "b", "c", sep="-")       # eigenes Trennzeichen -> a-b-c
print("ohne Umbruch", end="")       # end ersetzt den Zeilenumbruch
print(" ... geht hier weiter")
print()                             # nur eine Leerzeile
python output.py

Eingabe mit input()

input() wartet auf eine Eingabe im Terminal und liefert sie immer als Text (str). Für Zahlen muss man umwandeln.

# ask.py
name = input("Wie heißt du? ")
age = int(input("Wie alt bist du? "))    # Text -> Ganzzahl

print(f"Hallo {name}, nächstes Jahr bist du {age + 1}.")
python ask.py

f-Strings

Ein f vor dem Anführungszeichen macht aus einem Text eine Vorlage: Alles in { } wird ausgerechnet und eingesetzt. Entspricht dem Template-String `Hallo ${name}` in JavaScript.

# fstrings.py
name = "Anna"
points = 1234.5678

print(f"Hallo {name}!")
print(f"2 + 3 = {2 + 3}")              # beliebige Ausdrücke erlaubt
print(f"{points:.2f}")                 # 2 Nachkommastellen -> 1234.57
print(f"{points:,.0f}")                # Tausender-Trenner  -> 1,235
print(f"{name:>10}|")                  # rechtsbündig auf 10 Zeichen
print(f"{name:<10}|")                  # linksbündig
print(f"{7:03d}")                      # mit Nullen auffüllen -> 007
print(f"{name=}")                      # Debug-Hilfe -> name='Anna'
python fstrings.py

Tipps & typische Fehler

  • TypeError: can only concatenate str (not "int") to str – Text und Zahl mit + verbunden. Lösung: f-String oder str(zahl).
  • ValueError: invalid literal for int() – int("abc") oder int("3.5"). Eingaben mit try/except absichern, siehe Fehlerbehandlung.
  • NameError: name 'x' is not defined – Variable benutzt, bevor sie einen Wert bekommen hat (oder Tippfehler im Namen).
  • 0.1 + 0.2 ergibt 0.30000000000000004 – das ist in allen Sprachen so (Kommazahlen sind binär gespeichert). Für Geld mit Cent als int rechnen.
  • Vergleich mit None schreibt man x is None, nicht x == None.
