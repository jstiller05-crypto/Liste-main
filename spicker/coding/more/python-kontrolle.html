Python · Kontrollstrukturen

if, Schleifen & match

Entscheidungen mit if/elif/else, Wiederholungen mit for und while, Abkürzungen mit break/continue und Fallunterscheidung mit match/case.

Was ist das?

Kontrollstrukturen steuern, welche Zeilen ausgeführt werden (Bedingungen) und wie oft (Schleifen). In Python enden die Kopfzeilen mit einem Doppelpunkt, der Block darunter ist eingerückt. Runde Klammern um die Bedingung braucht man nicht.

if / elif / else

# grade.py
points = 72

if points >= 90:
    print("sehr gut")
elif points >= 50:              # elif = "else if", beliebig viele möglich
    print("bestanden")
else:
    print("nicht bestanden")

# Bedingungen verknüpfen: and, or, not (statt &&, ||, !)
age = 17
has_ticket = True
if age >= 16 and has_ticket:
    print("Einlass")

# Bereich prüfen – Vergleiche lassen sich verketten
if 0 <= points <= 100:
    print("gültige Punktzahl")

# Kurzform in einer Zeile (wie  bedingung ? a : b  in C++/JS)
status = "voll" if points == 100 else "nicht voll"
print(status)

for mit range()

Die for-Schleife läuft in Python immer über eine Folge von Werten. Die klassische Zählschleife for (int i = 0; i < 5; i++) gibt es nicht – dafür erzeugt range() die Zahlenfolge.

# loops.py
for i in range(5):              # 0, 1, 2, 3, 4  (die 5 ist NICHT dabei)
    print(i, end=" ")
print()

for i in range(1, 6):           # 1 bis 5  (Start, Ende exklusiv)
    print(i, end=" ")
print()

for i in range(10, 0, -2):      # 10, 8, 6, 4, 2  (dritter Wert = Schrittweite)
    print(i, end=" ")
print()

# Direkt über eine Liste laufen – kein Index nötig
colors = ["rot", "grün", "blau"]
for color in colors:
    print(color)

# Index UND Wert: enumerate
for index, color in enumerate(colors, start=1):
    print(index, color)

# Über einen Text laufen: Zeichen für Zeichen
for char in "abc":
    print(char)

while

while wiederholt, solange die Bedingung wahr ist – passend, wenn man vorher nicht weiß, wie oft.

# countdown.py
count = 3
while count > 0:
    print(count)
    count -= 1                  # ohne diese Zeile: Endlosschleife!
print("Start!")
python countdown.py

Eine Endlosschleife bricht man im Terminal mit Strg+C ab.

break & continue

# search.py
numbers = [4, 7, -1, 9, 12]

for number in numbers:
    if number < 0:
        continue                # diesen Durchlauf überspringen
    if number > 10:
        break                   # Schleife ganz verlassen
    print(number)               # gibt 4, 7, 9 aus

# Typisches Muster: so lange fragen, bis die Eingabe passt
while True:
    answer = input("Weiter? (j/n) ")
    if answer in ("j", "n"):
        break
    print("Bitte j oder n eingeben.")
python search.py

Besonderheit: Eine Schleife kann ein else haben. Es läuft nur, wenn die Schleife nicht per break verlassen wurde – praktisch für „nichts gefunden“.

match / case

Ab Python 3.10. Entspricht switch in C++/JS, aber ohne break – es wird immer nur ein Fall ausgeführt.

# command.py
command = "stop"

match command:
    case "start":
        print("Los geht's")
    case "stop" | "quit":       # | = oder
        print("Ende")
    case _:                     # _ = alles andere (wie default)
        print("Unbekannter Befehl")

# match kann auch Strukturen zerlegen
point = (0, 5)
match point:
    case (0, 0):
        print("Ursprung")
    case (0, y):                # x ist 0, y wird als Variable gefüllt
        print(f"auf der y-Achse bei {y}")
    case (x, y):
        print(f"irgendwo: {x}, {y}")

Tipps & typische Fehler

  • range(5) endet bei 4. Für 1 bis 5 schreibt man range(1, 6).
  • = weist zu, == vergleicht. if x = 5: ist in Python ein SyntaxError (in C++ ein versteckter Fehler).
  • Eine Liste nicht verändern, während man mit for über sie läuft – lieber eine neue Liste bauen.
  • Leere Liste, leerer Text, 0 und None gelten als falsch: if items: heißt „wenn die Liste nicht leer ist“.
  • In match ist ein einfacher Name wie case x: kein Vergleich mit der Variablen x, sondern fängt alles ein.
