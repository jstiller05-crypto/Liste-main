Funktionen

Funktionen mit mehreren Rückgabewerten, variablen Argumenten und Closures.

Grundform

local function add(a, b)
    return a + b
end

print(add(2, 3))        --> 5

-- Funktionen sind Werte:
local greet = function(name)
    return "Hallo " .. name
end

Mehrere Rückgabewerte

local function minMax(list)
    local min, max = math.huge, -math.huge
    for _, v in ipairs(list) do
        if v < min then min = v end
        if v > max then max = v end
    end
    return min, max
end

local lowest, highest = minMax({ 4, 9, 1 })
print(lowest, highest)     --> 1  9

Standardwerte & variable Argumente

local function greet(name, greeting)
    greeting = greeting or "Hallo"          -- Standardwert
    return greeting .. ", " .. name
end

local function sum(...)                     -- beliebig viele Argumente
    local total = 0
    for _, n in ipairs({ ... }) do
        total = total + n
    end
    return total
end
print(sum(1, 2, 3))   --> 6

Closures

local function makeCounter()
    local count = 0                 -- bleibt zwischen Aufrufen erhalten
    return function()
        count = count + 1
        return count
    end
end

local counter = makeCounter()
print(counter())   --> 1
print(counter())   --> 2

Tipps & typische Fehler

  • local function name() statt function name() – sonst ist die Funktion global.
  • Fehlende Argumente sind einfach nil, zu viele werden ignoriert – Lua meldet keinen Fehler.
  • _ ist ein übliches Zeichen für „diesen Wert brauche ich nicht“.
