Swift · Apple-Apps

Xcode

Apples Entwicklungsumgebung für alle Apple-Plattformen – Editor, Vorschau, Simulator und App-Store-Upload in einem.

Was ist das?

Xcode ist die offizielle IDE von Apple, kostenlos im Mac App Store. Man braucht sie, um Apps für iPhone, iPad, Mac, Apple Watch und Apple TV zu bauen, zu testen und zu veröffentlichen.

Nur auf macOS: Xcode, SwiftUI-Vorschau und der iPhone-Simulator gibt es ausschließlich auf einem Mac. Die Sprache Swift selbst läuft auch auf Windows und Linux.

Neues Projekt

  1. File → New → Project
  2. Plattform wählen (z. B. iOS) → „App“
  3. Product Name eingeben, Interface: SwiftUI, Language: Swift
  4. Ordner wählen – Git-Repository anlegen lassen
  5. Oben ein Simulator-Gerät wählen (z. B. iPhone) und ▶ drücken (⌘R)

Ohne Mac?

  • Die Sprache Swift auf Windows/Linux lernen (siehe Swift-Seiten).
  • Mac mieten in der Cloud (z. B. MacinCloud) – eher für einzelne Builds.
  • Plattformübergreifend entwickeln mit Flutter, React Native oder .NET MAUI – für das finale iOS-Build braucht man aber trotzdem irgendwo einen Mac.

Tipps & typische Fehler

  • Xcode ist sehr groß (viele GB) – genug Speicherplatz einplanen.
  • Fehler direkt im Editor anklicken – oft schlägt Xcode eine automatische Korrektur („Fix“) vor.
