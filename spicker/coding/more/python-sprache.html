Was ist das?

Python ist eine interpretierte Programmiersprache: Der Code wird nicht vorher in eine Programmdatei übersetzt (wie bei C++), sondern vom Programm python Zeile für Zeile ausgeführt. Blöcke werden nicht mit { } markiert, sondern durch Einrückung. Das macht Python-Code kurz und gut lesbar.

1. Geschichte

Python wurde 1991 von Guido van Rossum veröffentlicht. Der Name kommt nicht von der Schlange, sondern von der Comedy-Gruppe „Monty Python“. Heute ist nur noch Python 3 aktuell – Python 2 wird seit 2020 nicht mehr gepflegt. Anleitungen mit print "Hallo" (ohne Klammern) sind Python 2 und veraltet.

2. Grundlagen

Ein vollständiges Programm – keine main()-Funktion, keine Semikolons, keine Typangaben nötig:

# hello.py
names = ["Anna", "Max", "Kim"]      # eine Liste

for name in names:                  # Doppelpunkt + Einrückung = Block
    if name == "Max":
        print(f"Hallo {name}, du bist dran!")
    else:
        print(f"Hallo {name}")

Ausführen im Terminal:

python hello.py

Wichtige Konzepte

  • Einrückung (4 Leerzeichen) gehört zur Sprache
  • Variablen haben keinen festen Typ – der Wert bestimmt ihn
  • Fast alles ist ein Objekt mit Methoden: "abc".upper()
  • Sehr große Standardbibliothek („batteries included“)

4. Einsatzgebiete

  • Skripte und Automatisierung (Dateien umbenennen, Daten umwandeln, Backups)
  • Datenanalyse und KI (pandas, NumPy, PyTorch)
  • Web-Backends (Django, Flask, FastAPI)
  • Werkzeuge auf Linux – viele Programme auf Arch sind selbst in Python geschrieben
  • Lernen und Ausprobieren, weil man sofort Ergebnisse sieht

Weniger geeignet ist Python, wenn es auf maximale Geschwindigkeit ankommt (Spiele-Engines, Treiber) – dort nimmt man C++ oder C.

Merksatz: In Python ist die Einrückung keine Schönheitsfrage – sie ist die Struktur des Programms.

Tipps & typische Fehler

  • Auf Arch heißt der Befehl python (das ist Python 3). Auf Debian/Ubuntu heißt er python3.
  • True, False und None werden großgeschrieben – true ist ein Fehler.
  • Tabs und Leerzeichen nie mischen. Editor auf „4 Leerzeichen“ stellen.
