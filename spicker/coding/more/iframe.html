HTML · Einbetten

<iframe>

Zeigt eine andere Webseite als Fenster innerhalb deiner Seite an – z. B. YouTube-Videos oder Karten.

Was ist das?

Ein <iframe> (inline frame) ist wie ein kleines Browserfenster in deiner Seite. YouTube, Google Maps oder CodePen geben dir fertigen iframe-Code zum Einbetten.

Beispiel

<iframe
  src="https://www.youtube.com/embed/VIDEO-ID"
  width="560" height="315"
  title="Mein Tutorial-Video"
  loading="lazy"
  allowfullscreen>
</iframe>

Wichtige Attribute

AttributBedeutung
srcAdresse der eingebetteten Seite
titleBeschreibung für Screenreader (Pflicht für Barrierefreiheit)
width / heightGröße des Fensters
loadinglazy = erst laden, wenn sichtbar
allowfullscreenVollbild erlauben (für Videos)
sandboxSchränkt ein, was die fremde Seite darf (Skripte, Formulare …)

Responsive (passt sich der Breite an)

iframe {
  width: 100%;
  aspect-ratio: 16 / 9;   /* Seitenverhältnis wie ein Video */
  border: none;
}

Tipps & typische Fehler

  • Viele Seiten (z. B. Google, Banken) verbieten das Einbetten – dann bleibt der Rahmen leer.
  • Nur vertrauenswürdige Seiten einbetten. Mit sandbox schränkst du fremde Inhalte ein.
