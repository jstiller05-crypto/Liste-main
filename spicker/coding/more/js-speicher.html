localStorage – Daten speichern

Daten im Browser speichern, damit sie nach dem Neuladen noch da sind.

Was ist das?

localStorage ist ein kleiner Speicher im Browser (ca. 5 MB pro Website). Die Daten bleiben erhalten, bis sie gelöscht werden. sessionStorage funktioniert genauso, wird aber beim Schließen des Tabs geleert.

Befehle

localStorage.setItem("theme", "dark");       // speichern
localStorage.getItem("theme");               // "dark"  (oder null, wenn nicht vorhanden)
localStorage.removeItem("theme");            // einen Eintrag löschen
localStorage.clear();                        // ALLES dieser Seite löschen

Objekte & Arrays speichern

Gespeichert werden nur Texte. Objekte und Arrays deshalb mit JSON umwandeln:

const settings = { sort: "az", language: "html" };

localStorage.setItem("settings", JSON.stringify(settings));    // speichern

const saved = JSON.parse(localStorage.getItem("settings")) ?? {};   // laden

Beispiel: Einstellung merken

const select = document.getElementById("sortSelect");

// beim Laden: gespeicherten Wert wiederherstellen
try {
  const savedSort = localStorage.getItem("sort");
  if (savedSort) select.value = savedSort;
} catch (error) {
  console.warn("localStorage nicht verfügbar:", error);
}

// bei Änderung: speichern
select.addEventListener("change", () => {
  try {
    localStorage.setItem("sort", select.value);
  } catch (error) {
    console.warn("Speichern fehlgeschlagen:", error);
  }
});

Tipps & typische Fehler

  • Keine Passwörter oder sensiblen Daten speichern – jedes Skript der Seite kann sie lesen.
  • Im privaten Modus oder bei blockierten Cookies kann localStorage fehlen – deshalb try/catch.
  • Gespeicherte Daten ansehen: F12 → „Anwendung“ (Application) → „Lokaler Speicher“.
