Einheiten & calc()

px, %, em, rem, vw, vh, fr – und wie man mit calc() rechnet.

Übersicht

EinheitBedeutetGut für
pxPixel – feste GrößeRahmen, kleine Abstände, Schatten
%Prozent vom Eltern-ElementBreiten in Layouts
emVielfaches der Schriftgröße des ElementsAbstände, die mit der Schrift mitwachsen
remVielfaches der Schriftgröße von <html> (meist 16px)Schriftgrößen, Abstände – überall gleich
vw / vh1 % der Fensterbreite / -höheVollbild-Bereiche (height: 100vh)
frAnteil am freien Platz (nur in Grid)Grid-Spalten
chBreite des Zeichens „0“Lesefreundliche Textbreite (max-width: 65ch)

Beispiel

html { font-size: 16px; }        /* 1rem = 16px */

h1 { font-size: 2rem; }          /* 32px */
p  { margin-bottom: 1rem; }      /* 16px */

.button {
  font-size: 0.9rem;
  padding: 0.5em 1em;            /* wächst mit der Button-Schrift mit */
}

.sidebar { width: 25%; }         /* ein Viertel des Eltern-Elements */
.hero    { height: 100vh; }      /* ganze Fensterhöhe */

Rechnen mit calc()

.content {
  width: calc(100% - 250px);           /* ganze Breite minus Sidebar */
  height: calc(100vh - 60px);          /* Fenster minus Header */
  padding: calc(1rem + 2px);
}

Um + und - müssen Leerzeichen stehen: calc(100% - 20px), nicht calc(100%-20px).

min(), max(), clamp()

width: min(100%, 800px);             /* nimmt den kleineren Wert */
font-size: clamp(1.5rem, 4vw, 3rem); /* mindestens 1.5rem, höchstens 3rem, dazwischen fließend */

Tipps & typische Fehler

  • em kann sich verschachtelt aufschaukeln (1.2em in 1.2em …) – rem ist berechenbarer.
  • Bei 0 braucht man keine Einheit: margin: 0;.
  • 100vh kann auf Handys wegen der Adressleiste zu hoch sein – dort hilft 100dvh.
