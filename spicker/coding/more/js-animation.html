Animationen mit JavaScript

Wann CSS reicht, wie requestAnimationFrame funktioniert und was die Web Animations API kann.

1. Weg: CSS-Klasse umschalten (meist die beste Wahl)

.panel        { max-height: 0; overflow: hidden; transition: max-height 0.3s ease; }
.panel.open   { max-height: 500px; }
button.addEventListener("click", () => {
  panel.classList.toggle("open");          // JS schaltet nur um, CSS animiert
});

2. Weg: Web Animations API

const animation = box.animate(
  [
    { transform: "translateX(0)",     opacity: 1 },
    { transform: "translateX(200px)", opacity: 0.3 }
  ],
  { duration: 800, easing: "ease-in-out", iterations: 2, direction: "alternate" }
);

animation.onfinish = () => console.log("[anim] fertig");
// animation.pause() / .play() / .reverse() / .cancel()

Wie @keyframes, aber per JavaScript steuerbar – gut, wenn Werte erst zur Laufzeit feststehen.

3. Weg: requestAnimationFrame (Spiele, Canvas)

let x = 0;
let lastTime = performance.now();

function frame(now) {
  const delta = (now - lastTime) / 1000;   // Sekunden seit dem letzten Bild
  lastTime = now;

  x += 100 * delta;                        // 100 Pixel pro Sekunde – unabhängig von der Bildrate
  box.style.transform = `translateX(${x}px)`;

  if (x < 300) requestAnimationFrame(frame);   // nächstes Bild anfordern
}

requestAnimationFrame(frame);

Der Browser ruft die Funktion vor jedem Neuzeichnen auf (meist 60-mal pro Sekunde) und pausiert automatisch in Hintergrund-Tabs.

Welcher Weg?

SituationEmpfehlung
Hover, Aufklappen, Ein-/AusblendenCSS-Klasse umschalten
Animation mit berechneten Werten, steuerbar (Pause/Rückwärts)Web Animations API
Spiele, Physik, Canvas, ständige BewegungrequestAnimationFrame

Tipps & typische Fehler

  • transform und opacity animieren – das ist flüssig. left, width oder top ruckeln eher.
  • setInterval für Animationen vermeiden – es passt nicht zur Bildrate des Bildschirms.
  • Auf prefers-reduced-motion achten: matchMedia("(prefers-reduced-motion: reduce)").matches.
