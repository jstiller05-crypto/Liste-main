HTML · Interaktiv

<template>

Ein unsichtbarer HTML-Bauplan, den JavaScript beliebig oft kopieren und einfügen kann.

Was ist das?

Alles in <template> wird vom Browser nicht angezeigt und nicht ausgeführt (Bilder laden nicht, Skripte laufen nicht). Erst wenn JavaScript den Inhalt kopiert und einfügt, wird er sichtbar – ideal, um viele gleich aufgebaute Einträge zu erzeugen.

Beispiel

<ul id="list"></ul>

<template id="itemTemplate">
  <li class="item">
    <strong class="name"></strong> – <span class="info"></span>
  </li>
</template>

<script>
  const template = document.getElementById("itemTemplate");
  const list = document.getElementById("list");
  const entries = [
    { name: "HTML", info: "Struktur" },
    { name: "CSS",  info: "Aussehen" }
  ];

  entries.forEach((entry) => {
    const copy = template.content.cloneNode(true);   // Bauplan kopieren
    copy.querySelector(".name").textContent = entry.name;
    copy.querySelector(".info").textContent = entry.info;
    list.appendChild(copy);                         // einfügen
  });
</script>

Wichtige Befehle

BefehlWirkung
template.contentDer Inhalt des Templates (ein DocumentFragment)
.cloneNode(true)Tiefe Kopie – mit allen Kind-Elementen
.querySelector(…)In der Kopie Elemente zum Befüllen finden

Tipps & typische Fehler

  • Immer eine Kopie mit cloneNode(true) einfügen – sonst ist der Bauplan nach dem ersten Mal leer.
  • Gegenüber innerHTML mit langen Textbausteinen bleibt das HTML übersichtlich und sicher.
