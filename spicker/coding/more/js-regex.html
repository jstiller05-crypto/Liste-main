Reguläre Ausdrücke (Regex)

Muster in Texten finden, prüfen und ersetzen – z. B. für E-Mail, PLZ oder Telefonnummern.

Grundlagen

const plz = /^\d{5}$/;                 // genau 5 Ziffern

plz.test("12345");                      // true
plz.test("1234a");                      // false

"Tel: 0170 1234567".match(/\d+/g);    // ["0170", "1234567"]  (g = alle Treffer)
"a-b-c".replace(/-/g, " ");            // "a b c"
"2026-09-30".split(/-/);                // ["2026", "09", "30"]

Gruppen auslesen

const date = "Termin am 30.09.2026";
const match = date.match(/(\d{2})\.(\d{2})\.(\d{4})/);
if (match) {
  const [, day, month, year] = match;         // [0] = ganzer Treffer
  console.log(day, month, year);              // "30" "09" "2026"
}

// benannte Gruppen
const m = date.match(/(?<day>\d{2})\.(?<month>\d{2})/);
console.log(m.groups.day);                    // "30"

Tipps & typische Fehler

  • Im String-Konstruktor müssen Backslashes doppelt: new RegExp("\\d+") entspricht /\d+/.
  • E-Mail-Adressen perfekt per Regex zu prüfen ist fast unmöglich – eine grobe Prüfung plus Bestätigungsmail ist üblich.
  • Regex-Tester wie regex101.com erklären jedes Zeichen eines Musters.
