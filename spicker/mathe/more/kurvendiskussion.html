Kurvendiskussion

Eine Funktion Schritt für Schritt untersuchen: Wo steigt sie, wo hat sie Hoch- und Tiefpunkte, wo ändert sich die Krümmung?

Was ist das?

Bei einer Kurvendiskussion (Funktionsuntersuchung) sammelt man alle wichtigen Eigenschaften eines Graphen, um ihn ohne Computer genau zeichnen und beschreiben zu können. Die Ableitungen verraten dabei die Form.

ZeichenBedeutung
f'(x)Steigung: > 0 steigend, < 0 fallend, = 0 waagerecht
f''(x)Krümmung: > 0 Linkskurve (∪), < 0 Rechtskurve (∩)
f'''(x)dritte Ableitung – nur zur Kontrolle beim Wendepunkt
H, THochpunkt (lokales Maximum), Tiefpunkt (lokales Minimum)
WWendepunkt – dort wechselt die Kurve von Links- in Rechtskurve oder umgekehrt

Woher kommt das?

Pierre de Fermat fand um 1636 heraus, dass an einem Maximum oder Minimum die Tangente waagerecht ist – noch bevor es die Ableitung offiziell gab. Das „Extremwertproblem“ ist bis heute eine der wichtigsten Anwendungen: kleinste Kosten, größter Gewinn, kürzester Weg.

Monotonie

BedingungBedeutung
f'(x) > 0 auf einem Intervallf ist dort streng monoton steigend
f'(x) &lt; 0 auf einem Intervallf ist dort streng monoton fallend

Die Stellen mit f'(x) = 0 teilen die x-Achse in Abschnitte; in jedem Abschnitt prüft man das Vorzeichen von f' mit einem Testwert.

Extrempunkte und Wendepunkte

notwendige Bedingunghinreichende Bedingung
Hochpunktf'(x) = 0f''(x) &lt; 0 (Rechtskurve)
Tiefpunktf'(x) = 0f''(x) > 0 (Linkskurve)
Wendepunktf''(x) = 0f'''(x) ≠ 0
 
f(x)   = x³ − 3x
f'(x)  = 3x² − 3
f''(x) = 6x
f'''(x)= 6

Extremstellen: 3x² − 3 = 0 → x² = 1 → x = −1 oder x = 1
  f''(−1) = −6 < 0 → Hochpunkt, f(−1) = −1 + 3 = 2  → H(−1 | 2)
  f''(1)  =  6 > 0 → Tiefpunkt, f(1)  = 1 − 3 = −2  → T(1 | −2)
Wendestelle:  6x = 0 → x = 0, f'''(0) = 6 ≠ 0 → W(0 | 0)

Ablauf einer Kurvendiskussion

  1. Definitionsbereich: Welche x sind erlaubt?
  2. Symmetrie: f(−x) = f(x) oder f(−x) = −f(x)?
  3. Achsenschnittpunkte: Nullstellen f(x) = 0 und y-Achsenabschnitt f(0).
  4. Ableitungen f', f'', f''' bilden.
  5. Extrempunkte: f'(x) = 0 lösen, mit f'' prüfen, y-Wert berechnen.
  6. Wendepunkte: f''(x) = 0 lösen, mit f''' prüfen.
  7. Verhalten für x → ±∞ (höchste Potenz anschauen).
  8. Skizze mit allen Punkten zeichnen.

Tipps & typische Fehler

  • Den y-Wert immer in der Originalfunktion f berechnen, nicht in f'.
  • Ist f''(x) = 0 an einer Extremstelle, hilft der Vorzeichenwechsel von f' (Testwerte links und rechts).
  • Ein Polynom vom Grad n hat höchstens n − 1 Extrempunkte und n − 2 Wendepunkte.
