Quadratische Gleichungen

Gleichungen mit x²: pq-Formel, Mitternachtsformel und die Diskriminante, die verrät, wie viele Lösungen es gibt.

Was ist das?

Eine quadratische Gleichung enthält x² (aber keine höhere Potenz). Sie hat 0, 1 oder 2 Lösungen. Grafisch sind die Lösungen die Nullstellen einer Parabel – dort, wo sie die x-Achse schneidet.

Allgemeine Form:   ax² + bx + c = 0     (a ≠ 0)
Normalform:        x² + px + q = 0      (vorne steht nur x²)
ZeichenBedeutung
xdie gesuchte Zahl (Unbekannte)
aZahl vor x² (darf nicht 0 sein, sonst kein x²)
bZahl vor x
cZahl ohne x (konstantes Glied)
p, qZahl vor x bzw. ohne x in der Normalform, also p = b/a, q = c/a
±„plus oder minus“: einmal mit + rechnen, einmal mit − → zwei Lösungen

Woher kommt das?

Babylonische Tontafeln (um 1800 v. Chr.) enthalten schon Aufgaben wie „Fläche minus Seite = 870“ samt Lösungsweg. Der persische Gelehrte al-Chwarizmi beschrieb um 820 n. Chr. das systematische Lösen – von seinem Buchtitel „al-dschabr“ stammt das Wort Algebra. Die Formeln entstehen durch quadratische Ergänzung (binomische Formel rückwärts).

Der Name „Mitternachtsformel“ ist ein Schulwitz: Man soll sie auch aufsagen können, wenn man um Mitternacht geweckt wird.

pq-Formel

x² + px + q = 0
x₁,₂ = −p/2 ± √( (p/2)² − q )

Beispiel: x² − 2x − 3 = 0     → p = −2, q = −3
x = 1 ± √(1 + 3) = 1 ± 2
x₁ = 3,  x₂ = −1
Steht vor x² eine andere Zahl als 1, erst durch diese Zahl teilen: 2x² + 8x − 10 = 0 | :2 → x² + 4x − 5 = 0.

Mitternachtsformel (abc-Formel)

ax² + bx + c = 0
x₁,₂ = ( −b ± √(b² − 4ac) ) / (2a)

Beispiel: 2x² + 3x − 2 = 0    → a = 2, b = 3, c = −2
x = (−3 ± √(9 + 16)) / 4 = (−3 ± 5) / 4
x₁ = 0,5,  x₂ = −2

Diskriminante: wie viele Lösungen?

Der Teil unter der Wurzel heißt Diskriminante D (lateinisch „die Unterscheidende“).

D = b² − 4ac       (abc-Formel)
D = (p/2)² − q     (pq-Formel)
DiskriminanteLösungenParabel
D > 0zwei Lösungenschneidet die x-Achse zweimal
D = 0genau eine Lösungberührt die x-Achse (Scheitel liegt darauf)
D < 0keine reelle Lösung (Wurzel aus negativer Zahl)liegt ganz über/unter der x-Achse

Sonderfälle ohne Formel

Ohne c:  x² − 5x = 0  → x(x − 5) = 0  → x = 0 oder x = 5   (Ausklammern)
Ohne b:  x² − 16 = 0  → x² = 16       → x = 4 oder x = −4   (Wurzel, ±!)

Ein Produkt ist genau dann 0, wenn mindestens ein Faktor 0 ist (Satz vom Nullprodukt).

Tipps & typische Fehler

  • Vorzeichen mitnehmen: Bei x² − 2x − 3 ist p = −2 (nicht 2).
  • Beim Wurzelziehen aus x² = 16 die negative Lösung nicht vergessen.
  • Probe: Lösungen einsetzen – es muss 0 herauskommen.
