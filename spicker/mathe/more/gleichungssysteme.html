Gleichungssysteme, Gauß & Matrizen

Mehrere Gleichungen mit mehreren Unbekannten lösen – von Hand und mit Matrizen.

Was ist das?

Ein lineares Gleichungssystem (LGS) besteht aus mehreren Gleichungen, die gleichzeitig gelten sollen. Gesucht sind Zahlen für alle Unbekannten, die jede Gleichung erfüllen.

I:   2x −  y = 1
II:   x +  y = 5

Jede Gleichung mit zwei Unbekannten ist eine Gerade. Die Lösung ist der Schnittpunkt:

eindeutigschneiden sichgenau eine
keineparallelkeine Lösung
unendlich vieleliegen aufeinanderunendlich viele

Woher kommt das?

Ein chinesisches Rechenbuch („Neun Kapitel“, um 200 v. Chr.) löst Gleichungssysteme schon mit Zahlentafeln – im Grunde mit dem heutigen Gauß-Verfahren. Carl Friedrich Gauß nutzte es um 1810, um aus Messungen die Bahn eines Asteroiden zu berechnen. Heute lösen Computer Systeme mit Millionen Unbekannten (Wetter, Statik, 3D-Grafik, KI).

Gauß-Verfahren (für 3 und mehr Unbekannte)

Man bringt das System in Stufenform: Unten stehen immer weniger Unbekannte. Erlaubt sind: Gleichungen vertauschen, mit einer Zahl ≠ 0 malnehmen und das Vielfache einer Gleichung zu einer anderen addieren.

I:    x +  y +  z = 6
II:  2x −  y +  z = 3
III:  x + 2y −  z = 2

II − 2·I:    −3y −  z = −9
III − I:       y − 2z = −4
3·III' + II':      −7z = −21   →  z = 3

Rückwärts einsetzen:  y − 6 = −4 → y = 2
                      x + 2 + 3 = 6 → x = 1

Matrizen

Eine Matrix ist eine rechteckige Zahlentabelle. Ein LGS lässt sich kurz als Matrix schreiben – man lässt einfach die Buchstaben weg und rechnet nur mit den Zahlen (genau das macht das Gauß-Verfahren).

2x − y = 1        ( 2  −1 | 1 )
 x + y = 5   →    ( 1   1 | 5 )

Größe „m × n“: m Zeilen, n Spalten.  Aᵢⱼ = Eintrag in Zeile i, Spalte j
Im Allgemeinen gilt A · B ≠ B · A – die Reihenfolge ist wichtig! Multiplizieren geht nur, wenn A so viele Spalten hat wie B Zeilen.

Determinante (2 × 2)

    ( a  b )
A = ( c  d )      det(A) = a · d − b · c

Beispiel: ( 2  −1 )
          ( 1   1 )   det = 2·1 − (−1)·1 = 3
ZeichenBedeutung
det(A)Determinante – eine einzige Zahl, die man aus einer quadratischen Matrix berechnet
a, b, c, ddie vier Einträge: a oben links, b oben rechts, c unten links, d unten rechts

Ist det(A) ≠ 0, hat das zugehörige LGS genau eine Lösung und A ist umkehrbar (invertierbar). Ist det(A) = 0, gibt es keine oder unendlich viele Lösungen. Geometrisch ist |det| die Fläche des Parallelogramms aus den Spaltenvektoren.

Tipps & typische Fehler

  • Erst eine Variable eliminieren, dann rückwärts einsetzen – und am Ende in ALLE Gleichungen einsetzen (Probe).
  • Beim Subtrahieren von Gleichungen jede Seite komplett abziehen – Vorzeichenfehler sind der Klassiker.
  • Taschenrechner und Programme (z. B. Python mit NumPy) lösen LGS mit Matrizen in einer Zeile.
