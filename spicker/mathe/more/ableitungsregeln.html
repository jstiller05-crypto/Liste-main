Ableitungsregeln

Mit wenigen Regeln kann man fast jede Funktion ableiten – ohne Grenzwert-Rechnerei.

Was ist das?

Die Ableitungsregeln sind Abkürzungen, die man einmal mit dem Differenzenquotienten bewiesen hat. Jetzt kann man sie einfach anwenden. Man nennt das Ableiten auch Differenzieren.

ZeichenBedeutung
f, gFunktionen
u, vdie beiden Teil-Funktionen bei Produkt und Quotient
ceine feste Zahl (Konstante)
nExponent (beliebige reelle Zahl)
'Strich = „abgeleitet“

Woher kommt das?

Leibniz veröffentlichte 1684 die erste Arbeit mit Produkt- und Quotientenregel. Die Kettenregel steckt ebenfalls schon bei ihm. Heute nutzen Computer genau diese Regeln automatisch: Beim Training neuronaler Netze (KI) wird mit der Kettenregel abgeleitet („Backpropagation“).

Grundregeln

RegelFormelBeispiel
Konstante(c)' = 0(7)' = 0
Potenzregel(xⁿ)' = n · xⁿ⁻¹(x³)' = 3x², (x)' = 1
Faktorregel(c · f)' = c · f'(5x²)' = 5 · 2x = 10x
Summenregel(f + g)' = f' + g'(x³ + x²)' = 3x² + 2x
 
f(x)  = 4x³ − 2x² + 7x − 5
f'(x) = 12x² − 4x + 7
f''(x)= 24x − 4

Wurzeln und Brüche erst als Potenz schreiben:
√x = x^(1/2)  →  (√x)' = ½ · x^(−1/2) = 1 / (2√x)
1/x = x⁻¹     →  (1/x)' = −1 · x⁻² = −1/x²

Produkt-, Quotienten- und Kettenregel

RegelFormelWann?
Produktregel(u · v)' = u' · v + u · v'zwei Funktionen malgenommen
Quotientenregel(u / v)' = (u' · v − u · v') / v²eine Funktion durch eine andere
Kettenregel(f(g(x)))' = f'(g(x)) · g'(x)eine Funktion steckt in einer anderen
 
Produkt:  (x² · eˣ)' = 2x · eˣ + x² · eˣ = eˣ(2x + x²)

Quotient: (x / (x + 1))' = (1 · (x + 1) − x · 1) / (x + 1)² = 1 / (x + 1)²

Kette:    ((3x + 1)⁵)'   äußere: (…)⁵ → 5(…)⁴,  innere: 3x + 1 → 3
                       = 5(3x + 1)⁴ · 3 = 15(3x + 1)⁴
Kettenregel-Merksatz: „äußere Ableitung mal innere Ableitung“. Die innere Funktion bleibt in der äußeren Ableitung unverändert stehen.

Tipps & typische Fehler

  • Bei der Potenzregel: Exponent nach vorne, dann Exponent minus 1 – NICHT plus 1 (das ist Integrieren).
  • Eine allein stehende Zahl fällt beim Ableiten weg, eine Zahl als Faktor bleibt stehen.
  • Bei sin/cos immer im Bogenmaß rechnen.
