Ungleichungen, Betrag & Intervalle

Wenn statt „=“ ein „<“ oder „≥“ steht – und wie man Lösungsmengen als Intervalle aufschreibt.

Was ist das?

Eine Ungleichung vergleicht zwei Terme mit einem Größer- oder Kleiner-Zeichen. Die Lösung ist meist keine einzelne Zahl, sondern ein ganzer Bereich von Zahlen.

ZeichenBedeutung
<kleiner als: 2 < 5
>größer als: 5 > 2
≤kleiner oder gleich
≥größer oder gleich
≠ungleich
|x|Betrag von x – der Abstand von x zur 0

Woher kommt das?

Die Zeichen < und > führte der Engländer Thomas Harriot ein (veröffentlicht 1631) – die offene Seite zeigt zur größeren Zahl. ≤ und ≥ kamen im 18. Jahrhundert dazu. Ungleichungen braucht man überall, wo es Grenzen gibt: Budgets, Toleranzen, Tempolimits.

Ungleichungen lösen

Man rechnet wie bei Gleichungen – mit einer wichtigen Ausnahme:

Wird mit einer negativen Zahl malgenommen oder durch sie geteilt, dreht sich das Zeichen um: aus < wird >.
3x + 2 < 11    | −2
    3x < 9     | :3   (positiv → Zeichen bleibt)
     x < 3

−2x ≤ 8        | :(−2)  (negativ → Zeichen dreht!)
  x ≥ −4

Probe für −2x ≤ 8 mit x = 0:  0 ≤ 8 ✓

Intervalle

Ein Intervall ist ein lückenloser Abschnitt der Zahlengeraden. Eckige Klammern sagen, ob der Rand dazugehört.

SchreibweiseBedeutungRänder
[a; b]alle x mit a ≤ x ≤ ba und b gehören dazu (geschlossen)
]a; b[ oder (a; b)alle x mit a < x < ba und b gehören NICHT dazu (offen)
[a; b[a ≤ x < bhalboffen
]−∞; 3[alle x < 3∞ (unendlich) ist nie eingeschlossen

Betrag

|x| = x     wenn x ≥ 0
|x| = −x    wenn x < 0      (z. B. |−3| = −(−3) = 3)

|x| < 2   bedeutet  −2 < x < 2      → ]−2; 2[
|x| ≥ 2   bedeutet  x ≤ −2 oder x ≥ 2
|x − 5| = Abstand zwischen x und 5

Tipps & typische Fehler

  • Das Umdrehen des Zeichens bei negativen Zahlen ist der Fehler Nummer 1.
  • Merkhilfe: Das Krokodil-Maul (< / >) frisst immer die größere Zahl.
  • Bei ∞ steht immer eine offene Klammer, weil unendlich keine Zahl ist, die man erreicht.
