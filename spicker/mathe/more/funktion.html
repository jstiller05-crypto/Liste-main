Was ist eine Funktion?

Eine Funktion ist eine feste Regel: Zu jeder Eingabe x gehört genau eine Ausgabe y.

Die Idee

Eine Funktion ist wie eine Maschine: Man steckt eine Zahl hinein (x), die Maschine rechnet nach einer festen Regel, und heraus kommt genau eine Zahl (y bzw. f(x)).

Woher kommt das? Der Begriff „Funktion“ stammt von Gottfried Wilhelm Leibniz (um 1690). Die Schreibweise f(x) führte Leonhard Euler 1734 ein. Sie wird „f von x“ gelesen.

Wichtige Begriffe

BegriffBedeutung
Definitionsbereich DAlle x-Werte, die man einsetzen darf (z. B. nicht durch 0 teilen).
Wertebereich WAlle y-Werte, die tatsächlich herauskommen.
Nullstellex-Wert mit f(x) = 0 – dort schneidet der Graph die x-Achse.
y-Achsenabschnittf(0) – dort schneidet der Graph die y-Achse.

Keine Funktion

Ein Kreis ist keine Funktion von x: Zu einem x gehören dort zwei y-Werte (oben und unten). Test: Eine senkrechte Linie darf den Graphen höchstens einmal schneiden.

Tipps & typische Fehler

  • f(x) ist KEIN „f mal x“, sondern „der Wert der Funktion f an der Stelle x“.
  • Beim Einsetzen negativer Zahlen Klammern setzen: f(−2) = 0,5 · (−2)² − 1.
