Pine Script & Strategy Tester

TradingViews eigene Sprache für Indikatoren und Strategien – läuft für jede Kerze einmal, von links nach rechts.

Was ist das?

Pine Script ist TradingViews eigene Sprache für eigene Indikatoren, Strategien und Alarme. Aktuelle Version: v6 (erste Zeile im Code: //@version=6). Der Code läuft auf den Servern von TradingView – einmal pro Kerze, von links nach rechts durch den Chart.

Woher kommt das? Pine Script wurde um 2013/2014 eingeführt, damit Nutzer eigene Indikatoren teilen können. Heute gibt es eine große Bibliothek an Community-Skripten.

Pine Editor

Unten im Panel öffnen, Code einfügen, dann auf „Zum Chart hinzufügen“ klicken.

Grundbegriffe

BegriffBedeutung
close / open / high / lowWerte der aktuellen Kerze
Serieein Wert, der für jede Kerze neu existiert
close[1]Schlusskurs der Vorkerze
input.*Einstellungen, die im Zahnrad-Menü erscheinen
ta.*fertige Indikator-Bausteine, z. B. ta.sma()
plot()zeichnet einen Wert in den Chart
indicator() vs. strategy()nur anzeigen vs. auch simuliert handeln

Beispiel 1: Indikator

//@version=6
// Zeichnet zwei gleitende Durchschnitte und markiert das Golden Cross
indicator("SMA-Kreuz", overlay = true)

fastLength = input.int(50, "Schneller SMA")   // Einstellung im Zahnrad-Menü
slowLength = input.int(200, "Langsamer SMA")

fastSma = ta.sma(close, fastLength)            // Durchschnitt der letzten 50 Schlusskurse
slowSma = ta.sma(close, slowLength)

plot(fastSma, "Fast SMA", color = color.orange)
plot(slowSma, "Slow SMA", color = color.blue)

goldenCross = ta.crossover(fastSma, slowSma)   // true nur auf der Kerze, auf der gekreuzt wird
plotshape(goldenCross, "Golden Cross", shape.triangleup, location.belowbar, color.green)

// Ausgabe im Pine-Logs-Panel (wie console.log)
if goldenCross
    log.info("Golden Cross bei Kurs {0}", close)

// Macht die Bedingung als Alarm auswählbar
alertcondition(goldenCross, "Golden Cross", "50er kreuzt 200er nach oben")

fastSma und slowSma sind zwei gleitende Durchschnitte. ta.crossover() wird nur auf genau der Kerze true, auf der die schnelle Linie die langsame von unten nach oben kreuzt. log.info() schreibt – wie console.log im Browser – in ein eigenes Panel, die Pine Logs. alertcondition() macht das Golden Cross als Alarm-Bedingung auswählbar.

Beispiel 2: Strategie

//@version=6
strategy("SMA-Kreuz Strategie", overlay = true, initial_capital = 10000,
     commission_type = strategy.commission.percent, commission_value = 0.1)

fastSma = ta.sma(close, 50)
slowSma = ta.sma(close, 200)

if ta.crossover(fastSma, slowSma)
    strategy.entry("Long", strategy.long)      // Kaufen
if ta.crossunder(fastSma, slowSma)
    strategy.close("Long")                     // Position schließen

Strategy Tester

Testet eine Pine-Strategie an alten Kursdaten (Backtest). Reiter im Strategy Tester:

ReiterInhalt
ÜbersichtEquity-Kurve: wie sich das simulierte Kapital entwickelt hat
KennzahlenNettogewinn, max. Drawdown, Profitfaktor, Trefferquote, Anzahl Trades
Liste der Tradesjeder einzelne simulierte Trade

Hintergrund zu den Kennzahlen: Erwartungswert & Drawdown.

Overfitting: Eine Strategie, die perfekt auf alte Daten passt, versagt oft in der Zukunft. Gebühren im Tester immer realistisch einstellen. Ein Backtest ist keine Garantie.
