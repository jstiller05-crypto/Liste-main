#include

Was ist das?

Die #include-Direktive bindet externe Header-Dateien oder Bibliotheken in dein C++-Programm ein.

Syntax

#include <bibliothek>    // Standardbibliothek
#include "datei.h"         // Benutzerdefinierte Header

Beispiel

#include <iostream>      // Ein- und Ausgabe
#include <string>         // String-Funktionalität
#include "myHeader.h"      // Eigene Header-Datei

Mit `<>` werden Standard-Bibliotheken gesucht. Mit `""` wird zuerst im aktuellen Verzeichnis gesucht.

Wann nutzt man es?

Immer, wenn du Funktionen oder Klassen aus anderen Dateien oder Bibliotheken benötigst. Typische Beispiele:

  • <iostream> für Eingabe/Ausgabe
  • <string> für Strings
  • <vector> für dynamische Arrays
  • <cmath> für mathematische Funktionen

Wichtige Hinweise

  • #include muss am Anfang der Datei stehen
  • Es ist ein Präprozessor-Befehl (das # am Anfang ist wichtig)
  • Mehrfaches Einbinden desselben Headers kann zu Fehlern führen → nutze Include-Guards
