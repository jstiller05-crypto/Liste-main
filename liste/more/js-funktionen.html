Funktionen

Code in wiederverwendbare Bausteine packen – mit Parametern und Rückgabewert.

Drei Schreibweisen

// 1) Funktionsdeklaration
function add(a, b) {
  return a + b;
}

// 2) Funktionsausdruck
const subtract = function (a, b) {
  return a - b;
};

// 3) Pfeilfunktion (arrow function)
const multiply = (a, b) => a * b;          // ein Ausdruck: return automatisch
const greet = name => `Hallo ${name}`;     // ein Parameter: Klammern optional
const log = () => { console.log("Hi"); };  // mehrere Zeilen: { } und return nötig

console.log(add(2, 3));   // 5

Parameter & Rückgabe

function createUser(name, role = "Gast") {   // Standardwert
  return { name, role };                     // gibt ein Objekt zurück
}

createUser("Max");           // { name: "Max", role: "Gast" }
createUser("Anna", "Admin"); // { name: "Anna", role: "Admin" }

// Beliebig viele Argumente mit ...rest
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
sum(1, 2, 3);                // 6

Ohne return gibt eine Funktion undefined zurück. Nach return wird nichts mehr ausgeführt.

Funktionen als Werte (Callbacks)

Funktionen kann man an andere Funktionen übergeben – so funktionieren Events und Array-Methoden:

button.addEventListener("click", handleClick);   // ohne () übergeben!

function handleClick() {
  console.log("geklickt");
}

[3, 1, 2].sort((a, b) => a - b);   // Vergleichsfunktion als Callback

Tipps & typische Fehler

  • Eine Funktion = eine Aufgabe. Wird sie lang, in mehrere kleine aufteilen.
  • Namen mit Verb: calculateTotal, renderTable, isValid.
  • handleClick übergeben, nicht handleClick() – mit Klammern wird sie sofort ausgeführt.
