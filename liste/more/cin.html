std::cin

Was ist das?

std::cin liest Daten von der Standardeingabe (normalerweise Tastatur) und speichert sie in Variablen.

Syntax

std::cin >> variable;
std::cin >> var1 >> var2;

Der `>>`-Operator (Extract-Operator) liest Daten aus dem Input-Stream.

Beispiel

#include <iostream>
using namespace std;

int main() {
    int alter;
    string name;
    
    cout << "Gib deinen Namen ein: ";
    cin >> name;
    
    cout << "Gib dein Alter ein: ";
    cin >> alter;
    
    cout << "Hallo " << name << ", du bist " << alter << " Jahre alt!" << endl;
    return 0;
}

Wann nutzt man es?

Um Eingaben vom Benutzer zu lesen und in einem Programm zu verarbeiten.

Wichtige Hinweise

  • `cin >>` stoppt beim Lesen bei Whitespace (Leerzeichen, Tab, Newline)
  • Für ganze Zeilen: `getline(cin, string)` verwenden
  • Immer prüfen, ob die Eingabe erfolgreich war (`if(cin)` oder `cin.fail()`)
