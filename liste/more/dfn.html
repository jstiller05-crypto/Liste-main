HTML · Text

<dfn>

Markiert einen Begriff an der Stelle, an der er definiert (erklärt) wird.

Was ist das?

Wird ein Fachbegriff im Text erklärt, zeichnest du ihn dort mit <dfn> aus. Der umgebende Satz oder Absatz ist die Definition.

Beispiel

<p>Eine <dfn>API</dfn> ist eine Schnittstelle, über die Programme miteinander kommunizieren.</p>

Eine API ist eine Schnittstelle, über die Programme miteinander kommunizieren.

Tipps & typische Fehler

  • Jeder Begriff sollte nur einmal mit <dfn> ausgezeichnet werden – dort, wo er erklärt wird.
  • Kombinierbar: <dfn><abbr title="…">API</abbr></dfn>.
