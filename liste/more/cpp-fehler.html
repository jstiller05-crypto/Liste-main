Exceptions & Fehlersuche

Fehler zur Laufzeit abfangen und typische Compiler-Fehlermeldungen verstehen.

try / catch / throw

#include <stdexcept>

double divide(double a, double b) {
    if (b == 0) {
        throw std::invalid_argument("Division durch 0");   // Fehler auslösen
    }
    return a / b;
}

int main() {
    try {
        std::cout << divide(10, 0) << "\n";
    } catch (const std::invalid_argument& error) {
        std::cerr << "[Fehler] " << error.what() << "\n";   // what() = Fehlertext
    } catch (const std::exception& error) {                 // alle anderen Standard-Fehler
        std::cerr << "[Fehler] " << error.what() << "\n";
    }
    return 0;
}

Eingaben sicher einlesen

int number;
while (!(std::cin >> number)) {                 // Eingabe war keine Zahl
    std::cerr << "Bitte eine Zahl eingeben: ";
    std::cin.clear();                           // Fehlerzustand zurücksetzen
    std::cin.ignore(10000, '\n');              // falsche Eingabe verwerfen
}

Ausgaben zur Fehlersuche

std::cerr << "[debug] score = " << score << "\n";   // cerr: Fehlerkanal, ungepuffert

#include <cassert>
assert(level >= 1 && "Level muss mindestens 1 sein");   // bricht im Debug-Build ab

Tipps & typische Fehler

  • Immer den ersten Fehler zuerst lesen und beheben – viele Folgefehler verschwinden dann von selbst.
  • Mit -Wall -Wextra kompilieren: Der Compiler warnt vor vielen Fehlern, bevor sie passieren.
  • Exceptions per const& fangen: catch (const std::exception& e).
  • Debugger (z. B. in VS Code oder Qt Creator): Haltepunkt setzen und Schritt für Schritt Variablen ansehen.
