Dateien lesen & schreiben

Mit <fstream> Text in Dateien speichern und wieder laden.

Schreiben

#include <fstream>

std::ofstream file("scores.txt");          // öffnet (bzw. erstellt) die Datei, überschreibt sie
if (!file) {
    std::cerr << "[Datei] Konnte scores.txt nicht öffnen\n";
    return 1;
}
file << "Max 120\n";                       // wie cout, nur in die Datei
file << "Anna 150\n";
// Datei wird am Ende des Blocks automatisch geschlossen

std::ofstream log("log.txt", std::ios::app);   // app = anhängen statt überschreiben
log << "Programm gestartet\n";

Lesen

std::ifstream file("scores.txt");
if (!file) {
    std::cerr << "[Datei] scores.txt nicht gefunden\n";
    return 1;
}

// Zeile für Zeile
std::string line;
while (std::getline(file, line)) {
    std::cout << "Gelesen: " << line << "\n";
}
// Werte direkt einlesen (durch Leerzeichen getrennt)
std::ifstream file("scores.txt");
std::string name;
int score;
while (file >> name >> score) {
    std::cout << name << " hat " << score << " Punkte\n";
}

Tipps & typische Fehler

  • Immer prüfen, ob die Datei geöffnet werden konnte (if (!file)) – sonst passiert still nichts.
  • Relative Pfade gelten vom Arbeitsverzeichnis aus, nicht vom Ordner der .cpp-Datei. In IDEs ist das oft der Build-Ordner.
  • Auf Windows in Pfaden / oder doppelte Backslashes verwenden: "data/scores.txt" oder "data\\scores.txt".
