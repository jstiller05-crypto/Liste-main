Node.js · Server

Einfacher Webserver (http)

Mit dem eingebauten http-Modul einen Server starten und auf Anfragen antworten.

Minimaler Server

import http from "node:http";

const PORT = 3000;

const server = http.createServer((request, response) => {
  console.log(`[http] ${request.method} ${request.url}`);

  if (request.url === "/") {
    response.writeHead(200, { "Content-Type": "text/html; charset=utf-8" });
    response.end("<h1>Hallo vom Server</h1>");
  } else if (request.url === "/api/time") {
    response.writeHead(200, { "Content-Type": "application/json" });
    response.end(JSON.stringify({ time: new Date().toISOString() }));
  } else {
    response.writeHead(404, { "Content-Type": "text/plain; charset=utf-8" });
    response.end("Nicht gefunden");
  }
});

server.listen(PORT, () => {
  console.log(`[http] Server läuft auf http://localhost:${PORT}`);
});

Starten mit node server.js, dann im Browser http://localhost:3000 öffnen. Beenden mit Strg+C.

Wie eine Anfrage abläuft

Browser ──► GET /api/time ──► Server
Browser ◄── 200 + JSON   ◄── Server

Wichtige Begriffe

BegriffBedeutung
RequestAnfrage des Browsers: Methode, URL, Header, evtl. Daten
ResponseAntwort des Servers: Statuscode, Header, Inhalt
MethodeGET (abrufen), POST (senden), PUT/PATCH (ändern), DELETE (löschen)
Statuscode200 OK, 201 erstellt, 400 falsche Anfrage, 404 nicht gefunden, 500 Serverfehler
Port„Türnummer“ des Servers, z. B. 3000
Content-TypeArt der Antwort: text/html, application/json …

Tipps & typische Fehler

  • Für mehr als ein paar Routen wird das schnell unübersichtlich – dafür nutzt man Express.
  • „EADDRINUSE“ heißt: Der Port ist schon belegt (z. B. läuft der Server noch in einem anderen Terminal).
