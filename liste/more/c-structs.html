C · Daten

struct, typedef & enum

Eigene Datentypen in C – ohne Klassen, aber mit Funktionen, die mit ihnen arbeiten.

struct & typedef

#include <stdio.h>
#include <string.h>

typedef struct {             /* typedef: statt "struct Player" reicht "Player" */
    char name[32];
    int level;
    int score;
} Player;

void player_add_score(Player *player, int points) {   /* "Methode" als normale Funktion */
    player->score += points;                          /* -> bei Zeigern */
}

int main(void) {
    Player p = { "Max", 1, 0 };
    player_add_score(&p, 50);
    printf("%s: Level %d, %d Punkte\n", p.name, p.level, p.score);   /* . bei Variablen */
    return 0;
}

enum

typedef enum {
    DIFFICULTY_EASY,       /* 0 */
    DIFFICULTY_MEDIUM,     /* 1 */
    DIFFICULTY_HARD        /* 2 */
} Difficulty;

Difficulty level = DIFFICULTY_MEDIUM;
switch (level) {
    case DIFFICULTY_EASY: printf("Leicht\n"); break;
    default:              printf("Anders\n");
}

Tipps & typische Fehler

  • Structs in Funktionen per Zeiger übergeben (Player *p) – sonst wird kopiert und Änderungen gehen verloren.
  • Übliche Namensregel ohne Klassen: typname_aktion(), z. B. player_add_score.
