process, Umgebungsvariablen & .env

Kommandozeilen-Argumente lesen, Einstellungen über Umgebungsvariablen steuern und Geheimnisse aus dem Code halten.

Kommandozeilen-Argumente

// greet.js  →  node greet.js Max 3
const args = process.argv.slice(2);   // [0] = node, [1] = Skript, ab [2] eigene Argumente
const name = args[0] ?? "Welt";
const times = Number(args[1] ?? 1);

for (let i = 0; i < times; i++) {
  console.log(`Hallo ${name}!`);
}

Umgebungsvariablen

Setzen im TerminalBefehl
Windows (PowerShell)$env:PORT = 4000; node server.js
Windows (cmd)set PORT=4000 && node server.js
LinuxPORT=4000 node server.js
 
const PORT = process.env.PORT ?? 3000;
const isProduction = process.env.NODE_ENV === "production";
console.log("[config] Port:", PORT, "Produktion:", isProduction);

.env-Datei

# .env  – NICHT ins Git-Repository!
PORT=3000
DB_PASSWORD=geheim123
node --env-file=.env server.js    # Node 20.6+ liest .env direkt ein

So stehen Passwörter und API-Schlüssel nicht im Code und landen nicht versehentlich öffentlich auf GitHub.

Weitere nützliche process-Werte

AusdruckBedeutung
process.cwd()Aktuelles Arbeitsverzeichnis
process.platformwin32, linux, darwin
process.exit(1)Programm beenden (0 = OK, andere Zahl = Fehler)
process.on("SIGINT", …)Auf Strg+C reagieren (z. B. aufräumen)

Tipps & typische Fehler

  • .env in die .gitignore eintragen. Stattdessen eine .env.example ohne echte Werte committen.
  • Umgebungsvariablen sind immer Strings – Zahlen mit Number() umwandeln.
