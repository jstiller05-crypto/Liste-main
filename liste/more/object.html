<object>

Bindet eine externe Datei ein (z. B. PDF oder SVG) – mit Ersatzinhalt, falls das nicht klappt.

Was ist das?

<object> ähnelt <embed>, hat aber einen Vorteil: Zwischen den Tags darf ein Ersatzinhalt stehen, der erscheint, wenn der Browser die Datei nicht anzeigen kann.

Beispiel

<object data="anleitung.pdf" type="application/pdf" width="100%" height="500">
  <p>PDF kann nicht angezeigt werden.
     <a href="anleitung.pdf">PDF herunterladen</a></p>
</object>

Wichtige Attribute

AttributBedeutung
dataPfad zur Datei
typeDateityp, z. B. application/pdf oder image/svg+xml
width / heightGröße

Tipps & typische Fehler

  • Für Bilder <img> verwenden, für Webseiten <iframe>.
  • Immer einen Download-Link als Ersatz anbieten.
