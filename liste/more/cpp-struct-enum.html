struct & enum

Eigene Datentypen: zusammengehörige Werte bündeln und feste Auswahlmöglichkeiten benennen.

struct

struct Task {
    std::string question;
    int answer;
    int difficulty = 1;      // Standardwert
};

Task task1 = {"3 + 4", 7};          // difficulty = 1
Task task2{"12 / 3", 4, 2};

std::cout << task1.question << " = " << task1.answer << "\n";
task1.difficulty = 3;

Ein struct ist im Grunde eine Klasse, bei der alles standardmäßig public ist. Üblich für reine Datenpakete ohne viel Logik.

enum class

enum class Difficulty {
    Easy,
    Medium,
    Hard
};

Difficulty level = Difficulty::Medium;

switch (level) {
    case Difficulty::Easy:   std::cout << "Leicht\n"; break;
    case Difficulty::Medium: std::cout << "Mittel\n"; break;
    case Difficulty::Hard:   std::cout << "Schwer\n"; break;
}

int value = static_cast<int>(level);   // 1 – Umwandlung in Zahl nur ausdrücklich

Tipps & typische Fehler

  • Semikolon nach der schließenden Klammer nicht vergessen: struct X { … };.
  • Mit enum class statt „magischen Zahlen“ (0 = leicht, 1 = mittel …) wird Code viel lesbarer.
