TypeScript · Grundlagen

Was ist TypeScript?

TypeScript ist JavaScript mit Typangaben. Es findet Fehler schon beim Schreiben – und wird am Ende in normales JavaScript übersetzt.

Die Idee in einem Satz

Jedes JavaScript ist auch gültiges TypeScript. TypeScript fügt nur Typen hinzu: Du schreibst dazu, was eine Variable enthalten darf. Der TypeScript-Compiler prüft das und meckert, bevor du die Seite überhaupt öffnest.

// JavaScript: der Fehler fällt erst im Browser auf
function double(value) {
  return value * 2;
}
double("5");   // ergibt 10 – oder NaN, je nach Fall. Keine Warnung.

// TypeScript: ": number" sagt, was erlaubt ist
function double(value: number): number {
  return value * 2;
}
double("5");   // Fehler schon im Editor: "string" ist nicht "number"

Wie läuft TypeScript?

  1. Du schreibst Dateien mit der Endung .ts (statt .js).
  2. Der Compiler tsc prüft die Typen und erzeugt daraus normale .js-Dateien.
  3. Die Typangaben werden dabei einfach entfernt – der Browser oder Node.js sieht nur JavaScript.
Browser können TypeScript nicht direkt ausführen. Es braucht immer einen Übersetzungsschritt – den erledigt tsc, Vite oder ein anderes Build-Tool.

Installieren (Windows und Linux gleich)

Voraussetzung ist Node.js. Die Befehle sind in PowerShell und im Linux-Terminal identisch.

# im Projektordner
npm init -y                      # package.json anlegen (falls noch nicht da)
npm install -D typescript        # TypeScript nur für die Entwicklung installieren
npx tsc --init                   # tsconfig.json mit Einstellungen erzeugen

npx tsc                          # alle .ts-Dateien prüfen und übersetzen
npx tsc --watch                  # bei jeder Änderung automatisch neu übersetzen
npx tsc --noEmit                 # nur prüfen, keine .js-Dateien erzeugen

Erstes Beispiel

// hallo.ts
const userName: string = "Max Mustermann";
let visits: number = 3;

function greet(name: string): string {
  return `Hallo ${name}, Besuch Nummer ${visits}`;
}

console.log(greet(userName));
// visits = "viele";   // Fehler: Type 'string' is not assignable to type 'number'.
npx tsc hallo.ts      # erzeugt hallo.js
node hallo.js         # Hallo Max Mustermann, Besuch Nummer 3

Schneller Start mit Vite

Für eine Webseite ist Vite am bequemsten: Es übersetzt TypeScript automatisch, du musst tsc nicht selbst starten.

npm create vite@latest mein-projekt -- --template vanilla-ts
cd mein-projekt
npm install
npm run dev

Im HTML bindest du dann direkt main.ts ein – Vite kümmert sich um den Rest.

Tipps & typische Fehler

  • Du musst nicht alles typisieren: TypeScript errät viele Typen selbst (siehe „Typen“).
  • Typfehler verhindern nicht zwingend die Ausgabe – tsc erzeugt trotzdem JavaScript. Fehler also ernst nehmen und lesen.
  • VS Code versteht TypeScript ohne Erweiterung: Fehler erscheinen rot unterstrichen schon beim Tippen.
  • Zum Ausprobieren ohne Installation gibt es den offiziellen „TypeScript Playground“ im Browser.
