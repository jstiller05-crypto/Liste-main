HTML · Medien

<audio>

Spielt Audiodateien direkt im Browser ab – mit eingebauter Steuerung.

Was ist das?

<audio> bettet Musik, Podcasts oder Soundeffekte ein. Mit controls erscheinen Play, Pause, Lautstärke und Zeitleiste. Über <source> kannst du mehrere Formate anbieten – der Browser nimmt das erste, das er kann.

Beispiel

<audio controls>
  <source src="sound.mp3" type="audio/mpeg">
  <source src="sound.ogg" type="audio/ogg">
  Dein Browser unterstützt kein Audio.   <!-- nur sichtbar, wenn nichts klappt -->
</audio>

Wichtige Attribute

AttributBedeutung
controlsZeigt die Steuerung an
autoplayStartet sofort – wird von Browsern meist blockiert, außer mit muted
loopWiederholt endlos
mutedStartet stumm
preloadnone, metadata oder auto – wie viel vorab geladen wird

Mit JavaScript steuern

const audio = document.querySelector("audio");

audio.play();          // abspielen
audio.pause();         // pausieren
audio.volume = 0.5;    // Lautstärke 0 bis 1
audio.currentTime = 0; // an den Anfang springen

audio.addEventListener("ended", () => console.log("Fertig abgespielt"));

Tipps & typische Fehler

  • MP3 wird von allen Browsern unterstützt.
  • Automatisch startender Ton nervt – lieber den Nutzer selbst starten lassen.
