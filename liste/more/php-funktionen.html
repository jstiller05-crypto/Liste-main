Funktionen & include

Eigene Funktionen schreiben und Code auf mehrere Dateien verteilen.

Funktionen

<?php
function greet(string $name, string $greeting = "Hallo"): string {
    return "$greeting, $name!";
}

echo greet("Max");               // Hallo, Max!
echo greet("Anna", "Moin");      // Moin, Anna!

// Pfeilfunktion (kurz)
$double = fn($x) => $x * 2;
echo $double(4);                 // 8
TeilBedeutung
string $nameParameter mit Typangabe (optional, aber empfohlen)
= "Hallo"Standardwert
: stringRückgabetyp
?stringTyp oder null

Gültigkeitsbereich

$counter = 5;

function show() {
    // echo $counter;   // Fehler: Variablen von außen sind hier NICHT sichtbar
}

function showWith(int $counter) {   // besser: als Parameter übergeben
    echo $counter;
}

Dateien einbinden

<?php
require_once "config.php";      // Pflicht – bricht ab, wenn die Datei fehlt
require_once "functions.php";
include "header.php";           // optional – nur Warnung, wenn sie fehlt
?>
<main>…</main>
<?php include "footer.php"; ?>
BefehlWenn Datei fehltMehrfach einbinden
includeWarnung, läuft weiterJa
requireFehler, AbbruchJa
include_once / require_oncewie obenNur einmal

So muss ein gemeinsamer Kopf- und Fußbereich nur einmal geschrieben werden.

Tipps & typische Fehler

  • require_once für Dateien mit Funktionen oder Klassen – so werden sie nicht doppelt definiert.
  • Pfade sicher bauen: require_once __DIR__ . "/config.php"; – __DIR__ ist der Ordner der aktuellen Datei.
