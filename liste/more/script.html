HTML · Einbinden

<script>

Bindet JavaScript ein – als eigene Datei oder direkt im HTML.

Was ist das?

Mit <script> bringst du JavaScript in die Seite. Entweder verweist src auf eine .js-Datei, oder der Code steht zwischen den Tags.

Beispiele

<!-- Externe Datei (empfohlen) -->
<script defer src="app.js"></script>

<!-- Code direkt im HTML -->
<script>
  console.log("Seite geladen");
</script>

<!-- Modernes Modul (import/export möglich) -->
<script type="module" src="app.js"></script>

defer, async oder nichts?

VarianteWann läuft das Skript?
<script src>Sofort – das HTML-Laden stoppt so lange. Im <head> sind Elemente noch nicht da!
<script defer src>Nachdem das HTML fertig ist, in der richtigen Reihenfolge. Meist die beste Wahl.
<script async src>Sobald die Datei geladen ist – Reihenfolge nicht garantiert. Für unabhängige Skripte (z. B. Statistik).

Warum „Element nicht gefunden“?

Steht ein Skript ohne defer im <head>, läuft es, bevor der Browser den <body> kennt. document.getElementById(…) liefert dann null. Lösungen:

  • defer ans <script> schreiben, oder
  • den Code in document.addEventListener("DOMContentLoaded", …) packen, oder
  • das <script> ans Ende des <body> setzen.

Tipps & typische Fehler

  • Ein <script> mit src muss trotzdem ein End-Tag haben: <script src="…"></script>.
  • JavaScript-Fehler siehst du in der Konsole: F12 → Konsole.
