Für neue Projekte ES Modules verwenden – so wie im Browser. CommonJS begegnet dir aber noch oft in Tutorials.

Eigenes Modul

// mathUtils.js
export function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
// app.js
import { randomInt } from "./mathUtils.js";   // Endung .js ist Pflicht
console.log(randomInt(1, 6));

__dirname in ES Modules

import path from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
// Node 20.11+: kürzer mit import.meta.dirname
const dataFile = path.join(__dirname, "data.json");

Tipps & typische Fehler

  • Das Präfix node: macht klar, dass es ein eingebautes Modul ist (und kein npm-Paket).
  • require und import nicht in derselben Datei mischen.
  • Pfade immer mit path.join bauen – dann funktionieren sie auf Windows und Linux.
