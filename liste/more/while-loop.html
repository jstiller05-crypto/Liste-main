while-Schleife

Was ist das?

Eine while-Schleife wiederholt einen Codeblock solange eine Bedingung erfüllt ist.

Syntax

while (Bedingung) {
    // Code wird wiederholt, solange Bedingung wahr ist
}

do {
    // Code wird mindestens einmal ausgeführt
} while (Bedingung);

Beispiel

#include <iostream>
using namespace std;

int main() {
    int i = 1;
    
    // Normale while-Schleife
    while (i <= 5) {
        cout << "i = " << i << endl;
        i++;
    }
    
    cout << "---" << endl;
    
    // do-while: wird mindestens einmal ausgeführt
    int j = 10;
    do {
        cout << "j = " << j << endl;
        j++;
    } while (j <= 5);  // Bedingung ist falsch, aber Code wurde einmal ausgeführt
    
    return 0;
}

Wann nutzt man es?

  • while: Wenn du nicht weißt, wie oft die Schleife laufen wird
  • do-while: Wenn der Code mindestens einmal ausgeführt werden muss
  • Beispiel: Menu, das solange läuft, bis der Nutzer "Beenden" wählt

Wichtige Hinweise

  • Achte auf Endlosschleifen! (Bedingung wird nie falsch)
  • `break` beendet die Schleife
  • `continue` springt zum nächsten Durchlauf
