<link> – Dateien einbinden

Verbindet die Seite mit externen Dateien – vor allem CSS-Stylesheets und Icons.

Was ist das?

<link> steht im <head> und ist ein leeres Element. Was eingebunden wird, sagt rel (relation). JavaScript wird dagegen mit <script> eingebunden.

Einbinden bedeutet: Die Datei liegt getrennt, die HTML-Seite verweist nur darauf. So kann dieselbe CSS- oder JS-Datei von vielen Seiten genutzt werden.

Beispiel

<head>
  <!-- CSS-Datei -->
  <link rel="stylesheet" href="style.css">

  <!-- Icon im Browser-Tab (Favicon) -->
  <link rel="icon" type="image/x-icon" href="icons/favicon.ico">

  <!-- Schriftart von Google Fonts -->
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter&display=swap">

  <!-- JavaScript: nicht mit link, sondern mit script! -->
  <script defer src="script.js"></script>
</head>

Häufige rel-Werte

relBindet ein …
stylesheetCSS-Datei
iconFavicon (Icon im Tab)
preloadDatei, die früh geladen werden soll
preconnectFrühe Verbindung zu einem Server (z. B. für Schriften)

Tipps & typische Fehler

  • CSS lädt nicht? In der Konsole (F12 → Netzwerk) nach roten Einträgen schauen – meist stimmt der Pfad nicht.
  • ../ im Pfad geht einen Ordner nach oben.
  • Wird dieselbe Datei zweimal eingebunden, wird sie doppelt geladen – einmal reicht.
