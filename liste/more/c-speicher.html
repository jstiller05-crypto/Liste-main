malloc & free

Speicher zur Laufzeit anfordern, vergrößern und wieder freigeben.

Grundform

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    size_t count = 5;
    int *numbers = malloc(count * sizeof *numbers);   /* Platz für 5 int */
    if (numbers == NULL) {                           /* malloc kann fehlschlagen */
        fprintf(stderr, "Kein Speicher!\n");
        return 1;
    }

    for (size_t i = 0; i < count; i++) {
        numbers[i] = (int)(i * 10);
    }

    free(numbers);       /* zurückgeben – genau einmal */
    numbers = NULL;      /* Schutz vor versehentlicher Weiterverwendung */
    return 0;
}

Die Funktionen

FunktionWirkung
malloc(bytes)Speicher anfordern – Inhalt ist zufällig
calloc(anzahl, größe)Speicher anfordern und mit 0 füllen
realloc(ptr, neue_bytes)Vergrößern/verkleinern (Daten bleiben erhalten)
free(ptr)Speicher freigeben

Dynamisch wachsende Liste

size_t capacity = 4, size = 0;
int *list = malloc(capacity * sizeof *list);

void push(int value) {             /* vereinfacht: globale Variablen */
    if (size == capacity) {
        capacity *= 2;
        int *bigger = realloc(list, capacity * sizeof *list);
        if (bigger == NULL) { /* Fehler behandeln, list bleibt gültig */ return; }
        list = bigger;
    }
    list[size++] = value;
}

So funktioniert im Grunde auch std::vector in C++ – nur automatisch.

Tipps & typische Fehler

  • Jedes malloc braucht genau ein free – sonst Speicherleck, zweimal = Absturz.
  • Speicherfehler findet man auf Linux mit valgrind ./programm oder beim Kompilieren mit -fsanitize=address.
  • realloc nie direkt ptr = realloc(ptr, …) zuweisen – schlägt es fehl, ist der alte Zeiger verloren.
