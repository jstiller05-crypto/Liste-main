Klassen & Generics

Klassen mit Sichtbarkeit (public, private, protected) und Generics – Typen als Platzhalter.

Klassen mit Typen

Klassen funktionieren wie in JavaScript. Neu ist: Eigenschaften werden mit Typ oben in der Klasse angegeben.

class Counter {
  count: number = 0;
  label: string;

  constructor(label: string) {
    this.label = label;
  }

  increase(by: number = 1): void {
    this.count += by;
    console.log(`${this.label}: ${this.count}`);
  }
}

const clicks = new Counter("Klicks");
clicks.increase();    // Klicks: 1
clicks.increase(5);   // Klicks: 6

class BankAccount {
  private balance: number = 0;
  readonly owner: string;

  constructor(owner: string) {
    this.owner = owner;
  }

  deposit(amount: number): void {
    if (amount <= 0) {
      console.warn("[konto] Betrag muss positiv sein");
      return;
    }
    this.balance += amount;
  }

  getBalance(): number {
    return this.balance;
  }
}

const account = new BankAccount("Max Mustermann");
account.deposit(50);
console.log(account.getBalance());   // 50
// account.balance = 1000;           // Fehler: balance ist private
private gilt nur beim Prüfen durch TypeScript. Echtes Verstecken zur Laufzeit geht mit #balance aus JavaScript.

Klassen und Interfaces: implements

interface Shape {
  area(): number;
}

class Circle implements Shape {
  constructor(private radius: number) {}
  area(): number {
    return Math.PI * this.radius ** 2;
  }
}

class Rectangle implements Shape {
  constructor(private width: number, private height: number) {}
  area(): number {
    return this.width * this.height;
  }
}

const shapes: Shape[] = [new Circle(2), new Rectangle(3, 4)];
shapes.forEach((shape) => console.log(shape.area().toFixed(2)));

Abstrakte Klassen

abstract class Animal {
  constructor(protected name: string) {}
  abstract makeSound(): string;          // Unterklassen MÜSSEN das haben
  introduce(): void {
    console.log(`${this.name} sagt ${this.makeSound()}`);
  }
}

class Cat extends Animal {
  makeSound() { return "Miau"; }
}

new Cat("Minka").introduce();   // Minka sagt Miau
// new Animal("x");            // Fehler: abstrakte Klasse

Generics: Typen als Platzhalter

Manchmal soll eine Funktion mit verschiedenen Typen funktionieren, aber trotzdem wissen, was herauskommt. Dafür gibt es einen Platzhalter in spitzen Klammern, meist T genannt.

// ohne Generic: Rückgabe ist "any" – Typ geht verloren
function firstAny(list: any[]): any {
  return list[0];
}

// mit Generic: T ist der Typ der Elemente
function first<T>(list: T[]): T | undefined {
  return list[0];
}

const n = first([3, 7, 9]);          // n ist number | undefined
const s = first(["a", "b"]);         // s ist string | undefined

TypeScript setzt T automatisch ein. Du kannst es auch selbst angeben: first<string>([...]).

Generics, die du schon kennst

const names: Array<string> = [];              // Array von strings
const cache = new Map<string, number>();       // Schlüssel string, Wert number
const ids = new Set<number>();
const promise: Promise<string> = fetch("https://example.com/")
  .then((response) => response.text());

Eigene generische Klasse

class Box<T> {
  constructor(private content: T) {}
  get(): T {
    return this.content;
  }
}

const numberBox = new Box(42);          // Box<number>
const textBox = new Box("Hallo");       // Box<string>
console.log(numberBox.get() + 1);       // 43
console.log(textBox.get().toUpperCase());

Generics einschränken

// T muss mindestens eine length-Eigenschaft haben
function longest<T extends { length: number }>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}

longest("Apfel", "Kiwi");        // ok (strings haben length)
longest([1, 2], [1, 2, 3]);      // ok (Arrays haben length)
// longest(10, 20);              // Fehler: number hat kein length

Praxis: fetch mit Typ

interface Todo {
  id: number;
  title: string;
  completed: boolean;
}

async function loadJson<T>(url: string): Promise<T> {
  const response = await fetch(url);
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  return (await response.json()) as T;   // Achtung: nur behauptet, nicht geprüft
}

loadJson<Todo[]>("https://example.com/todos.json")
  .then((todos) => todos.forEach((todo) => console.log(todo.title)))
  .catch((error) => console.error("[todos] Laden fehlgeschlagen:", error));

Tipps & typische Fehler

  • Einbuchstabige Namen sind üblich: T (Type), K (Key), V (Value).
  • Generics erst benutzen, wenn eine Funktion wirklich mit mehreren Typen arbeiten soll – sonst reicht ein fester Typ.
  • private und protected verschwinden beim Übersetzen. Für echte Privatsphäre #feld verwenden.
