Datenbank mit Node.js

SQL-Datenbanken aus Node.js ansprechen – sicher mit Platzhaltern.

SQLite (eingebaut, ab Node 22.13 / 23.4)

import { DatabaseSync } from "node:sqlite";

const db = new DatabaseSync("app.db");   // Datei wird angelegt, falls nicht vorhanden

db.exec(`
  CREATE TABLE IF NOT EXISTS scores (
    id     INTEGER PRIMARY KEY AUTOINCREMENT,
    name   TEXT NOT NULL,
    points INTEGER NOT NULL
  )
`);

// Einfügen – mit ? als Platzhalter
const insert = db.prepare("INSERT INTO scores (name, points) VALUES (?, ?)");
insert.run("Max", 120);
insert.run("Anna", 150);

// Abfragen
const top = db.prepare("SELECT name, points FROM scores ORDER BY points DESC LIMIT ?").all(3);
console.table(top);

Für ältere Node-Versionen gibt es das Paket better-sqlite3 mit fast gleicher Schreibweise.

MySQL / MariaDB (Paket mysql2)

import mysql from "mysql2/promise";

const db = await mysql.createConnection({
  host: "localhost",
  user: "root",
  password: process.env.DB_PASSWORD,   // Passwort aus der .env
  database: "app"
});

const [rows] = await db.execute(
  "SELECT * FROM users WHERE email = ?",
  [email]                              // Wert getrennt übergeben
);
console.log(rows);

Mit Express kombinieren

app.get("/api/scores", (req, res) => {
  const rows = db.prepare("SELECT * FROM scores ORDER BY points DESC").all();
  res.json(rows);
});

Tipps & typische Fehler

  • Nie Werte direkt in den SQL-Text einbauen ("… WHERE name = '" + name + "'") – das ermöglicht SQL-Injection. Immer ?-Platzhalter verwenden.
  • Zugangsdaten gehören in die .env, nicht in den Code.
  • SQLite braucht keinen eigenen Server – ideal zum Lernen und für kleine Projekte.
