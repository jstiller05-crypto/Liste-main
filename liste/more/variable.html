Variablen

Was ist das?

Eine Variable ist ein benannter Speicherbereich, der einen Wert eines bestimmten Typs speichert.

Syntax

Typ variableName;              // Deklaration
Typ variableName = wert;       // Deklaration mit Initialisierung
variableName = neuerWert;      // Zuweisung

Beispiel

#include <iostream>
using namespace std;

int main() {
    // Deklaration
    int alter;
    
    // Deklaration mit Initialisierung
    int gewicht = 75;
    string name = "Anna";
    float temperatur = 36.5f;
    
    // Zuweisung
    alter = 28;
    
    cout << "Name: " << name << endl;
    cout << "Alter: " << alter << endl;
    
    return 0;
}

Namenskonventionen

  • Beginne mit Buchstabe oder Unterstrich (_)
  • Keine Leerzeichen oder Sonderzeichen (außer _)
  • Groß- und Kleinschreibung wird unterschieden
  • Good Practice: aussagekräftige Namen verwenden (z.B. `alter` statt `a`)

Wichtige Hinweise

  • Variablen müssen deklariert werden, bevor sie verwendet werden
  • Nicht initialisierte Variablen enthalten zufällige Werte (Garbage)
  • Mit `const` können Konstanten definiert werden: `const int MAX = 100;`
