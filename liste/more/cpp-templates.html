Templates

Funktionen und Klassen schreiben, die mit beliebigen Datentypen funktionieren.

Was ist das?

Ohne Templates müsste man max für int, double, std::string … jeweils einzeln schreiben. Ein Template ist eine Vorlage, aus der der Compiler für jeden benutzten Typ eine passende Version erzeugt. std::vector<int> ist selbst ein Template.

Funktions-Template

template <typename T>
T biggest(T a, T b) {
    return (a > b) ? a : b;
}

std::cout << biggest(3, 7) << "\n";            // T = int     → 7
std::cout << biggest(2.5, 1.5) << "\n";        // T = double  → 2.5
std::cout << biggest<std::string>("Apfel", "Birne") << "\n";   // Typ ausdrücklich

Klassen-Template

template <typename T>
class Box {
public:
    Box(T value) : value(value) {}
    T get() const { return value; }
private:
    T value;
};

Box<int> numberBox(42);
Box<std::string> textBox("Hallo");
std::cout << numberBox.get() << " " << textBox.get() << "\n";

Tipps & typische Fehler

  • Templates stehen komplett im Header – die Definition muss beim Benutzen sichtbar sein.
  • Fehlermeldungen bei Templates sind oft sehr lang. Die wichtige Zeile steht meist ganz oben („required from here“).
  • Für den Einstieg reicht es, Templates benutzen zu können (vector, map) – eigene schreibt man seltener.
