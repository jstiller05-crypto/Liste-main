List, Dictionary & LINQ

Listen und Wörterbücher – und mit LINQ elegant filtern, sortieren und auswerten.

Array & List<T>

int[] fixedNumbers = { 3, 1, 4 };        // Array: feste Größe

var numbers = new List<int> { 3, 1, 4 };  // List: wächst automatisch
numbers.Add(9);
numbers.Remove(1);                        // Wert entfernen
numbers.RemoveAt(0);                      // Position entfernen
numbers.Insert(0, 7);
numbers.Contains(4);                      // true
numbers.Count;                            // Anzahl
numbers.Sort();

Dictionary<TKey, TValue>

var highscores = new Dictionary<string, int> {
    ["Max"] = 120,
    ["Anna"] = 150
};

highscores["Tom"] = 90;                   // hinzufügen / überschreiben

if (highscores.TryGetValue("Lisa", out int score)) {
    Console.WriteLine(score);
} else {
    Console.WriteLine("Lisa nicht gefunden");
}

foreach (var (name, points) in highscores) {
    Console.WriteLine($"{name}: {points}");
}

LINQ

using System.Linq;   // meist schon automatisch eingebunden

var players = new List<(string Name, int Score)> {
    ("Max", 120), ("Anna", 150), ("Tom", 90)
};

var top = players
    .Where(p => p.Score >= 100)           // filtern
    .OrderByDescending(p => p.Score)      // sortieren
    .Select(p => p.Name)                  // umwandeln
    .ToList();

Console.WriteLine(string.Join(", ", top));   // Anna, Max

int total = players.Sum(p => p.Score);
double average = players.Average(p => p.Score);
bool anyLow = players.Any(p => p.Score < 100);
var first = players.FirstOrDefault(p => p.Name == "Tom");

Tipps & typische Fehler

  • Bei highscores["Unbekannt"] wirft ein Dictionary eine Exception – TryGetValue oder ContainsKey verwenden.
  • LINQ-Abfragen werden erst ausgeführt, wenn man das Ergebnis braucht – .ToList() erzwingt es.
