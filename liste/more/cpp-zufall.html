Zufallszahlen

Zufällige Zahlen modern mit <random> erzeugen – und warum man rand() meiden sollte.

Modern mit <random>

#include <iostream>
#include <random>

int main() {
    std::random_device seed;                     // echter Zufall als Startwert
    std::mt19937 generator(seed());              // schneller, guter Zufallsgenerator

    std::uniform_int_distribution<int> dice(1, 6);   // gleichmäßig 1 bis 6 (inklusive)

    for (int i = 0; i < 5; ++i) {
        std::cout << dice(generator) << " ";
    }
    std::cout << "\n";
    return 0;
}
BausteinAufgabe
std::random_deviceLiefert einen unvorhersehbaren Startwert (Seed)
std::mt19937Der eigentliche Generator (Mersenne Twister)
uniform_int_distribution<int>(a, b)Ganze Zahlen von a bis b
uniform_real_distribution<double>(a, b)Kommazahlen von a bis unter b
bernoulli_distribution(0.3)true mit 30 % Wahrscheinlichkeit

Als Hilfsfunktion

int randomInt(int min, int max) {
    static std::mt19937 generator(std::random_device{}());   // static: nur EINMAL anlegen
    std::uniform_int_distribution<int> dist(min, max);
    return dist(generator);
}

// Beispiel: zufällige Rechenaufgabe
int a = randomInt(1, 10);
int b = randomInt(1, 10);
std::cout << a << " + " << b << " = ?\n";

Mischen & zufällig auswählen

std::vector<std::string> tasks = {"A", "B", "C", "D"};

static std::mt19937 generator(std::random_device{}());
std::shuffle(tasks.begin(), tasks.end(), generator);   // <algorithm>

std::uniform_int_distribution<size_t> pick(0, tasks.size() - 1);
std::cout << tasks[pick(generator)] << "\n";

Der alte Weg: rand()

#include <cstdlib>
#include <ctime>

std::srand(std::time(nullptr));      // Startwert einmal setzen
int dice = std::rand() % 6 + 1;      // 1 bis 6 – ungleichmäßig verteilt

rand() findet man noch oft in Tutorials. Es ist aber ungenau verteilt und von schlechter Qualität – für neuen Code <random> verwenden.

Tipps & typische Fehler

  • Den Generator nicht bei jedem Aufruf neu erzeugen – sonst kommen oft dieselben Zahlen. Einmal anlegen (z. B. static) und wiederverwenden.
  • Für reproduzierbare Tests einen festen Seed verwenden: std::mt19937 generator(42); – dann kommen immer dieselben „Zufallszahlen“.
  • In Qt gibt es zusätzlich QRandomGenerator::global()->bounded(1, 7).
