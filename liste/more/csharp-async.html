async/await & Dateien

Asynchrone Methoden, Dateien lesen/schreiben und JSON in C#.

async & await

static async Task<string> LoadAsync(string url) {
    using var client = new HttpClient();
    return await client.GetStringAsync(url);    // wartet, ohne das Programm zu blockieren
}

string html = await LoadAsync("https://example.com");
Console.WriteLine(html.Length);

Wie in JavaScript: async markiert die Methode, await wartet auf das Ergebnis. Rückgabetyp ist Task bzw. Task<T>.

Tipps & typische Fehler

  • Methoden, die await benutzen, müssen async sein und heißen üblicherweise …Async.
  • Path.Combine statt Strings mit \ oder / – dann funktioniert es auf Windows und Linux.
