Schleifen

Code wiederholen: for, while, for…of, forEach – und wie man abbricht.

for – feste Anzahl

for (let i = 0; i < 5; i++) {
  console.log("Durchlauf", i);   // 0, 1, 2, 3, 4
}
//   Start     Bedingung  Schritt

while / do…while – solange eine Bedingung gilt

let tries = 0;
while (tries < 3) {
  console.log("Versuch", tries);
  tries++;
}

// do…while läuft mindestens einmal
let answer;
do {
  answer = prompt("Passwort?");
} while (answer !== "geheim");

Über Arrays und Objekte

const colors = ["rot", "grün", "blau"];

for (const color of colors) {          // for…of: jeder WERT
  console.log(color);
}

colors.forEach((color, index) => {     // forEach: Wert + Position
  console.log(index, color);
});

const user = { name: "Max", age: 30 };
for (const key in user) {              // for…in: jeder SCHLÜSSEL eines Objekts
  console.log(key, user[key]);
}

Welche Schleife wann?

SchleifeWann?
forDu brauchst einen Zähler oder eine feste Anzahl
for…ofJedes Element eines Arrays/Strings durchgehen
forEachWie for…of, als Methode – kann nicht mit break abbrechen
for…inSchlüssel eines Objekts durchgehen
whileAnzahl vorher unbekannt

Abbrechen und überspringen

for (const n of [1, 2, 3, 4, 5]) {
  if (n === 2) continue;   // diesen Durchlauf überspringen
  if (n === 4) break;      // Schleife komplett beenden
  console.log(n);          // 1, 3
}

Tipps & typische Fehler

  • Endlosschleife: Ändert sich die Bedingung nie (z. B. i++ vergessen), hängt der Browser-Tab.
  • Zum Umwandeln oder Filtern von Arrays sind map und filter oft besser als eine Schleife.
  • i < array.length, nicht <= – sonst greifst du einmal zu weit.
