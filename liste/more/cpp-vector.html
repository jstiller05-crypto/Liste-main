std::vector

Die wichtigste Liste in C++: wächst und schrumpft automatisch.

Anlegen & Zugriff

#include <vector>

std::vector<int> numbers = {3, 1, 4};   // mit Startwerten
std::vector<std::string> names;          // leer
std::vector<int> zeros(10, 0);           // 10 Elemente mit Wert 0

numbers[0];            // 3 – ohne Prüfung
numbers.at(1);         // 1 – mit Prüfung (wirft std::out_of_range)
numbers.front();       // erstes Element
numbers.back();        // letztes Element
numbers.size();        // Anzahl: 3
numbers.empty();       // true, wenn leer

Hinzufügen & Entfernen

MethodeWirkung
push_back(x)Hinten anhängen
emplace_back(args)Hinten direkt erzeugen (spart eine Kopie)
pop_back()Letztes entfernen
insert(pos, x)An Position einfügen
erase(pos)Element an Position entfernen
clear()Alles löschen
resize(n)Größe ändern
 
std::vector<int> scores;
scores.push_back(80);
scores.push_back(95);
scores.push_back(70);

scores.erase(scores.begin() + 1);        // zweites Element (95) entfernen
scores.insert(scores.begin(), 100);      // vorne einfügen

for (const auto& score : scores) {
    std::cout << score << " ";           // 100 80 70
}

An Funktionen übergeben

// nur lesen: const-Referenz (keine Kopie!)
double average(const std::vector<int>& values) {
    if (values.empty()) return 0.0;
    int sum = 0;
    for (int v : values) sum += v;
    return static_cast<double>(sum) / values.size();
}

// ändern: normale Referenz
void addBonus(std::vector<int>& values, int bonus) {
    for (int& v : values) v += bonus;
}

Vector aus Objekten

struct Task {
    std::string question;
    int answer;
};

std::vector<Task> tasks;
tasks.push_back({"3 + 4", 7});
tasks.push_back({"6 * 7", 42});

for (const auto& task : tasks) {
    std::cout << task.question << " = " << task.answer << "\n";
}

Tipps & typische Fehler

  • Beim Übergeben an Funktionen fast immer const std::vector<T>& – sonst wird der ganze Vector kopiert.
  • Während einer Schleife über den Vector keine Elemente hinzufügen oder entfernen – das macht Iteratoren ungültig.
  • size() liefert einen vorzeichenlosen Typ. In for (int i = 0; i < v.size(); ++i) warnt der Compiler – size_t i oder eine bereichsbasierte for-Schleife verwenden.
