if-else

Was ist das?

Mit if-else kannst du verschiedene Codeblöcke basierend auf Bedingungen ausführen.

Syntax

if (Bedingung) {
    // Wird ausgeführt, wenn Bedingung wahr ist
} else if (Bedingung2) {
    // Wird ausgeführt, wenn Bedingung2 wahr ist
} else {
    // Wird ausgeführt, wenn keine Bedingung erfüllt
}

Beispiel

#include <iostream>
using namespace std;

int main() {
    int alter = 20;
    
    if (alter < 13) {
        cout << "Du bist ein Kind." << endl;
    } else if (alter < 18) {
        cout << "Du bist ein Teenager." << endl;
    } else if (alter < 65) {
        cout << "Du bist Erwachsen." << endl;
    } else {
        cout << "Du bist ein Senior." << endl;
    }
    
    return 0;
}

Ausgabe: "Du bist Erwachsen."

Vergleichsoperatoren

  • `==` : ist gleich
  • `!=` : ist nicht gleich
  • `<` : ist kleiner
  • `>` : ist größer
  • `<=` : ist kleiner oder gleich
  • `>=` : ist größer oder gleich

Logische Operatoren

  • `&&` : UND (beide Bedingungen müssen wahr sein)
  • `||` : ODER (mindestens eine Bedingung muss wahr sein)
  • `!` : NICHT (negiert die Bedingung)

Wichtige Hinweise

  • `else` ist optional
  • Geschweifte Klammern `{}` sind optional bei einzelnen Statements, aber empfohlen
  • Ternärer Operator: `int ergebnis = (x > 5) ? 10 : 20;`
