C#

Die Hauptsprache von .NET – für Windows-Apps, Web-Backends, Spiele mit Unity und mehr.

Was ist das?

C# („C Sharp“) wurde von Microsoft entwickelt und läuft auf der .NET-Plattform. Die Syntax ähnelt C++ und Java, aber Speicher wird automatisch verwaltet (Garbage Collector). .NET läuft heute auf Windows, Linux und macOS.

Erstes Projekt

dotnet new console -o HelloApp    # neues Konsolenprojekt
cd HelloApp
dotnet run                         # kompilieren und starten
// Program.cs – "Top-level statements": kein Main nötig
Console.WriteLine("Hallo Welt!");

Console.Write("Wie heißt du? ");
string? name = Console.ReadLine();
Console.WriteLine($"Hallo {name}!");

Tipps & typische Fehler

  • dotnet build kompiliert nur, dotnet run kompiliert und startet, dotnet watch startet bei jeder Änderung neu.
  • Das ? in string? bedeutet: Der Wert darf null sein (Nullable Reference Types).
