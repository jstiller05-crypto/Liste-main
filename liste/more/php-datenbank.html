Datenbank mit PDO

Mit PDO sicher auf MySQL, MariaDB oder SQLite zugreifen.

Verbindung

<?php
try {
    $pdo = new PDO(
        "mysql:host=localhost;dbname=app;charset=utf8mb4",
        "root",
        "",                                            // XAMPP-Standard: kein Passwort
        [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,        // Fehler als Exception
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,   // Zeilen als assoziative Arrays
        ]
    );
} catch (PDOException $e) {
    error_log("[db] " . $e->getMessage());
    exit("Datenbank nicht erreichbar.");
}

// SQLite: new PDO("sqlite:" . __DIR__ . "/app.db");

Abfragen mit Platzhaltern

// mehrere Zeilen
$stmt = $pdo->prepare("SELECT name, points FROM users WHERE points >= :min ORDER BY points DESC");
$stmt->execute(["min" => 100]);
$users = $stmt->fetchAll();

foreach ($users as $user) {
    echo htmlspecialchars($user["name"]) . ": " . $user["points"] . "<br>";
}

// eine Zeile
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$id]);
$user = $stmt->fetch();          // false, wenn nicht gefunden

Einfügen, ändern, löschen

$stmt = $pdo->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
$stmt->execute([$name, $email]);
$newId = $pdo->lastInsertId();

$stmt = $pdo->prepare("UPDATE users SET points = points + ? WHERE id = ?");
$stmt->execute([10, $id]);
echo $stmt->rowCount() . " Zeile(n) geändert";

Wichtige Methoden

MethodeWirkung
prepare($sql)SQL mit Platzhaltern vorbereiten
execute([…])Mit Werten ausführen
fetch()Nächste Zeile (oder false)
fetchAll()Alle Zeilen als Array
fetchColumn()Einen einzelnen Wert, z. B. bei COUNT(*)
lastInsertId()ID des zuletzt eingefügten Datensatzes
rowCount()Anzahl betroffener Zeilen

Tipps & typische Fehler

  • Immer prepare + execute mit Platzhaltern (? oder :name) – nie Variablen direkt in den SQL-Text.
  • Zugangsdaten in eine eigene config.php außerhalb des öffentlichen Ordners oder in Umgebungsvariablen legen.
  • Beim Ausgeben der Daten htmlspecialchars nicht vergessen.
