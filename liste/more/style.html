<style>

Schreibt CSS direkt in die HTML-Seite, statt eine eigene Datei einzubinden.

Was ist das?

CSS kann an drei Stellen stehen. <style> im <head> ist die mittlere Variante:

Die drei Wege für CSS

<!-- 1) Externe Datei – für mehrere Seiten (empfohlen) -->
<link rel="stylesheet" href="style.css">

<!-- 2) style-Element – CSS nur für diese eine Seite -->
<style>
  h1 {
    color: #4f8cff;
  }
</style>

<!-- 3) style-Attribut – nur für dieses eine Element -->
<p style="color: gray;">Grauer Text</p>
WegGut fürNachteil
Externe DateiGanze WebsiteEine Datei mehr
<style>Einzelne Seite, schnelle TestsNicht auf anderen Seiten nutzbar
style="…"Einmalige AusnahmeUnübersichtlich, schwer zu überschreiben

Welche Regel gewinnt?

Gelten mehrere Regeln für dasselbe Element, gewinnt die spezifischere: style-Attribut > ID > Klasse > Element. Bei Gleichstand gewinnt die Regel, die weiter unten steht.

Tipps & typische Fehler

  • Für Projekte mit mehreren Seiten immer eine externe CSS-Datei nutzen.
  • <style> gehört in den <head>.
