PHP

Eine Server-Sprache, die HTML-Seiten erzeugt – bevor sie an den Browser geschickt werden.

Was ist das?

PHP läuft auf dem Server. Ruft jemand eine .php-Seite auf, führt der Server den PHP-Code aus und schickt nur das fertige HTML an den Browser. Der Besucher sieht den PHP-Code nie. Viele Webseiten und Systeme wie WordPress sind in PHP geschrieben.

Ablauf

Browser ──► fordert index.php an ──► Server
                                    │  PHP läuft: liest Datenbank, rechnet …
Browser ◄── fertiges HTML ◄──────────┘

Erste Seite

<!DOCTYPE html>
<html lang="de">
<body>
  <h1>Hallo</h1>
  <p>Heute ist <?php echo date("d.m.Y"); ?></p>

  <?php
    $name = "Welt";
    echo "<p>Hallo $name!</p>";
  ?>

  <p>Kurzform: <?= $name ?></p>   <!-- <?= ist Kurzform für <?php echo -->
</body>
</html>

PHP-Code steht zwischen <?php und ?>. Enthält eine Datei nur PHP, lässt man das schließende ?> weg.

Installieren

SystemInstallation
WindowsXAMPP (PHP + Apache + MySQL in einem Paket) oder PHP einzeln von windows.php.net
Linux (Debian/Ubuntu)sudo apt install php php-cli php-mysql · für MariaDB zusätzlich mariadb-server

Prüfen mit php -v.

Lokal ausführen

MöglichkeitWie
Eingebauter Serverphp -S localhost:8000 im Projektordner, dann http://localhost:8000 öffnen
XAMPPPaket mit Apache, PHP und MySQL – Dateien in den Ordner htdocs legen
Kommandozeilephp skript.php – für Skripte ohne Browser

Eine .php-Datei per Doppelklick im Browser zu öffnen funktioniert nicht – es braucht immer einen Server, der PHP ausführt.

PHP vs. JavaScript im Browser

PHPJavaScript (Browser)
Läuft aufServerComputer des Besuchers
Zugriff auf DatenbankJaNein (nur über eine API)
Reagiert auf Klicks ohne NeuladenNeinJa
Quellcode sichtbarNeinJa

Tipps & typische Fehler

  • Jede Anweisung endet mit ;.
  • Fehler anzeigen beim Entwickeln: ini_set('display_errors', 1); error_reporting(E_ALL); ganz oben – auf einem echten Server wieder abschalten.
  • Aktuelle PHP-Version: mindestens 8.x verwenden.
