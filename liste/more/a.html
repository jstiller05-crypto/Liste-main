HTML · Text & Links

<a>

Erstellt einen Link zu einer anderen Seite, einer Datei, einer Stelle auf derselben Seite, einer E-Mail-Adresse oder einer Telefonnummer.

Was ist das?

<a> steht für anchor (Anker). Ohne Links gäbe es kein Web: Sie verbinden Seiten miteinander. Das Ziel steht im Attribut href, der klickbare Inhalt zwischen Start- und End-Tag.

Der Inhalt darf Text, ein Bild oder sogar ein ganzer Block (z. B. eine Karte) sein.

Syntax

<a href="ziel">Klickbarer Text</a>

Beispiele

<!-- Andere Seite im selben Ordner -->
<a href="img.html">Mehr über Bilder</a>

<!-- Externe Seite in neuem Tab -->
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">MDN Web Docs</a>

<!-- Sprung zu einer Stelle auf derselben Seite (id="kontakt") -->
<a href="#kontakt">Zum Kontakt</a>

<!-- E-Mail und Telefon -->
<a href="mailto:max@example.com">E-Mail schreiben</a>
<a href="tel:+491701234567">Anrufen</a>

<!-- Datei herunterladen -->
<a href="anleitung.pdf" download>PDF herunterladen</a>
Mehr über Bilder · Zum Kontakt

Wichtige Attribute

AttributBedeutung
hrefZiel des Links: URL, Dateipfad, #id, mailto: oder tel:
target_blank öffnet den Link in einem neuen Tab
relBeziehung zum Ziel. Bei target="_blank" immer noopener setzen
downloadLädt die Datei herunter, statt sie zu öffnen
titleTooltip beim Drüberfahren

Relative und absolute Pfade

PfadBedeutung
seite.htmlDatei im selben Ordner
more/seite.htmlDatei in einem Unterordner
../index.html.. = einen Ordner nach oben
/seite.htmlVom Stamm der Website aus. Funktioniert lokal (Datei im Browser geöffnet) oft nicht
https://…Absolute Adresse im Internet

Tipps & typische Fehler

  • Linktext soll verraten, wohin es geht: „Mehr über Bilder“ statt „hier klicken“.
  • Links nicht ineinander verschachteln – ein <a> darf kein weiteres <a> enthalten.
  • Für Aktionen ohne Seitenwechsel (z. B. Menü öffnen) ist <button> das richtige Element, nicht <a>.
  • Lokale Pfade beachten Groß-/Kleinschreibung, sobald die Seite online auf einem Server liegt.
