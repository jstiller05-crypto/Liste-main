int main()

Was ist das?

Die main()-Funktion ist der Einstiegspunkt eines C++-Programms. Hier startet die Ausführung.

Syntax

int main() {
    // Programmcode
    return 0;  // 0 = erfolgreich beendet
}

Beispiel

#include <iostream>
using namespace std;

int main() {
    cout << "Hallo, Welt!" << endl;
    return 0;
}

Dieses Programm gibt "Hallo, Welt!" aus und beendet sich erfolgreich.

Rückgabewert

  • 0 : Programm erfolgreich abgeschlossen
  • Andere Zahlen: Fehlercode (z.B. 1 für Fehler)

Mit Kommandozeilenargumenten

int main(int argc, char* argv[]) {
    // argc = Anzahl der Argumente
    // argv = Array der Argumente
    
    if (argc > 1) {
        cout << "Erstes Argument: " << argv[1] << endl;
    }
    
    return 0;
}

Mit diesem Programm: `./programm hello` gibt "hello" aus

Wichtige Hinweise

  • Pro Programm gibt es nur eine main()-Funktion
  • Das `int` ist der Rückgabewert für das Betriebssystem
  • In modernen Compilern kann `return 0;` am Ende der main() auch weggelassen werden
