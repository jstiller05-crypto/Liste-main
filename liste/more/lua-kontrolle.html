Lua · Kontrollstrukturen

Bedingungen & Schleifen

if, for, while, repeat – und wie man in Lua eine Schleife überspringt.

if / elseif / else

local points = 72

if points >= 90 then
    print("Sehr gut")
elseif points >= 60 then        -- elseif in einem Wort
    print("Bestanden")
else
    print("Nicht bestanden")
end

Zahlen-for

for i = 1, 5 do              -- 1 bis 5 (inklusive)
    print(i)
end

for i = 10, 1, -2 do         -- Start, Ende, Schritt: 10 8 6 4 2
    print(i)
end

for über Tabellen

local colors = { "rot", "grün", "blau" }
for index, color in ipairs(colors) do     -- Listen: der Reihe nach
    print(index, color)
end

local player = { name = "Max", level = 3 }
for key, value in pairs(player) do        -- alle Schlüssel (Reihenfolge nicht garantiert)
    print(key, value)
end

while & repeat

local tries = 0
while tries < 3 do
    tries = tries + 1          -- kein tries++ oder += in Lua!
end

local input
repeat                          -- läuft mindestens einmal
    input = io.read()
until input == "ende"

break & continue

for i = 1, 10 do
    if i > 5 then break end     -- Schleife beenden
    if i % 2 == 0 then goto continue end   -- "continue" gibt es nicht → goto (ab 5.2 / LuaJIT)
    print(i)                    -- 1 3 5
    ::continue::
end

Tipps & typische Fehler

  • Jeder Block endet mit end – then nach if, do nach for/while.
  • x = x + 1 statt x++ oder x += 1 – die Kurzformen gibt es in Standard-Lua nicht (in Luau schon).
  • ipairs stoppt beim ersten nil in der Liste.
