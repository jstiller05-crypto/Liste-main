Flexbox

Ordnet Elemente in einer Reihe oder Spalte an – mit Abständen, Ausrichtung und flexibler Größe.

Was ist das?

Mit display: flex wird ein Element zum Flex-Container. Seine direkten Kinder (Flex-Items) werden dann in einer Linie angeordnet. Flexbox ist ideal für Menüs, Button-Leisten, Karten nebeneinander und zum Zentrieren.

Grundbeispiel

<div class="row">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>
.row {
  display: flex;
  gap: 12px;                      /* Abstand zwischen den Kindern */
  justify-content: space-between; /* Verteilung auf der Hauptachse */
  align-items: center;            /* Ausrichtung auf der Querachse */
}

Häufige Muster

/* 1) Etwas genau in die Mitte */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 300px;
}

/* 2) Logo links, Menü rechts */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* 3) Suchfeld nimmt den Rest der Zeile */
.search-row { display: flex; gap: 8px; }
.search-row input { flex: 1; }

/* 4) Karten, die umbrechen */
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
.cards > * { flex: 1 1 200px; }   /* mind. 200px, sonst gleichmäßig wachsen */

Tipps & typische Fehler

  • Flexbox wirkt nur auf die direkten Kinder des Containers.
  • Eine Richtung (Reihe oder Spalte) → Flexbox. Zwei Richtungen (Raster) → Grid.
  • gap ist sauberer als Margins an den Kindern.
