Zahlen & Datum formatieren (Intl)

Zahlen, Währungen, Datum und relative Zeitangaben automatisch im deutschen Format.

Zahlen & Währung

const number = 1234567.891;

new Intl.NumberFormat("de-DE").format(number);                         // "1.234.567,891"
new Intl.NumberFormat("de-DE", { maximumFractionDigits: 2 }).format(number);   // "1.234.567,89"
new Intl.NumberFormat("de-DE", { style: "currency", currency: "EUR" }).format(19.9);   // "19,90 €"
new Intl.NumberFormat("de-DE", { style: "percent" }).format(0.853);    // "85 %"
new Intl.NumberFormat("de-DE", { notation: "compact" }).format(15300); // "15.300" bzw. "15.3 Tsd."

Datum & Uhrzeit

const date = new Date(2026, 8, 30, 14, 5);    // Monat 8 = September!

new Intl.DateTimeFormat("de-DE").format(date);                 // "30.9.2026"
new Intl.DateTimeFormat("de-DE", { dateStyle: "full" }).format(date);
// "Mittwoch, 30. September 2026"
new Intl.DateTimeFormat("de-DE", { dateStyle: "medium", timeStyle: "short" }).format(date);
// "30.09.2026, 14:05"
new Intl.DateTimeFormat("de-DE", { weekday: "long" }).format(date);   // "Mittwoch"

Relative Zeit

const rtf = new Intl.RelativeTimeFormat("de", { numeric: "auto" });

rtf.format(-1, "day");      // "gestern"
rtf.format(-3, "day");      // "vor 3 Tagen"
rtf.format(2, "week");      // "in 2 Wochen"

Listen & Sortieren

new Intl.ListFormat("de", { type: "conjunction" }).format(["HTML", "CSS", "JS"]);
// "HTML, CSS und JS"

const collator = new Intl.Collator("de");
["Zebra", "Äpfel", "apfel"].sort(collator.compare);   // Umlaute richtig einsortiert

Tipps & typische Fehler

  • Formatter wiederverwenden (einmal in einer Variable anlegen), statt in einer Schleife ständig neu zu erzeugen.
  • toLocaleString("de-DE") ist die Kurzform für einfache Fälle.
  • Für Rechnungen: Beträge in Cent als ganze Zahl rechnen und erst zur Anzeige formatieren.
