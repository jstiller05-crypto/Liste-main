using namespace

Was ist das?

Die using namespace-Anweisung macht Symbole aus einem Namespace verfügbar, ohne den Namespace-Präfix zu brauchen.

Syntax

using namespace std;
using namespace eigenerNamespace;

Beispiel

#include <iostream>
using namespace std;

int main() {
    cout << "Hallo!" << endl;  // ohne std:: Präfix
    return 0;
}

Ohne `using namespace std;` müsste man `std::cout` schreiben.

Wann nutzt man es?

Vor allem für Anfänger praktisch. In größeren Projekten eher sparsam einsetzen, um Namenskollisionen zu vermeiden.

Wichtige Hinweise

  • Standard in vielen Anfänger-Programmen
  • In professionellem Code oft vermieden (kann zu Konflikten führen)
  • Alternative: einzelne Symbole importieren mit `using std::cout;`
