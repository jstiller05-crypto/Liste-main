<algorithm> & Lambdas

Fertige Funktionen zum Sortieren, Suchen, Zählen – und kleine Funktionen direkt im Code.

Lambdas

auto square = [](int x) { return x * x; };
std::cout << square(4) << "\n";   // 16

int bonus = 5;
auto addBonus = [bonus](int x) { return x + bonus; };   // [bonus] = Variable "einfangen"
auto increase = [&bonus]() { bonus++; };                // [&bonus] = per Referenz
CaptureBedeutung
[]Nichts von außen verwenden
[x]x als Kopie
[&x]x als Referenz (Änderungen wirken außen)
[=] / [&]Alles als Kopie / alles als Referenz

Die wichtigsten Algorithmen

#include <algorithm>
#include <numeric>

std::vector<int> v = {5, 2, 8, 1, 9};

std::sort(v.begin(), v.end());                          // 1 2 5 8 9
std::sort(v.begin(), v.end(), std::greater<int>());     // 9 8 5 2 1
std::reverse(v.begin(), v.end());

auto it = std::find(v.begin(), v.end(), 8);             // suchen
if (it != v.end()) { /* gefunden */ }

int count = std::count(v.begin(), v.end(), 5);          // wie oft 5?
int bigOnes = std::count_if(v.begin(), v.end(),
                            [](int x) { return x > 4; });

int maxValue = *std::max_element(v.begin(), v.end());
int sum = std::accumulate(v.begin(), v.end(), 0);       // <numeric>

bool allPositive = std::all_of(v.begin(), v.end(), [](int x) { return x > 0; });

Objekte sortieren

struct Player { std::string name; int score; };
std::vector<Player> players = {{"Max", 120}, {"Anna", 150}, {"Tom", 90}};

std::sort(players.begin(), players.end(),
          [](const Player& a, const Player& b) {
              return a.score > b.score;         // höchster Score zuerst
          });

Elemente entfernen (erase-remove)

// alle negativen Zahlen entfernen
v.erase(std::remove_if(v.begin(), v.end(), [](int x) { return x < 0; }),
        v.end());

// C++20 kürzer:
std::erase_if(v, [](int x) { return x < 0; });

Tipps & typische Fehler

  • begin() und end() markieren den Bereich – end() zeigt hinter das letzte Element.
  • Eigene Schleife geschrieben, die sortiert oder zählt? Oft gibt es dafür schon einen Algorithmus.
  • std::shuffle (mit einem Zufallsgenerator) mischt einen Vector – z. B. Aufgaben in zufälliger Reihenfolge.
