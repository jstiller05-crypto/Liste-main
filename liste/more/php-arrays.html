PHP · Daten

Arrays

Listen und assoziative Arrays (Schlüssel → Wert) – das wichtigste Datenwerkzeug in PHP.

Indizierte Arrays

<?php
$colors = ["rot", "grün", "blau"];

echo $colors[0];          // "rot"
$colors[] = "gelb";       // hinten anhängen
echo count($colors);      // 4

Assoziative Arrays

$user = [
    "name"   => "Max",
    "age"    => 17,
    "skills" => ["HTML", "CSS"]
];

echo $user["name"];                 // "Max"
$user["city"] = "Musterstadt";      // hinzufügen
unset($user["age"]);                // entfernen
isset($user["email"]);              // false – existiert der Schlüssel?

$users = [                          // Liste von Datensätzen (typisch aus der Datenbank)
    ["name" => "Max",  "points" => 120],
    ["name" => "Anna", "points" => 150],
];

Wichtige Funktionen

FunktionWirkung
count($a)Anzahl
in_array("rot", $a)Ist Wert enthalten?
array_key_exists("name", $a)Gibt es den Schlüssel?
array_push($a, $x) / $a[] = $xAnhängen
array_pop($a) / array_shift($a)Letztes / erstes entfernen
array_merge($a, $b)Zusammenfügen
array_keys($a) / array_values($a)Nur Schlüssel / nur Werte
array_map(fn, $a)Jedes Element umwandeln
array_filter($a, fn)Passende Elemente behalten
array_column($users, "name")Eine Spalte aus einer Liste von Datensätzen
sort / rsort / usortSortieren (ändert das Original)

Beispiel

$users = [
    ["name" => "Max",  "points" => 120],
    ["name" => "Anna", "points" => 150],
    ["name" => "Tom",  "points" => 90],
];

// nur Nutzer ab 100 Punkten
$good = array_filter($users, fn($u) => $u["points"] >= 100);

// nach Punkten absteigend sortieren
usort($users, fn($a, $b) => $b["points"] <=> $a["points"]);

// nur die Namen
$names = array_column($users, "name");   // ["Anna", "Max", "Tom"]

print_r($names);   // Array lesbar ausgeben (zum Debuggen)

Tipps & typische Fehler

  • In PHP gibt es nur einen Array-Typ – er ist Liste und „Objekt“ (wie in JS) in einem.
  • print_r in <pre> einpacken, dann bleibt die Ausgabe im Browser eingerückt: echo "<pre>"; print_r($a); echo "</pre>";.
  • sort und usort ändern das Original und geben nur true zurück.
