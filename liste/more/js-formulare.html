Formulare mit JavaScript

Eingaben lesen, prüfen, eigene Fehlermeldungen anzeigen und ohne Neuladen absenden.

Grundgerüst

<form id="signupForm" novalidate>
  <label for="email">E-Mail</label>
  <input id="email" name="email" type="email" required>
  <p class="error" id="emailError" aria-live="polite"></p>

  <label for="age">Alter</label>
  <input id="age" name="age" type="number" min="1" max="120">

  <button type="submit">Anmelden</button>
</form>

novalidate schaltet die Browser-Sprechblasen ab, damit wir eigene Meldungen anzeigen können – die HTML-Regeln (required, type="email") gelten trotzdem und lassen sich per JS abfragen.

Prüfen & absenden

const form = document.getElementById("signupForm");
const email = document.getElementById("email");
const emailError = document.getElementById("emailError");

// Live-Prüfung beim Tippen
email.addEventListener("input", () => {
  emailError.textContent = email.validity.valid ? "" : "Bitte eine gültige E-Mail eingeben.";
});

form.addEventListener("submit", async (event) => {
  event.preventDefault();                          // nicht neu laden

  if (!form.checkValidity()) {                     // alle HTML-Regeln erfüllt?
    console.warn("[form] ungültig");
    form.querySelector(":invalid")?.focus();       // zum ersten Fehler springen
    return;
  }

  const data = Object.fromEntries(new FormData(form));   // { email: "...", age: "..." }
  console.log("[form] sende", data);

  const button = form.querySelector("button");
  button.disabled = true;                          // Doppelklick verhindern
  try {
    await fetch("/api/signup", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(data)
    });
    form.reset();
  } catch (error) {
    console.error("[form] Fehler:", error);
  } finally {
    button.disabled = false;
  }
});

Nützliche Eigenschaften

AusdruckBedeutung
input.valueAktueller Inhalt (immer ein String)
input.valueAsNumberBei Zahlenfeldern direkt als Zahl
checkbox.checkedAngehakt?
input.validity.validErfüllt das Feld alle Regeln?
input.validity.valueMissing / typeMismatch / tooShortWarum ungültig?
input.setCustomValidity("Text")Eigene Regel: Feld als ungültig markieren ("" = gültig)
form.checkValidity()Ganzes Formular prüfen
new FormData(form)Alle Felder mit name einsammeln
form.reset()Alles zurücksetzen

Ungültige Felder mit CSS markieren

/* :user-invalid greift erst, nachdem der Nutzer das Feld bearbeitet hat */
input:user-invalid {
  border-color: #ff5f5f;
}

Tipps & typische Fehler

  • Prüfung im Browser ist Komfort, keine Sicherheit – der Server muss alles noch einmal prüfen.
  • Fehlermeldung neben das Feld schreiben und mit aria-live versehen, damit Screenreader sie vorlesen.
  • Absende-Button während des Sendens deaktivieren.
