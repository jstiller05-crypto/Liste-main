Vite & Build-Tools

Ein modernes Frontend-Projekt aufsetzen: Dev-Server mit Live-Neuladen und fertiger Build zum Veröffentlichen.

Warum ein Build-Tool?

  • Dev-Server mit sofortigem Neuladen beim Speichern
  • npm-Pakete per import im Browser nutzen
  • TypeScript, Sass oder Frameworks (React, Vue, Svelte) ohne Extra-Aufwand
  • Beim Build: Dateien verkleinern und zusammenfassen – schnellere Webseite

Projekt anlegen

npm create vite@latest mein-projekt    # Vorlage wählen: Vanilla / TypeScript / React …
cd mein-projekt
npm install
npm run dev          # Dev-Server, z. B. http://localhost:5173
npm run build        # fertige Dateien im Ordner dist/
npm run preview      # den Build lokal testen

Die Befehle sind auf Windows und Linux gleich.

Aufbau

mein-projekt/
├── index.html          ← Einstieg (lädt src/main.js als Modul)
├── package.json
├── public/             ← Dateien, die 1:1 kopiert werden (Favicon …)
└── src/
    ├── main.js
    └── style.css
// src/main.js
import "./style.css";                 // CSS direkt importieren
import confetti from "canvas-confetti";   // npm-Paket (vorher: npm install canvas-confetti)

document.querySelector("#app").textContent = "Hallo Vite";
confetti();

Veröffentlichen

Der Ordner dist/ enthält normale HTML-, CSS- und JS-Dateien. Die lassen sich auf jedem Webspace hochladen oder kostenlos über GitHub Pages, Netlify oder Vercel veröffentlichen.

Tipps & typische Fehler

  • node_modules und dist gehören in die .gitignore.
  • Für kleine Seiten wie einen Spickzettel ist kein Build-Tool nötig – es lohnt sich, sobald npm-Pakete oder TypeScript dazukommen.
