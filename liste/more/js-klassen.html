Klassen

class, constructor, Vererbung mit extends, Getter/Setter und private Felder.

Grundform

class Player {
  #score = 0;                       // privates Feld (# = von außen unsichtbar)
  static count = 0;                 // gehört zur Klasse, nicht zum Objekt

  constructor(name, level = 1) {    // wird bei "new" ausgeführt
    this.name = name;               // öffentliche Eigenschaft
    this.level = level;
    Player.count++;
    console.log(`[Player] ${name} erstellt`);
  }

  addScore(points) {                // Methode
    if (points < 0) throw new Error("Punkte dürfen nicht negativ sein");
    this.#score += points;
  }

  get score() {                     // Getter: Zugriff wie auf eine Eigenschaft
    return this.#score;
  }

  toString() {
    return `${this.name} (${this.#score} Punkte)`;
  }
}

const p = new Player("Max");
p.addScore(50);
console.log(p.score);          // 50  – ohne () wegen get
console.log(String(p));        // "Max (50 Punkte)"
console.log(Player.count);     // 1
// p.#score                    // SyntaxError – privat

Vererbung

class Admin extends Player {
  constructor(name) {
    super(name, 99);               // Konstruktor der Elternklasse aufrufen – Pflicht vor "this"
    this.permissions = ["delete"];
  }

  toString() {
    return "[Admin] " + super.toString();   // Methode der Elternklasse
  }
}

const admin = new Admin("Anna");
console.log(admin instanceof Player);   // true

Tipps & typische Fehler

  • Klassennamen beginnen mit Großbuchstaben: Player, ShoppingCart.
  • Methoden als Event-Handler übergeben verliert this – dann eine Pfeilfunktion verwenden: button.addEventListener("click", () => this.save()).
  • Für reine Datenpakete reicht oft ein normales Objekt { name, score } – Klassen lohnen sich, wenn Verhalten dazukommt.
