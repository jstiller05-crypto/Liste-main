std::cout

Was ist das?

std::cout gibt Daten auf der Standardausgabe aus, normalerweise im Konsolenfenster.

Syntax

std::cout << "Text" << variable << std::endl;

Der `<<`-Operator (Insert-Operator) schreibt Daten in den Output-Stream.

Beispiel

#include <iostream>
using namespace std;

int main() {
    int alter = 25;
    cout << "Ich bin " << alter << " Jahre alt." << endl;
    cout << "Das ist eine neue Zeile." << endl;
    return 0;
}

Ausgabe:

Ich bin 25 Jahre alt.
Das ist eine neue Zeile.

Wann nutzt man es?

Um Ergebnisse, Meldungen oder Debug-Informationen auf dem Bildschirm anzuzeigen.

Wichtige Hinweise

  • std::endl erzeugt einen Zeilenumbruch und leert den Buffer
  • "\n" ist schneller als `endl` (nur Umbruch, kein Flush)
  • Man kann mehrere Werte mit `<<` hintereinander ausgeben
