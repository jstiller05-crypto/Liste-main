HTML · Text

<data>

Verknüpft einen lesbaren Text mit einem maschinenlesbaren Wert.

Was ist das?

Menschen lesen „19,99 €“, ein Programm braucht aber 19.99. <data> zeigt den Text an und speichert den Wert zusätzlich im Attribut value – z. B. für Skripte oder Suchmaschinen.

Beispiel

<p>Preis: <data value="19.99">19,99 €</data></p>
<p>Produkt: <data value="4006381333931">Bleistift HB</data></p>

Mit JavaScript liest du den Wert so aus: element.value.

Tipps & typische Fehler

  • Für Datum und Uhrzeit gibt es das spezialisierte Element <time datetime="…">.
