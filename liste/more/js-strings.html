Beispiel: Suche ohne Groß-/Kleinschreibung

function matches(text, search) {
  return text.toLowerCase().includes(search.trim().toLowerCase());
}

matches("Tabelle mit Zeilen", "  TABELLE ");   // true

Tipps & typische Fehler

  • Strings sind unveränderlich: text.toUpperCase() ändert text nicht, sondern gibt einen neuen String zurück.
  • Im Template-String kommt in ${ } beliebiger JavaScript-Code: Rechnungen, Funktionsaufrufe, Ternär-Operator.
  • Zeichen einzeln: text[0] oder for (const char of text).
