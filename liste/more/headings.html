<h1> – <h6>

Überschriften in sechs Ebenen – von der wichtigsten (<h1>) bis zur kleinsten (<h6>).

Was ist das?

Überschriften gliedern eine Seite wie ein Inhaltsverzeichnis. Die Zahl steht für die Ebene, nicht für die Schriftgröße: <h1> ist der Titel der Seite, <h2> ein Kapitel, <h3> ein Unterkapitel usw.

Beispiel

<h1>Kochbuch</h1>
  <h2>Vorspeisen</h2>
    <h3>Suppen</h3>
    <h3>Salate</h3>
  <h2>Hauptgerichte</h2>
    <h3>Nudeln</h3>

h1 – Kochbuch

h2 – Vorspeisen

h3 – Suppen

h4 – Tomatensuppe

h5 – Zutaten
h6 – Hinweis

Die Einrückung im Code dient nur der Übersicht – der Browser ignoriert sie.

Größe mit CSS anpassen

h1 { font-size: 2rem; }
h2 { font-size: 1.5rem; }

/* h2 soll kleiner aussehen, bleibt aber ein h2 */
.sidebar h2 { font-size: 1rem; }

Tipps & typische Fehler

  • Pro Seite genau eine <h1>.
  • Keine Ebene überspringen: nach <h2> kommt <h3>, nicht <h5>.
  • Überschrift nicht wegen der Größe wählen – die Größe regelt CSS.
  • Screenreader-Nutzer springen oft von Überschrift zu Überschrift. Eine saubere Gliederung hilft ihnen enorm.
