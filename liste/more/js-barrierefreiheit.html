Barrierefreiheit mit JavaScript

Eigene Menüs, Dialoge und Buttons so bauen, dass sie mit Tastatur und Screenreader funktionieren.

Grundregel: echte HTML-Elemente verwenden

Statt …besser …weil
<div onclick><button>Tastatur (Tab, Enter, Leertaste) und Screenreader funktionieren automatisch
<span onclick> als Link<a href>Kann in neuem Tab geöffnet und angesprungen werden
eigenes Popup aus <div><dialog>Fokus, Esc und Hintergrund-Sperre sind eingebaut
eigenes Aufklapp-Element<details>Ohne JavaScript bedienbar

Aufklappmenü mit ARIA

<button id="menuButton" aria-expanded="false" aria-controls="menu">Menü</button>
<ul id="menu" hidden>
  <li><a href="#">Start</a></li>
  <li><a href="#">Kontakt</a></li>
</ul>
const button = document.getElementById("menuButton");
const menu = document.getElementById("menu");

button.addEventListener("click", () => {
  const open = button.getAttribute("aria-expanded") === "true";
  button.setAttribute("aria-expanded", String(!open));   // Screenreader: "ausgeklappt"
  menu.hidden = open;
  if (!open) menu.querySelector("a").focus();            // Fokus ins Menü
});

document.addEventListener("keydown", (event) => {
  if (event.key === "Escape" && !menu.hidden) {
    menu.hidden = true;
    button.setAttribute("aria-expanded", "false");
    button.focus();                                      // Fokus zurück zum Auslöser
  }
});

Wichtige ARIA-Attribute

AttributBedeutung
aria-label="Schließen"Name für Elemente ohne sichtbaren Text (z. B. Icon-Button)
aria-expandedIst das gesteuerte Element aufgeklappt?
aria-controls="id"Welches Element wird gesteuert?
aria-live="polite"Änderungen in diesem Bereich vorlesen (Fehlermeldungen, Suchergebnisse)
aria-hidden="true"Vor Screenreadern verstecken (z. B. Deko-Icons)
aria-pressedZustand eines Umschalt-Buttons (z. B. Filter aktiv)

Fokus

element.focus();                               // Fokus setzen
document.activeElement;                        // aktuell fokussiertes Element
element.setAttribute("tabindex", "-1");        // per JS fokussierbar, aber nicht per Tab
/* Fokus sichtbar lassen – nur für Tastatur */
:focus-visible { outline: 2px solid #4f8cff; outline-offset: 2px; }

Tipps & typische Fehler

  • Test: Seite einmal nur mit Tab, Shift+Tab, Enter und Esc bedienen.
  • Erste ARIA-Regel: Keine ARIA ist besser als falsche ARIA – zuerst passende HTML-Elemente nutzen.
  • Barrierefreiheit ist für viele öffentliche und geschäftliche Webseiten inzwischen auch gesetzlich gefordert (Barrierefreiheitsstärkungsgesetz).
