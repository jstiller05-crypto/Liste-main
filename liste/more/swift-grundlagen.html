let, var & Datentypen

Konstanten und Variablen, Typen, Strings und Operatoren.

let & var

let maxLevel = 10          // Konstante – nicht änderbar (bevorzugen!)
var score = 0             // Variable – änderbar
score += 10

let price: Double = 9.99  // Typ ausdrücklich angeben
var name: String = "Max"

Wie const/let in JavaScript: Standardmäßig let, nur wenn sich der Wert ändert var.

Strings

let greeting = "Hallo " + name              // verbinden

name.count                 // 3
name.uppercased()          // "MAX"
name.contains("a")         // true
name.isEmpty               // false
"a,b,c".split(separator: ",")               // ["a", "b", "c"]

Operatoren & Umwandlung

let a = 7, b = 2
a / b            // 3   (Int / Int)
Double(a) / Double(b)   // 3.5
a % b            // 1

let number = Int("42")      // Int? – kann nil sein, wenn der Text keine Zahl ist
let text = String(42)

let label = score >= 60 ? "bestanden" : "nicht bestanden"

Swift wandelt Typen nie automatisch um: Int + Double ist ein Fehler, man muss ausdrücklich Double(x) schreiben.

Tipps & typische Fehler

  • let wo möglich – Xcode schlägt es sogar selbst vor.
  • Es gibt kein i++ – stattdessen i += 1.
