Iteratoren & Generatoren

Wie for…of unter der Haube funktioniert – und Funktionen, die Werte nach und nach liefern.

Generator-Funktion

function* countTo(max) {          // * = Generator
  for (let i = 1; i <= max; i++) {
    yield i;                          // Wert liefern und pausieren
  }
}

for (const n of countTo(3)) {
  console.log(n);                     // 1, 2, 3
}

const gen = countTo(2);
gen.next();   // { value: 1, done: false }
gen.next();   // { value: 2, done: false }
gen.next();   // { value: undefined, done: true }

Endlose Folgen

function* idGenerator() {
  let id = 1;
  while (true) yield id++;            // läuft nie "zu Ende" – nur so weit, wie abgefragt wird
}

const ids = idGenerator();
ids.next().value;   // 1
ids.next().value;   // 2

Eigene Objekte durchlaufbar machen

class TaskList {
  #tasks = [];
  add(task) { this.#tasks.push(task); }

  *[Symbol.iterator]() {              // macht die Klasse "for…of"-fähig
    yield* this.#tasks;               // yield* gibt alle Werte eines anderen Iterierbaren weiter
  }
}

const list = new TaskList();
list.add("HTML"); list.add("CSS");
for (const task of list) console.log(task);
console.log([...list]);               // ["HTML", "CSS"]

Tipps & typische Fehler

  • Alles, was for…of versteht (Arrays, Strings, Map, Set, NodeList), ist ein Iterable.
  • Generatoren sind praktisch für große oder unendliche Datenmengen, die man Stück für Stück verarbeitet.
