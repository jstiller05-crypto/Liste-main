Funktionen

Was ist das?

Eine Funktion ist ein wiederverwendbarer Codeblock, der eine spezifische Aufgabe erfüllt. Sie kann Parameter annehmen und einen Wert zurückgeben.

Syntax

Rückgabewert funktionName (Paramter1, Parameter2) {
    // Funktionscode
    return rückgabewert;
}

Beispiel

#include <iostream>
using namespace std;

// Funktions-Deklaration (Prototyp)
int addieren(int a, int b);

// Funktions-Definition
int addieren(int a, int b) {
    int ergebnis = a + b;
    return ergebnis;
}

// Funktion ohne Rückgabewert
void grueßen(string name) {
    cout << "Hallo " << name << "!" << endl;
}

int main() {
    int sum = addieren(5, 3);
    cout << "5 + 3 = " << sum << endl;
    
    grueßen("Anna");
    
    return 0;
}

Wichtige Konzepte

  • Rückgabewert: `void` wenn nichts zurückgegeben wird, sonst Datentyp angeben
  • Parameter: Eingabewerte (können mehrere sein oder keine)
  • Prototyp: Funktionssignatur vor der main() - gute Praxis
  • Gültigkeitsbereich: Parameter sind nur innerhalb der Funktion bekannt

Wann nutzt man Funktionen?

  • Wiederverwendung von Code
  • Strukturierung und Übersichtlichkeit
  • Tests und Debugging vereinfachen

Wichtige Hinweise

  • Mit `return` wird die Funktion beendet
  • Parameter werden by value übergeben (Kopie)
  • Mit Referenzen (`&`) oder Zeigern (`*`) kann by reference übergeben werden
