HTML · Formulare

<form>

Ein Formular sammelt Eingaben (Textfelder, Auswahlen, Checkboxen) und schickt sie ab.

Was ist das?

<form> ist der Rahmen um zusammengehörige Eingabefelder. Beim Abschicken werden alle Felder mit einem name an die Adresse in action gesendet – oder du fängst das Abschicken mit JavaScript ab und verarbeitest die Daten selbst.

Syntax

<form action="ziel" method="post">
  <!-- Eingabefelder -->
  <button type="submit">Absenden</button>
</form>

Beispiel: Kontaktformular

<form id="contactForm">
  <label for="name">Name</label>
  <input type="text" id="name" name="name" required>

  <label for="email">E-Mail</label>
  <input type="email" id="email" name="email" required>

  <label for="topic">Thema</label>
  <select id="topic" name="topic">
    <option value="frage">Frage</option>
    <option value="feedback">Feedback</option>
  </select>

  <label for="message">Nachricht</label>
  <textarea id="message" name="message" rows="4"></textarea>

  <label>
    <input type="checkbox" name="newsletter"> Newsletter abonnieren
  </label>

  <button type="submit">Senden</button>
</form>

Wichtige Attribute

AttributBedeutung
actionAdresse, an die die Daten geschickt werden
methodget (Daten in der URL) oder post (Daten unsichtbar im Hintergrund)
novalidateSchaltet die eingebaute Browser-Prüfung ab
autocompleteon/off – Browser-Vorschläge erlauben oder nicht

Formular mit JavaScript verarbeiten

const form = document.getElementById("contactForm");

form.addEventListener("submit", (event) => {
  event.preventDefault();               // Seite NICHT neu laden

  const data = new FormData(form);      // alle Felder mit name einsammeln
  console.log("Name:", data.get("name"));
  console.log("E-Mail:", data.get("email"));
});

event.preventDefault() verhindert das normale Abschicken. Ohne diese Zeile lädt die Seite neu und deine JavaScript-Ausgaben sind weg.

Tipps & typische Fehler

  • Jedes Feld braucht ein name-Attribut, sonst wird es nicht mitgeschickt.
  • Jedes Feld braucht ein <label> – für Übersicht und Barrierefreiheit.
  • Formulare dürfen nicht ineinander verschachtelt werden.
  • Browser-Prüfungen wie required oder type="email" ersetzen keine Prüfung auf dem Server.
