HTML · Formulare & Interaktion

<button>

Eine klickbare Schaltfläche – zum Absenden von Formularen oder für eigene JavaScript-Aktionen.

Was ist das?

<button> ist das Element für Aktionen: Formular absenden, Menü öffnen, Filter setzen, Text kopieren. Anders als <input type="button"> darf ein <button> auch HTML enthalten, z. B. ein Icon.

Syntax

<button type="button">Klick mich</button>

Die drei Typen

typeWas passiert beim Klick?
submitSchickt das Formular ab. Standard innerhalb eines <form>!
buttonNichts – du bestimmst per JavaScript, was passiert
resetSetzt alle Felder des Formulars zurück

Beispiel mit JavaScript

<button type="button" id="counterBtn">0 Klicks</button>

<script>
  const button = document.getElementById("counterBtn");
  let clicks = 0;

  button.addEventListener("click", () => {
    clicks++;                                    // +1
    button.textContent = clicks + " Klicks";
    console.log("Button geklickt:", clicks);
  });
</script>

Wichtige Attribute

AttributBedeutung
typesubmit, button oder reset
disabledButton ist ausgegraut und nicht klickbar
name / valueWerden beim Absenden mitgeschickt
data-…Eigene Daten, z. B. data-language="html" – in JS über button.dataset.language

Button gestalten (CSS)

Browser geben Buttons ein eigenes Aussehen. So setzt du es zurück und gestaltest den Button selbst, hier als runder „Chip“:

.button {
  all: unset;              /* Browser-Styles entfernen */
  cursor: pointer;         /* Hand-Cursor wieder anzeigen */
  padding: 6px 14px;
  border: 1px solid #4a4a4a;
  border-radius: 999px;    /* Pillenform */
}

.button:hover         { background: #474747; }
.button:focus-visible { outline: 2px solid #4f8cff; }   /* Tastatur-Fokus sichtbar lassen! */

Tipps & typische Fehler

  • Häufigster Fehler: Ein <button> ohne type im Formular schickt es ab und lädt die Seite neu. Für JS-Buttons immer type="button" schreiben.
  • Nur zu einer anderen Seite springen? Dann ist <a> richtig, nicht <button>.
  • Buttons sind automatisch per Tastatur (Tab + Enter) bedienbar – ein <div> mit Klick-Event nicht.
