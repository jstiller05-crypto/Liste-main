Klassen

Was ist das?

Eine Klasse ist eine Vorlage (Template) zur Erstellung von Objekten. Sie definiert Eigenschaften (Attribute) und Funktionen (Methoden).

Syntax

class Klassenname {
public:
    // Öffentliche Eigenschaften und Methoden
    Datentyp attribut;
    void methode();
    
private:
    // Private Eigenschaften und Methoden
    int privateAttribute;
};

Beispiel

#include <iostream>
#include <string>
using namespace std;

class Auto {
public:
    string hersteller;
    int baujahr;
    
    // Konstruktor
    Auto(string h, int b) {
        hersteller = h;
        baujahr = b;
    }
    
    // Methode
    void info() {
        cout << hersteller << " aus " << baujahr << endl;
    }
};

int main() {
    Auto meinAuto("Mercedes", 2020);
    meinAuto.info();    // Mercedes aus 2020
    
    Auto *autoZeiger = new Auto("BMW", 2022);
    autoZeiger->info();  // BMW aus 2022
    delete autoZeiger;
    
    return 0;
}

Wichtige Konzepte

  • Konstruktor: Spezielle Methode, wird beim Erstellen aufgerufen
  • public: Kann von außen zugegriffen werden
  • private: Nur innerhalb der Klasse zugänglich
  • Attribut: Eigenschaft eines Objekts
  • Methode: Funktion innerhalb einer Klasse

Objekt erstellen

// Auf dem Stack
Auto meinAuto("Tesla", 2023);

// Auf dem Heap
Auto *autoPtr = new Auto("Audi", 2021);
delete autoPtr;  // Speicher freigeben

Wichtige Hinweise

  • Destruktor (~Klassenname) wird aufgerufen wenn Objekt gelöscht wird
  • Vererbung: `class Sportwagen : public Auto { ... };`
  • Zugriff auf Methoden: `.` für Stack-Objekte, `->` für Zeiger
