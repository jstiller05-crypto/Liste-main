DOM – HTML mit JavaScript ändern

Elemente finden, Inhalte und Klassen ändern, neue Elemente erzeugen und entfernen.

Was ist das DOM?

Beim Laden baut der Browser aus dem HTML einen Baum aus Objekten – das Document Object Model. Über document greifst du mit JavaScript darauf zu. Änderungen am DOM siehst du sofort auf der Seite.

Elemente finden

BefehlLiefert
document.getElementById("id")Ein Element (oder null)
document.querySelector(".klasse")Das erste passende Element – beliebiger CSS-Selektor
document.querySelectorAll("li")Alle passenden Elemente (NodeList, mit forEach)
element.closest(".card")Nächstes passendes Eltern-Element
element.children / .parentElementKinder / Eltern

Inhalt & Aussehen ändern

const title = document.querySelector("h1");

title.textContent = "Neuer Titel";          // nur Text (sicher)
title.innerHTML = "Neu <em>fett</em>";      // HTML – nur mit eigenen, vertrauenswürdigen Daten!

title.classList.add("active");              // Klasse hinzufügen
title.classList.remove("active");
title.classList.toggle("active");           // an/aus
title.classList.contains("active");         // true/false

title.style.color = "#4f8cff";              // Inline-Style (Bindestrich → camelCase: backgroundColor)

const input = document.querySelector("input");
input.value;                                // Inhalt eines Feldes
input.disabled = true;

Attribute & data-*

link.getAttribute("href");
link.setAttribute("href", "neu.html");
img.src = "bild.png";                       // viele Attribute gehen auch direkt

// <button data-language="html">
button.dataset.language;                    // "html"

Elemente erzeugen & entfernen

const list = document.querySelector("ul");

const item = document.createElement("li");  // 1) erzeugen (noch unsichtbar)
item.textContent = "Neuer Eintrag";         // 2) füllen
item.classList.add("entry");
list.appendChild(item);                     // 3) einhängen → sichtbar

list.prepend(item);                         // am Anfang einfügen
item.remove();                              // entfernen
list.innerHTML = "";                        // alle Kinder löschen

Wann ist das HTML da?

// Skript im <head>? Dann warten, bis das HTML geladen ist:
document.addEventListener("DOMContentLoaded", () => {
  console.log("DOM bereit");
});

// oder einfach: <script defer src="app.js"></script>

Tipps & typische Fehler

  • null-Fehler („Cannot read properties of null“) heißt fast immer: Element nicht gefunden – Selektor prüfen oder Skript läuft zu früh.
  • textContent statt innerHTML für Nutzereingaben – sonst kann fremder Code eingeschleust werden.
  • Styling lieber über Klassen (classList) als über element.style – das CSS bleibt an einem Ort.
