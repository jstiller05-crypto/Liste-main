for-Schleife

Was ist das?

Eine for-Schleife wiederholt einen Codeblock eine bekannte Anzahl von Malen.

Syntax

for (Initialisierung; Bedingung; Erhöhung) {
    // Code wird wiederholt
}

Initialisierung: Counter-Variable setzen
Bedingung: Solange diese wahr ist, wird die Schleife wiederholt
Erhöhung: Wird nach jedem Durchlauf ausgeführt

Beispiel

#include <iostream>
using namespace std;

int main() {
    // Zaehle von 1 bis 5
    for (int i = 1; i <= 5; i++) {
        cout << "Durchlauf " << i << endl;
    }
    
    // Zaehle rückwärts
    for (int i = 5; i >= 1; i--) {
        cout << i << " ";
    }
    cout << endl;
    
    return 0;
}

Ausgabe der ersten Schleife:

Durchlauf 1
Durchlauf 2
Durchlauf 3
Durchlauf 4
Durchlauf 5

Wichtige Hinweise

  • `i++` erhöht i um 1, `i--` reduziert um 1
  • `i += 2` erhöht um 2, allgemein: `i += n`
  • Mit `break` kann die Schleife unterbrochen werden
  • Mit `continue` wird der aktuelle Durchlauf übersprungen
