Testen mit Vitest

Funktionen automatisch prüfen lassen – damit Änderungen nichts Bestehendes kaputt machen.

Warum Tests?

Ein Test ruft eine Funktion mit bekannten Eingaben auf und prüft, ob das erwartete Ergebnis herauskommt. Nach jeder Änderung laufen alle Tests in Sekunden durch – so merkst du sofort, wenn etwas kaputtgeht.

Einrichten

npm install --save-dev vitest
// package.json
"scripts": {
  "test": "vitest"
}

Erster Test

// src/math.js
export function average(values) {
  if (values.length === 0) return 0;
  return values.reduce((sum, v) => sum + v, 0) / values.length;
}
// src/math.test.js
import { describe, it, expect } from "vitest";
import { average } from "./math.js";

describe("average", () => {
  it("berechnet den Durchschnitt", () => {
    expect(average([2, 4, 6])).toBe(4);
  });

  it("gibt 0 bei leerer Liste zurück", () => {
    expect(average([])).toBe(0);
  });

  it("funktioniert mit Kommazahlen", () => {
    expect(average([0.1, 0.2])).toBeCloseTo(0.15);
  });
});
npm test        # startet Vitest und wiederholt die Tests bei jeder Änderung

Wichtige Prüfungen

PrüfungBedeutung

expect(obj).toEqual({ a: 1 })Inhalt gleich (für Objekte/Arrays)
expect(x).toBeCloseTo(0.3)Kommazahl ungefähr gleich
expect(list).toContain("html")Enthalten
expect(x).toBeTruthy() / .toBeNull()Wahr / null
expect(() => fn()).toThrow()Wirft einen Fehler

Tipps & typische Fehler

  • Gut testbar sind Funktionen ohne DOM-Zugriff: Filter, Sortieren, Berechnungen. Deshalb Logik und Anzeige trennen.
  • Ein Projekt mit Tests auf GitHub zeigt Arbeitgebern, dass du sauber arbeitest.
  • Jest funktioniert fast identisch – die Befehle describe, it, expect sind gleich.
