Datentypen: int, float, string, bool

Was ist das?

Datentypen definieren, welche Art von Daten eine Variable speichern kann.

Syntax

int ganzeZahl;              // Ganze Zahl: -2147483648 bis 2147483647
float dezimalzahl;          // Dezimalzahl: ca. 6-7 Dezimalstellen
double dezimalzahl2;        // Dezimalzahl: ca. 15 Dezimalstellen
string text;                // Text/String
bool bedingung;             // Wahrheitswert: true oder false
char zeichen;               // Ein einzelnes Zeichen

Beispiel

#include <iostream>
#include <string>
using namespace std;

int main() {
    int alter = 25;
    float gewicht = 75.5;
    string name = "Max";
    bool istStuedent = true;
    
    cout << name << " ist " << alter << " Jahre alt." << endl;
    cout << "Gewicht: " << gewicht << " kg" << endl;
    
    return 0;
}

Übersicht der wichtigsten Typen

  • int: Ganze Zahlen (-2.1 Mrd bis +2.1 Mrd)
  • float: Dezimalzahlen (Speicher: 4 Bytes)
  • double: Dezimalzahlen mit höherer Genauigkeit (8 Bytes)
  • string: Textketten (benötigt `#include <string>`)
  • bool: true oder false
  • char: Ein Zeichen ('A', 'x', '5')

Wichtige Hinweise

  • C++ ist eine typsichere Sprache – Typen können später nicht geändert werden
  • Typkonvertierung: `int x = (int)3.7;` ergibt 3
  • String benötigt Header `#include <string>`
