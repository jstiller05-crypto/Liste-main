HTML · Struktur

<nav>

Enthält die wichtigsten Navigationslinks einer Seite.

Was ist das?

<nav> fasst Links zusammen, mit denen man sich auf der Website bewegt: Hauptmenü, Inhaltsverzeichnis, Seitenzahlen.

Beispiel

<nav>
  <ul>
    <li><a href="index.html">Start</a></li>
    <li><a href="projekte.html">Projekte</a></li>
    <li><a href="kontakt.html">Kontakt</a></li>
  </ul>
</nav>

Links als Liste zu schreiben ist üblich: Screenreader sagen dann „Liste mit 3 Einträgen“ an.

Menü nebeneinander (CSS)

nav ul {
  display: flex;      /* Einträge nebeneinander */
  gap: 16px;
  list-style: none;   /* Punkte entfernen */
  padding: 0;
}

Tipps & typische Fehler

  • Nicht jede Linkgruppe braucht <nav> – nur die wichtigen Navigationsbereiche.
  • Gibt es mehrere <nav>, mit aria-label unterscheiden, z. B. aria-label="Hauptmenü".
