ID

Man kann eine ID in verschidene sprachen definieren

!WICHTIG!
damit du ein ID in verschidenen Programsprachen hast musst du sie im "head" verbinden.

zb.

html:
<element ID="exsample">

CSS:
#exsample {
--exsample
}

Mit JS ist das ganze etwas komplexer.

Die Identietät dient dazu das ausgewählte Element anzupassen
