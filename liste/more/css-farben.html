Farben & Hintergründe

Textfarbe, Hintergrundfarbe, Verläufe, Hintergrundbilder und Transparenz.

Die wichtigsten Eigenschaften

EigenschaftWirkung
colorTextfarbe
background-colorHintergrundfarbe
background-imageHintergrundbild oder Farbverlauf
background Kurzform für alle background-Eigenschaften
opacityDurchsichtigkeit des ganzen Elements (0 bis 1)

Farben angeben

color: red;                       /* Farbname */
color: #4f8cff;                   /* Hex: #RRGGBB */
color: #4f8cff80;                 /* Hex mit Transparenz (80 = ca. 50 %) */
color: rgb(79, 140, 255);         /* Rot, Grün, Blau: 0–255 */
color: rgb(79 140 255 / 50%);     /* mit Transparenz */
color: hsl(220, 100%, 65%);       /* Farbton 0–360, Sättigung, Helligkeit */
FormatGut für
Name (red)Schnelle Tests
Hex (#4f8cff)Am verbreitetsten, Farbwähler liefern meist Hex
rgb()Wenn Transparenz dazukommt
hsl()Farben leicht heller/dunkler machen: nur den letzten Wert ändern

Farbverläufe

/* linear: von oben nach unten */
background: linear-gradient(#4f8cff, #222);

/* mit Richtung und mehreren Farben */
background: linear-gradient(to right, #4f8cff, #9b59ff, #ff5f8c);

/* kreisförmig */
background: radial-gradient(circle, #4f8cff, #222);

Hintergrundbilder

.hero {
  background-image: url("bilder/berg.jpg");
  background-size: cover;       /* Fläche ganz füllen (schneidet evtl. ab) */
  background-position: center;  /* Bildmitte zeigen */
  background-repeat: no-repeat; /* nicht kacheln */
}
background-sizeWirkung
coverFüllt die Fläche komplett, Teile werden evtl. abgeschnitten
containGanzes Bild sichtbar, evtl. leere Ränder
100px autoFeste Breite, Höhe passend

opacity oder transparente Farbe?

.box1 { opacity: 0.5; }                     /* ganzes Element inkl. Text halb durchsichtig */
.box2 { background: rgb(0 0 0 / 50%); }     /* nur der Hintergrund durchsichtig, Text bleibt klar */

Tipps & typische Fehler

  • Auf genug Kontrast zwischen Text und Hintergrund achten – dunkelgrau auf schwarz ist schlecht lesbar.
  • Farben einmal als Variablen festlegen (--accent: #4f8cff;) und überall wiederverwenden.
  • Pfade in url() gehen von der CSS-Datei aus, nicht von der HTML-Datei.
