Listen (<ul>, <ol>, <li>)

Aufzählungen mit Punkten oder Nummern.

Was ist das?

HTML kennt drei Listenarten:

  • <ul> – unordered list: Aufzählung mit Punkten, Reihenfolge egal.
  • <ol> – ordered list: nummerierte Liste, Reihenfolge wichtig (z. B. Anleitung).
  • <dl> – Definitionsliste: Begriff und Beschreibung (eigene Seite).

Jeder Eintrag in <ul> und <ol> steht in einem <li> (list item).

Beispiele

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Datei speichern</li>
  <li>Browser öffnen</li>
  <li>Seite neu laden (F5)</li>
</ol>
  • HTML
  • CSS
  • JavaScript
  1. Datei speichern
  2. Browser öffnen
  3. Seite neu laden (F5)

Verschachtelte Liste

<ul>
  <li>Frontend
    <ul>                 <!-- neue Liste INNERHALB des li -->
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>

Wichtige Attribute

AttributBedeutung
start<ol start="5"> beginnt bei 5
reversed<ol reversed> zählt rückwärts
type<ol type="a"> nummeriert mit a, b, c (auch A, i, I)

Listen mit CSS gestalten

ul {
  list-style: none;   /* Punkte entfernen – z. B. für Menüs */
  padding-left: 0;    /* Standard-Einrückung entfernen */
}

ol {
  list-style-type: upper-roman;   /* I, II, III … */
}

Tipps & typische Fehler

  • Direkt in <ul>/<ol> dürfen nur <li> stehen – kein Text, kein <div>.
  • Menüs und Navigationen werden fast immer als <ul> gebaut.

Verwandte Seiten
