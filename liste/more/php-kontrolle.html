Bedingungen & Schleifen

if, switch, match und Schleifen in PHP.

if / elseif / else

<?php
$points = 72;

if ($points >= 90) {
    echo "Sehr gut";
} elseif ($points >= 60) {     // elseif in einem Wort
    echo "Bestanden";
} else {
    echo "Nicht bestanden";
}

$label = $points >= 60 ? "bestanden" : "nicht bestanden";   // Ternär

match (PHP 8) & switch

$grade = match (true) {
    $points >= 90 => "sehr gut",
    $points >= 60 => "bestanden",
    default       => "nicht bestanden",
};

$day = "Sa";
switch ($day) {
    case "Sa":
    case "So":
        echo "Wochenende";
        break;
    default:
        echo "Werktag";
}

match vergleicht streng (===), liefert einen Wert und braucht kein break – meist die bessere Wahl.

Schleifen

for ($i = 1; $i <= 5; $i++) {
    echo $i;
}

$tries = 0;
while ($tries < 3) {
    $tries++;
}

$languages = ["HTML", "CSS", "PHP"];
foreach ($languages as $language) {                 // nur Werte
    echo "<li>$language</li>";
}

$user = ["name" => "Max", "age" => 17];
foreach ($user as $key => $value) {                 // Schlüssel und Wert
    echo "$key: $value<br>";
}

Alternative Syntax in HTML-Vorlagen

<ul>
<?php foreach ($languages as $language): ?>
    <li><?= htmlspecialchars($language) ?></li>
<?php endforeach; ?>
</ul>

<?php if ($isLoggedIn): ?>
    <p>Willkommen zurück!</p>
<?php else: ?>
    <a href="login.php">Anmelden</a>
<?php endif; ?>

Mit : und endforeach/endif bleiben Vorlagen mit viel HTML gut lesbar.

Tipps & typische Fehler

  • break beendet eine Schleife, continue springt zum nächsten Durchlauf – wie in JS und C++.
  • foreach ist in PHP die häufigste Schleife.
