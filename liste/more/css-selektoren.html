CSS-Selektoren

Selektoren bestimmen, welche Elemente eine CSS-Regel trifft.

Was ist das?

Jede CSS-Regel beginnt mit einem Selektor. Danach folgen in { } die Eigenschaften, die für die getroffenen Elemente gelten.

selektor {
  eigenschaft: wert;
}

Grund-Selektoren

* { box-sizing: border-box; }      /* Universal: alles */
p { line-height: 1.6; }            /* Typ: alle <p> */
.card { padding: 16px; }           /* Klasse */
#menu { position: sticky; }        /* ID */
input[type="email"] { width: 100%; } /* Attribut */

Kombinatoren (Beziehungen)

<nav>
  <ul>
    <li><a href="#">Start</a></li>
  </ul>
</nav>
<h2>Titel</h2>
<p>Erster Absatz</p>
<p>Zweiter Absatz</p>
nav a    { color: white; }   /* Nachfahre: das <a> steckt tief in <nav> → trifft */
nav > a  { color: red; }     /* Kind: <a> ist KEIN direktes Kind von <nav> → trifft nicht */
ul > li  { list-style: none; } /* Kind: <li> ist direktes Kind von <ul> → trifft */
h2 + p   { font-weight: bold; } /* nur "Erster Absatz" */
h2 ~ p   { color: gray; }     /* beide Absätze */

Pseudoklassen (Zustände)

a:hover { color: #4f8cff; }          /* Maus darüber */
input:focus { outline: 2px solid; }  /* aktives Feld */
li:first-child { margin-top: 0; }    /* erstes Kind */
tr:nth-child(even) { background: #2b2b2b; } /* jede zweite Zeile */
button:disabled { opacity: 0.5; }

Welche Regel gewinnt? (Spezifität)

Treffen mehrere Regeln dasselbe Element, gewinnt die spezifischere:

  1. style="…" direkt am Element
  2. ID-Selektor #id
  3. Klasse .klasse, Attribut […], Pseudoklasse :hover
  4. Typ p und Universal *

Sind beide gleich stark, gewinnt die Regel, die weiter unten steht.

Tipps & typische Fehler

  • Mehrere Selektoren mit Komma trennen, um dieselben Regeln zu vergeben: h1, h2, h3 { … }.
  • Leerzeichen ist wichtig: .a .b (b in a) ist etwas anderes als .a.b (ein Element mit beiden Klassen).
  • Selektoren kurz halten – lange Ketten wie body main section div p sind schwer zu warten.
  • Dieselben Selektoren funktionieren in JavaScript: document.querySelectorAll("nav > a").
