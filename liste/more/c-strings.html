Strings in C (char-Arrays)

Texte als Zeichen-Arrays mit abschließender Null – und die Funktionen aus <string.h>.

Wie Strings in C funktionieren

Einen String-Typ gibt es in C nicht. Ein Text ist ein Array aus char, das mit dem Null-Zeichen '\0' endet.

char name[] = "Max";     /* Speicher: 'M' 'a' 'x' '\0'  → 4 Bytes */
char buffer[20];         /* Platz für 19 Zeichen + '\0' */

printf("%s hat %zu Zeichen\n", name, strlen(name));   /* strlen zählt ohne '\0' */

Funktionen aus <string.h>

FunktionWirkung
strlen(s)Länge (ohne \0)
strcpy(dest, src) / strncpyKopieren
strcat(dest, src) / strncatAnhängen
strcmp(a, b)Vergleichen: 0 = gleich, <0 / >0 = kleiner / größer
strchr(s, 'x') / strstr(s, "ab")Zeichen / Text suchen (Zeiger oder NULL)
snprintf(buf, size, …)Formatiert in einen Puffer schreiben – sicherste Methode

Sicher zusammensetzen

#include <stdio.h>
#include <string.h>

int main(void) {
    char greeting[32];
    const char *name = "Max";

    snprintf(greeting, sizeof greeting, "Hallo %s!", name);   /* schneidet notfalls ab */
    printf("%s\n", greeting);

    if (strcmp(name, "Max") == 0) {       /* NICHT name == "Max" */
        printf("Gleich!\n");
    }
    return 0;
}

Zahl ↔ Text

#include <stdlib.h>

int n = atoi("42");                  /* einfach, aber ohne Fehlerprüfung */
long value = strtol("123", NULL, 10);
double d = strtod("3.14", NULL);

char text[16];
snprintf(text, sizeof text, "%d", 42);   /* Zahl → Text */

Tipps & typische Fehler

  • Strings nie mit == vergleichen – das vergleicht Adressen. Immer strcmp.
  • Buffer Overflow: strcpy in einen zu kleinen Puffer überschreibt fremden Speicher – eine klassische Sicherheitslücke. snprintf bzw. Größenprüfung verwenden.
  • 'A' ist ein einzelnes Zeichen, "A" ein String (zwei Bytes: A und \0).
