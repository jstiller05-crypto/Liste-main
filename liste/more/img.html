<img>

Bindet ein Bild in die Seite ein.

Was ist das?

<img> ist ein leeres Element (kein End-Tag). Die Bilddatei steht in src, eine Beschreibung in alt. Unterstützte Formate: JPG, PNG, GIF, SVG, WebP, AVIF, ICO.

Syntax

<img src="bild.png" alt="Beschreibung des Bildes">

Beispiele

<!-- Bild aus einem Unterordner -->
<img src="icons/logo.png" alt="Firmenlogo" width="40" height="40">

<!-- Erst laden, wenn man hinscrollt -->
<img src="grosses-foto.jpg" alt="Sonnenuntergang am Meer" loading="lazy">

<!-- Bild als Link -->
<a href="index.html">
  <img src="icons/home.png" alt="Zur Startseite">
</a>

Wichtige Attribute

AttributBedeutung
srcPfad bzw. URL der Bilddatei (Pflicht)
altErsatztext: wird vorgelesen und angezeigt, wenn das Bild fehlt (Pflicht)
width / heightGröße in Pixeln – verhindert, dass die Seite beim Laden „springt“
loadinglazy = erst laden, wenn das Bild in Sichtweite kommt
titleTooltip beim Drüberfahren
usemapVerknüpft das Bild mit einer Image-Map (#name)

Guter alt-Text

Bildalt
Logo, das zur Startseite führtalt="Zur Startseite"
Foto mit Inhaltalt="Person am Schreibtisch mit zwei Monitoren"
Reine Dekoalt="" (leer, damit Screenreader es überspringen)

Ladefehler abfangen

<img src="logo.png" alt="Logo"
     onerror="console.warn('Bild fehlt:', this.src); this.style.display='none';">

Bilder mit CSS anpassen

img {
  max-width: 100%;     /* nie breiter als der Container */
  height: auto;        /* Seitenverhältnis bleibt erhalten */
}

.avatar {
  width: 80px;
  height: 80px;
  object-fit: cover;   /* füllt die Fläche, ohne zu verzerren */
  border-radius: 50%;  /* rund */
}

Tipps & typische Fehler

  • alt nie weglassen.
  • Große Fotos vorher verkleinern – ein 5-MB-Foto macht die Seite langsam.
  • Pfade: ../ geht einen Ordner nach oben. Leerzeichen in Dateinamen möglichst vermeiden.
  • Bild mit Bildunterschrift? Dann <figure> + <figcaption> verwenden.
