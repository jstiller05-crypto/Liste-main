HTML

Die Sprache, mit der Inhalte auf einer Webseite strukturiert werden.

Geschichte Warum HTML? Aufbau Elemente Einsatzgebiete Praxis

1. Geschichte

HTML entstand in den frühen 1990er Jahren, als Tim Berners-Lee das World Wide Web mit einem einfachen Dokumentformat begründete. Ziel war es, wissenschaftliche Dokumente im Internet einfach austauschbar und verlinkbar zu machen.

In den Anfangsjahren war HTML sehr simpel: Überschriften, Absätze, Links und kleine Formatierungen. Mit der Zeit kamen Semantik, Multimedia und interaktive Elemente hinzu. Heute ist HTML die Grundlage fast jeder Website.

Wichtig: HTML beschreibt Struktur, nicht Aussehen. Das Styling übernimmt CSS.

2. Warum gibt es HTML?

Ohne HTML gäbe es keine einheitliche Sprache, mit der Browser Inhalte verstehen und darstellen können. HTML sorgt dafür, dass ein Browser weiß, was ein Überschrift, ein Absatz, ein Link, ein Bild oder eine Tabelle ist.

Das ist wichtig, weil Webseiten nicht nur schön aussehen sollen, sondern auch verständlich, zugänglich und maschinenlesbar sein müssen. Screenreader, Suchmaschinen und Browser nutzen diese Struktur.

  • HTML macht Inhalte semantisch verständlich.
  • Es ist die Grundlage für das Web.
  • Es verbindet Inhalte mit Hyperlinks und interaktiven Elementen.

3. Aufbau eines HTML-Dokuments

Ein HTML-Dokument besteht aus mehreren wichtigen Teilen:

<!DOCTYPE html>
<html lang="de">
  <head>
    <meta charset="UTF-8">
    <title>Meine Seite</title>
  </head>
  <body>
    <h1>Hallo Welt</h1>
    <p>Das ist mein erster Text.</p>
  </body>
</html>

Wichtige Bestandteile

  • <html> ist das Wurzelelement.
  • <head> enthält Metadaten wie Titel und Zeichensatz.
  • <body> enthält den sichtbaren Inhalt.
  • <title> bestimmt den Browser-Tab-Titel.

4. Elemente und Tags

HTML arbeitet mit sogenannten Elementen. Ein Element besteht meist aus einem Start-Tag, Inhalt und einem End-Tag.

<p>Das ist ein Absatz.</p>

Einige Elemente sind selbstschließend, zum Beispiel Bild, Zeilenumbruch oder Link auf Metadaten:

<img src="bild.jpg" alt="Beschreibung"> <br>

Typische HTML-Elemente

  • <h1> bis <h6> für Überschriften
  • <p> für Absätze
  • <a> für Hyperlinks
  • <img> für Bilder
  • <table> für Tabellen
  • <form> für Formulare

5. Einsatzgebiete

HTML wird überall dort genutzt, wo Inhalte im Browser sichtbar sein sollen: Webseiten, Landingpages, Dokumentenseiten, Portfolios, E-Commerce, Blogs, Admin-Oberflächen und Webapps.

Es eignet sich besonders für:

  • Textbasierte Inhalte und Dokumentseiten
  • Navigation und Verlinkung
  • Formulare für Eingaben
  • Strukturierung von Inhalten
  • Einbettung von Medien wie Bildern, Videos und Audio

6. Praktische Bedeutung

Wenn du eine Seite baust, arbeitest du meistens mit HTML als Grundgerüst. Danach kommt CSS für Design und JavaScript für Interaktivität.

Ein gutes HTML-Dokument ist sauber, semantisch und barrierearm. Das hilft nicht nur Nutzern, sondern auch Suchmaschinen und Entwicklern.

Merksatz: HTML legt fest, was etwas ist. CSS legt fest, wie es aussieht. JavaScript legt fest, was es tun kann.
