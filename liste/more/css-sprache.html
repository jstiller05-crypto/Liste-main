CSS

Die Sprache, mit der Webseiten gestaltet und organisiert werden.

Geschichte Warum CSS? Syntax Selektoren Layout Praxis

1. Geschichte

CSS steht für Cascading Style Sheets und wurde in den späten 1990er Jahren entwickelt, um HTML-Seiten nicht nur strukturiert, sondern auch optisch ansprechend zu gestalten. Vor CSS mussten Formate direkt im HTML-Code stehen, was schnell unübersichtlich wurde.

Die Idee war, Design und Inhalt getrennt zu halten. Dadurch konnte man mehrere Seiten mit derselben Gestaltung nutzen und schneller ändern.

2. Warum gibt es CSS?

HTML legt fest, was etwas ist. CSS legt fest, wie etwas aussieht. Eine Überschrift muss nicht immer in einer Standardfarbe und Größe erscheinen. Mit CSS kannst du Farben, Abstände, Schriftarten, Spalten und Layouts kontrollieren.

Das ist besonders wichtig, weil moderne Websites oft auf verschiedenen Bildschirmgrößen funktionieren müssen. CSS hilft beim Responsive Design, also beim anpassbaren Layout für Desktop, Tablet und Mobilgeräte.

3. Syntax

CSS besteht aus Regeln, die aus Selektor und Deklarationen bestehen.

p {
  color: white;
  font-size: 16px;
  margin-top: 10px;
}
  • Selektor: Wählt das Ziel aus, z. B. alle Absätze.
  • Eigenschaft: z. B. color oder font-size.
  • Wert: z. B. white oder 16px.

4. Selektoren

Selektoren bestimmen, welche Elemente angesprochen werden. Das ist ein Grundpfeiler von CSS.

  • Typselektor: p
  • Klassenselektor: .box
  • ID-Selektor: #hauptbereich
  • Attributselektor: [type="text"]

Durch geschickte Selektoren lässt sich ein Layout sauber und wiederverwendbar strukturieren.

5. Layout und Design

CSS ist nicht nur für Farben und Schriften relevant, sondern auch für die Anordnung von Elementen. Mit Flexbox und Grid lassen sich Seiten zuverlässig aufbauen.

.nav {
  display: flex;
  justify-content: space-between;
  gap: 1rem;
}

Damit lassen sich Navigationen, Karten, Bereiche und responsive Layouts in kurzer Zeit sauber aufbauen.

6. Praktische Bedeutung

CSS ist entscheidend für das Aussehen und die Benutzerfreundlichkeit von Webauftritten. Es macht Seiten einheitlich, lesbar, modern und auf verschiedene Geräte anpassbar.

Ohne CSS wären Websites meist unstrukturiert und schwer zu nutzen. Die Sprache ist deshalb ein zentraler Bestandteil des Frontend-Designs.

Merksatz: HTML ist das Gerüst, CSS ist die Oberfläche.
