Vererbung & Polymorphie

Klassen erweitern und über eine gemeinsame Basisklasse unterschiedlich reagieren lassen.

Vererbung

class Shape {                          // Basisklasse
public:
    Shape(const std::string& name) : name(name) {}
    virtual ~Shape() = default;       // bei Vererbung immer virtuellen Destruktor!

    virtual double area() const = 0;  // rein virtuell: muss überschrieben werden
    std::string getName() const { return name; }

protected:
    std::string name;
};

class Rectangle : public Shape {      // Rectangle erbt von Shape
public:
    Rectangle(double w, double h) : Shape("Rechteck"), width(w), height(h) {}

    double area() const override {    // override: überschreibt die Basis-Methode
        return width * height;
    }

private:
    double width, height;
};

class Circle : public Shape {
public:
    Circle(double r) : Shape("Kreis"), radius(r) {}
    double area() const override { return 3.14159 * radius * radius; }
private:
    double radius;
};

Polymorphie

std::vector<std::unique_ptr<Shape>> shapes;
shapes.push_back(std::make_unique<Rectangle>(3, 4));
shapes.push_back(std::make_unique<Circle>(2));

for (const auto& shape : shapes) {
    // ruft je nach echtem Typ die richtige area() auf
    std::cout << shape->getName() << ": " << shape->area() << "\n";
}

Polymorphie („Vielgestaltigkeit“): Derselbe Aufruf shape->area() macht je nach Objekt etwas anderes. Das funktioniert nur über Zeiger oder Referenzen und nur mit virtual.

Begriffe

BegriffBedeutung
BasisklasseDie allgemeine Klasse (Shape)
Abgeleitete KlasseDie spezielle Klasse (Circle)
virtualMethode darf überschrieben werden, der richtige Typ wird zur Laufzeit gewählt
overrideKennzeichnet das Überschreiben – Compiler prüft, ob es passt
= 0Rein virtuell – Klasse wird abstrakt, man kann kein Objekt direkt erzeugen
finalDarf nicht weiter überschrieben/abgeleitet werden

Tipps & typische Fehler

  • Immer override schreiben – bei einem Tippfehler in der Signatur meldet der Compiler dann einen Fehler statt still eine neue Methode anzulegen.
  • Basisklassen mit virtuellen Methoden brauchen einen virtual Destruktor.
  • Vererbung nur bei einer echten „ist-ein“-Beziehung (Kreis ist eine Form). Sonst lieber ein Objekt als Member („hat-ein“).
